# 파이썬 리스트 슬라이싱 & 언팩킹 정리

## 1. 리스트 슬라이싱 (Slicing)

리스트의 일부 구간을 잘라내거나 교체할 때 사용한다.

### 기본 문법
```python
list[start:end]        # start 인덱스부터 end-1 인덱스까지
list[start:end:step]   # step 간격으로 슬라이싱
```

### 예제
```python
numbers = [0, 0, 0, 0, 0]

# 1번~3번 인덱스를 7로 교체
numbers[1:4] = [7] * 3
print(numbers)  # [0, 7, 7, 7, 0]
```

### 특징
-슬라이싱 범위는 end 인덱스 직전까지만 포함한다.

-슬라이싱에 리스트를 대입하면 선택된 구간이 통째로 교체된다.

-for문을 사용하지 않고 구간을 한 번에 바꿀 수 있어 코드가 간결해진다.

# 2. 언팩킹(Unpacking)과 출력
리스트나 튜플 같은 자료구조 앞에 *를 붙이면, 내부 요소가 풀려서 개별 인자로 전달된다.

### 기본 문법
```python
print(*리스트)
```

### 예제
```python
nums = [1, 2, 3, 4, 5]

print(*nums)   # 1 2 3 4 5
```

### 특징
print()는 여러 인자를 받을 때 기본적으로 공백(" ")으로 구분해 출력한다.

" ".join(map(str, nums)) 대신 print(*nums)를 사용하면 훨씬 간결하다.

내부적으로 str() 변환도 자동으로 처리해 준다.

# 3. 요약
- 슬라이싱 대입: list[a:b] = [값] * 개수 → 리스트 구간을 한 번에 교체 가능.

- 언팩킹 출력: print(*list) → 리스트 요소들을 공백으로 구분해 출력.

✅ 두 기능 모두 코드의 간결성과 가독성을 크게 높여준다.
