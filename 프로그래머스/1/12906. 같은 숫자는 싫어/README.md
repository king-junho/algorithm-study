# P002 — 같은 숫자는 싫어

- 난이도: 기초(학습용 분류), 유형: 배열·반복문·조건 판단

## 문제 설명

정수 배열에서 같은 값이 연달아 나오는 각 구간을 값 하나로 줄인 결과를 반환한다. 남은 값들의 순서는 유지한다. 떨어져 다시 등장한 값은 유지해야 한다. 원문의 조건을 보존한 요약이다.

## 함수 형식

Java Solution 클래스에 `public int[] solution(int[] arr)`를 구현한다. 표준 입출력은 사용하지 않는다.

## 제한사항

- 1 ≤ arr.length ≤ 1,000,000
- 각 원소는 0 이상 9 이하인 정수

## 예시

| arr | 반환값 |
| --- | --- |
| [1,1,3,3,0,1,1] | [1,3,0,1] |
| [4,4,4,3,3] | [4,3] |

첫 예시의 마지막 1 구간은 앞의 1 구간과 떨어져 있으므로 남는다. 두 번째는 4 구간과 3 구간을 각각 하나로 줄인다.
