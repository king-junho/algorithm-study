# P161. 도시 간 최소 이동 시간

플로이드–워셜 기본 · 독립 창작 · 입문 · Java · 권장 20분 · 수정 후 로컬 통과 · 복습 대상

2026-11-20 출제. MST, 다익스트라에 이어 모든 정점 쌍 최단거리 기초를 점검한다.

1~N 도시와 단방향 도로 M개가 주어진다. 모든 출발 도시에서 모든 도착 도시까지의 최소 이동 시간을 표로 출력한다. 자기 자신은 0, 갈 수 없으면 -1이다.

첫 줄 T(1~10). 케이스마다 N M(1≤N≤100, 0≤M≤1,000), 다음 M줄 a b c(1≤a,b≤N, a≠b, 1≤c≤10^9). 같은 방향 도로가 여러 개일 수 있다. Solution.main에서 #케이스번호를 한 줄에 출력한 뒤 N줄에 N개씩 최소 시간을 출력한다.

예시 N=4, 도로 1→2(5),1→2(3),2→3(2),1→3(10),3→1(4)의 결과:
0 3 5 -1
6 0 2 -1
4 7 0 -1
-1 -1 -1 0

## 제출 평가

Java 21 로컬 30/30. 95점. 제출 주석 35분, 실제 시간 미확인. 시간 O(M+N³), 공간 O(N²), 출력 버퍼 별도.
