# P119. 간단한 369게임

- D2 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 10분
- 확인일 2026-11-13 · [SWEA 1926](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV5PTeo6AHUDFAUq)

1부터 N까지의 수를 순서대로 확인한다. 어떤 수에 3, 6, 9가 한 번 이상 들어 있으면 그 수를 해당 자릿수의 개수만큼 이어 붙인 하이픈으로 바꾼다. 세 숫자가 들어 있지 않으면 수를 그대로 출력한다.

Java `Solution.main`으로 구현한다. 입력은 정수 N 하나이며 10 ≤ N ≤ 1,000이다. 결과 N개를 공백으로 구분해 한 줄에 출력한다.

## 자체 예시

```text
14
```

```text
1 2 - 4 5 - 7 8 - 10 11 12 - 14
```

13에는 3이 한 번 들어 있으므로 `-`를 출력한다. 36처럼 해당 숫자가 두 번 등장하면 `--`를 출력한다.
