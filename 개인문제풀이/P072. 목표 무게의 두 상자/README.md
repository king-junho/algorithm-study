# P072. 목표 무게의 두 상자

- 유형: 투 포인터. 난이도: D2 수준 비공식 추정.
- 출처: 독립 창작(2026), 기출 아님. 공개 연습 CSES Sum of Two Values의 두 원소 합 개념 참고. 원문과 달리 정렬·서로 다른 무게가 보장되고 인덱스 대신 모든 쌍의 개수를 출력한다.
- 참고: https://cses.fi/problemset/task/1640 / 확인 2026-10-30. 원문 출제 연도 미확인.
- 권장 20분. 제출 대기.

서로 다른 무게의 N개 상자가 무게 오름차순으로 주어진다. 서로 다른 두 상자를 선택해 무게 합이 정확히 K가 되는 쌍의 개수를 구한다. 순서를 바꾼 같은 쌍은 한 번만 세며 같은 상자를 두 번 쓸 수 없다. 가능한 쌍이 없으면 0.

입력 T, 각 케이스 N K, 다음 줄 N개 무게. 1≤T≤10, 1≤N≤100000, 1≤K≤2000000000, 1≤무게≤1000000000. 무게는 엄격한 오름차순. 출력 #번호 쌍개수. Java Solution/main.

입력
```
3
6 7
1 2 3 4 5 6
5 10
1 3 5 7 9
1 10
5
```
출력
```
#1 3
#2 2
#3 0
```
첫째 (1,6),(2,5),(3,4). 둘째 (1,9),(3,7), 5 하나를 두 번 선택 불가. 셋째 상자 하나여서 불가능.


## 2026-10-30 — P072 첫 제출: 수정 대기

- 풀이10분(11:30~11:40). 잠정73점(정확성25/효율성20/품질12/경계7/설명9). 제출 코드 Java21 실제3사례: [5],K=5 기대0/실제1; [1,2,3],K=3 기대1/실제1; 첫 예시 기대3/실제3.
- left==right일 때 한 상자 무게를 합으로 삼아 잘못된 쌍을 셈. 서로 다른 두 상자가 필요하므로 while(left<right)로 같은 위치 이전 종료하고 두 값 합만 계산하면 됨.
- 사용자 개선 코드 요청에 따라 해당 수정안 제시. 개선안은 별도 Java21 실제4338사례 통과(1~8 부분집합255개×목표1~17=4335, 최대경계3), 독립 이중반복 및 경계 기대값 대조. 이 검증은 사용자 제출 원본 통과를 뜻하지 않음. 완료풀이 저장/커밋/푸시 없음.
- 시간O(N), 입력 포함 공간O(N), 함수 보조O(1), 출력 버퍼 별도. 이번 최대 합2×10^9은 int 범위 이내. 복습 포인트: left<right는 서로 다른 두 원소, 구명보트처럼 한 명도 처리해야 하는 문제의 left<=right와 구분.


## 2026-10-30 — P072 수정 통과
