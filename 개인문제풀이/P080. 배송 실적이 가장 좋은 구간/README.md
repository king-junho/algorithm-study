# P080. 배송 실적이 가장 좋은 구간

- 학습용 D2 수준 추정, 배열과 구간 합, 권장 20분.
- 독립 창작 문제. [CSES Maximum Subarray Sum II](https://cses.fi/problemset/task/1644)의 연속 구간 합을 참고했다. 2026-11-09에 확인했다. 원문 출제 연도는 미확인이다. 고정 길이, 시작일 동률 처리, 제한과 SWEA 형식 입출력은 별도로 구성했다.

N일 동안의 배송 완료 건수가 날짜순으로 주어진다. 정확히 K일 연속으로 골랐을 때 배송 건수 합이 가장 큰 구간을 찾아 시작일과 합을 출력한다. 최대 합이 같으면 가장 이른 시작일을 선택한다. 날짜 번호는 1부터 시작한다.

첫 줄에 T, 각 케이스에 N K와 N개의 배송 건수가 주어진다. 1 ≤ T ≤ 10, 1 ≤ K ≤ N ≤ 100,000, 0 ≤ 일별 건수 ≤ 1,000,000,000. 출력은 `#번호 시작일 최대합`이다.

입력 예시

```text
3
7 3
4 1 7 2 6 1 3
5 2
1 3 1 3 1
3 3
1000000000 1000000000 1000000000
```

출력 예시

```text
#1 3 15
#2 1 4
#3 1 3000000000
```

첫째는 3~5일의 합이 15다. 둘째는 모든 길이 2 구간의 합이 4이므로 1일을 선택한다. 셋째는 전체 기간을 선택한다.

Java `Solution` 클래스의 `main`으로 작성한다. 제출 시 풀이 설명, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
