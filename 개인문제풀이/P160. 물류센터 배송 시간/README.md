# P160. 물류센터 배송 시간

다익스트라 기본 · 독립 창작 · 입문 · Java · 권장 20분 · 수정 후 로컬 통과 · 복습 대상

2026-11-20 출제. P159 MST에 이어 한 출발점 최단거리 기초를 점검한다.

1~N 물류 거점과 단방향 도로 M개, 출발 거점 S가 주어진다. S에서 각 거점까지의 최소 이동 시간을 번호 순서대로 구한다. 자기 자신은 0, 갈 수 없으면 -1이다.

첫 줄 T(1~10), 케이스마다 N M S(1≤N≤1,000, 0≤M≤10,000, 1≤S≤N), 다음 M줄 a b c(a에서 b로 이동, a≠b, 1≤c≤10^9). 같은 방향의 도로가 여러 개일 수 있다. Solution.main에서 #케이스번호 뒤에 1~N번까지의 최소 시간을 출력한다.

예시 N=5, S=1, 간선 1→2(4),1→3(1),3→2(2),2→4(1),3→4(7),4→1(3)의 답은 0 3 1 4 -1이다.

## 제출 평가

Java 21 로컬 30/30. 95점. 최초 13분, 수정 시간 미확인. 시간 O(N+M log(M+1)), 공간 O(N+M), 출력 버퍼 별도.
