# P084. 가장 붐비는 행사장

- D3 수준 추정. 유형은 정렬과 시간 구간. 권장 30분.
- [CSES 1619](https://cses.fi/problemset/task/1619)의 공개 연습 문제를 2026-11-09에 확인했다. 원문 출제 연도는 미확인이다. 같은 시각의 입·퇴장 허용, 최초 시각 출력, 입력 제한과 SWEA 형식을 적용한 변형이다.

N명의 입장 시각과 퇴장 시각이 주어진다. 입장 시각 a, 퇴장 시각 b인 사람은 a ≤ t < b인 시각 t에 행사장 안에 있다. 동시에 행사장 안에 있는 최대 인원과 그 인원에 처음 도달한 시각을 구한다.

첫 줄에 T가 주어진다. 각 케이스에서 첫 줄에 N, 다음 N줄에 a b가 주어진다. 1 ≤ T ≤ 10, 1 ≤ N ≤ 100,000, 0 ≤ a < b ≤ 1,000,000,000. 기록은 시간순이라는 보장이 없고 같은 시각의 입장과 퇴장이 가능하다. 서로 같은 기록도 서로 다른 사람의 기록이다. `#번호 최대인원 최초시각`을 출력한다.

입력 예시

```text
3
5
4 7
1 5
6 9
2 4
4 6
4
0 2
2 4
0 2
2 4
1
999999999 1000000000
```

출력 예시

```text
#1 3 4
#2 2 0
#3 1 999999999
```

첫째는 시각 4에 2시에 입장한 사람이 나가고 두 사람이 들어와 세 명이 된다. 둘째는 시각 2에 두 명이 나가고 두 명이 들어오므로 최대 인원은 두 명이며 최초 시각은 0이다. 셋째는 한 명의 입장 시각에 최대가 된다.

Java `Solution` 클래스의 `main`으로 작성한다. 풀이 설명, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.


## 2026-11-09 — P084 해설 및 실행 검증

- 요청에 따라 입장과 퇴장을 각각 사건으로 기록하고, 시각순으로 정렬한 뒤 같은 시각의 변화량을 모두 반영하는 Java 해설을 제공했다.
- Java 21에서 해설 코드를 1,206개 입력으로 검증했다. 시각 0~4의 소규모 구간 조합 전수 1,000개와 무작위 200개는 입장 시각마다 실제 재실 인원을 직접 센 값과 비교했다. 예시 3개와 10만 명 경계 3개도 일치했다.
- 복습할 때 시각의 최댓값과 사건 개수를 구분한다. 동시 입·퇴장 전체를 반영한 뒤 최대 인원을 비교하고, 최대가 처음 나타난 시각을 유지한다. 시간 O(N log N), 공간 O(N).
- 현재 상태는 해설 제공 및 직접 구현 대기다.
