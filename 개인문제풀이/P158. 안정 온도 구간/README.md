# P158. 안정 온도 구간

SSAFY 모의 7회차 2번 · 독립 창작 · SWEA D3 추정 · Java · 해설 확인 후 복습 통과

2026-11-19. [17기 공식 안내](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_menu_cd=&p_pageno=&p_process=select-board-view&p_seq=194&p_tabseq=226504)와 [15기 후기](https://5-ms.tistory.com/32) 참고. 전체 80분에서 1번 최초 40분 및 수정에 쓴 시간을 제외한 타이머 잔여 시간 적용. 상세 채점은 종료 후 공개.

N분의 온도가 주어진다. 비어 있지 않은 연속 구간에서 최대 온도와 최소 온도의 차이가 K 이하이면 안정 구간이다. 가장 긴 안정 구간의 시작 분과 길이를 구한다. 동률이면 시작 분이 빠른 것을 택한다. 분은 1부터 센다.

첫 줄 T(1~10), 케이스마다 N K(1≤N≤100,000, 0≤K≤100), 다음 줄 온도 N개(각 0~100)가 주어진다. Solution.main에서 #케이스번호 시작분 구간길이를 출력한다.

N=6, K=1, 온도 4 1 4 2 3 2에서 4~6분이 답으로 #1 4 3이다.

## 복습 재출제 · 2026-11-19

유형 비공개, 권장 25분. 기존 제한과 출력 형식을 유지한다. 추가 예시 N=7, K=2, 온도 5 2 3 3 4 8 8의 답은 시작분 2, 길이 4다. 재제출 대기.
