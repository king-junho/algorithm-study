## 문제

가로로 늘어선 칸마다 건물 높이가 주어진다. 높이가 h인 건물에는 1층부터 h층까지 층마다 한 세대가 있다. 어떤 세대의 층 높이에서 왼쪽 두 칸과 오른쪽 두 칸이 모두 비어 있으면 조망권이 확보된다. 같은 높이의 이웃 층도 조망을 가린다. 전체 건물에서 조망권이 확보된 세대 수를 구한다.

## 입출력과 제한

테스트 케이스는 10개로 고정이며 맨 앞에 T를 입력하지 않는다. 케이스마다 첫 줄에 가로 길이 N, 다음 줄에 공백으로 구분된 건물 높이 N개가 주어진다. N은 최대 1,000, 높이는 0 이상 255 이하다. 처음 두 칸과 마지막 두 칸의 높이는 0이다. 케이스마다 `#번호 세대수`를 한 줄에 출력한다. 번호는 1부터 시작한다.

## 자체 예시

아래는 첫 번째 케이스만 보여 준다.

```text
8
0 0 3 7 4 2 0 0
```

```text
#1 3
```

높이 7인 건물의 5층, 6층, 7층에서 조망권이 확보된다.
