# P062. 연구 기지 통신망

- 독립 창작(2026),기초 응용,유형 비공개.
- 참고 자료(유형 판별을 위해 두 자료를 함께 기록): https://cp-algorithms.com/graph/dijkstra.html 및 https://cp-algorithms.com/graph/mst_prim.html /확인2026-10-29. 공개기출·SWEA등록문제아님.
- 권장35분/제출대기

1~N번연구기지,L개기존양방향통신선,M개새통신선후보.기존선은추가비용없이계속사용가능.후보일부를설치해모든기지가직접또는경유하여서로통신하도록한다.새설치비용합최소를구하라.전체연결불가능-1,이미전체연결이면0.특정기지출발시간아닌설치비용총합.

입력T(1~10),각케이스N L M,다음L줄a b(기존선),다음M줄a b cost(후보).1≤N≤1000,0≤L,M≤10000,1≤cost≤10^9,기지번호1~N.자기선없음,기존및후보전체에서같은두기지쌍중복없음(따라서L+M≤N(N-1)/2).모든선양방향.출력 #번호 최소추가비용. Java class Solution/main.

```text
입력
3
4 1 4
1 2
2 3 4
1 3 7
3 4 2
2 4 9
3 1 0
1 2
3 2 1
1 2
2 3
1 3 9

출력
#1 6
#2 -1
#3 0
```

첫째기존1-2활용,2-3과3-4설치4+2=6.둘째3번연결불가.셋째기존선으로전체연결.코드/기법선택근거/복잡도/실제풀이시간제출.유형및핵심풀이요청전비공개.
