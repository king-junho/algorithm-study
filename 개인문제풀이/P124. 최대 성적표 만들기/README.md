# P124. 최대 성적표 만들기

- D3 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 10분
- 확인일 2026-11-13 · [SWEA 4466](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AWOUfCJ6qVMDFAWg)

N개 과목 중 정확히 K개를 골라 성적표에 적는다. 고른 과목의 점수를 더한 값의 최댓값을 구한다. 같은 점수를 받은 서로 다른 과목도 각각 고를 수 있다.

Java `Solution.main`으로 구현한다. 첫 줄에 테스트 케이스 수 T가 주어진다. 각 케이스의 첫 줄에는 N과 K, 다음 줄에는 점수 N개가 주어진다. 1 ≤ K ≤ N ≤ 100이며 점수는 0 이상 100 이하의 정수다. 각 결과는 `#케이스번호 최대총점` 형식으로 출력한다.

## 자체 예시

```text
2
5 3
45 80 80 10 95
4 4
0 25 50 75
```

```text
#1 255
#2 150
```

첫 케이스에서 95점 과목과 80점 과목 두 개를 고르면 총점은 255점이다. 둘째 케이스에서는 네 과목을 모두 골라야 한다.
