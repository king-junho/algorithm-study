# P010 — 목표 방까지 최소 이동

- 출처 구분: 창작 문제(기출 아님)
- 참고: https://school.programmers.co.kr/learn/courses/30/lessons/1844 (공개 연습의 최소 이동 개념 참고)
- 변경점: 격자 대신 P008·P009의 양방향 방 연결 목록 사용. 방문 칸 수가 아닌 문을 지나는 횟수 반환. 시작·목표를 매개변수로 지정.
- 확인·창작일: 2026-10-19 / 난이도: BFS 기초+ / 유형: BFS·최단거리
- 권장 시간: 25분 / 상태: 로컬 검증 통과 · 93/100 · 최초 보고20분(추가 수정 시간 미보고)

## 설명

rooms[i]는 i번 방과 직접 연결된 방 목록이다. start에서 target까지 문을 지나는 최소 횟수를 반환한다. 문 하나를 지나면 이동1회이며 모든 문의 이동 비용은 같다. 도달할 수 없으면 -1, start==target이면 0이다.

## 함수와 제한

`public int solution(int[][] rooms, int start, int target)`

- 방 수1~20, 번호0..rooms.length-1
- start와 target은 유효한 번호
- 문은 양방향, 양쪽 연결 목록 모두 제공
- 목록 내 중복·자기 연결 없음, 빈 목록 가능, 목록 순서는 임의
- Queue와 반복문으로 BFS 구현

## 예시

1. rooms=[[1,2],[0,3],[0,4],[1,4],[2,3]], start=0, target=4 → 2. 0→2→4는2회, 0→1→3→4는3회.
2. rooms=[[1],[0],[]], start=0, target=2 → -1. 목표방 고립.
3. rooms=[[1],[0]], start=1, target=1 → 0. 이미 도착.

## 제출

Java 코드, 풀이 설명, 시간·공간 복잡도와 근거, 실제 풀이 시간. 테스트 예상값·실행 여부 제출 요구 없음. 에이전트가 검증.

## 최종 평가

- 정확성40/40, 효율성20/20, 코드품질10/15, 테스트·경계조건15/15, 설명·면접대응8/10 = 93/100, 통과.
- [P010.java](P010.java): 제출 로직과 주석·미사용 move를 보존하고 붙여넣기 서식, import·클래스·공백만 정리.
- Java21 실제69,832개 시작/목표 조합 검증 통과. 방1~5의 모든 무방향 단순그래프, 방1~20 무작위300개, 방20 완전연결·완전고립. 이웃 목록 순서를 섞고 Floyd-Warshall의 최단거리와 비교. 입력 불변 확인, 외부 채점기 미실행. 검증 파일은 커밋 제외.
- O(V+E) 시간, O(V) 추가 공간. 각 방을 최대1회 등록하고 연결 목록을 확인함.
- 개선: 큐 처리 횟수 대신 방별 거리, 미발견 -1, 시작점 거리0, 이웃 목표 반환 시 현재거리+1, 시작=목표0 처리.
- 품질 감점: 미사용 move, 실제 코드와 다른 과거 주석. rooms[current][i]를 next 변수로 정리하면 명확함.
- 설명 보완: BFS는 가까운 거리부터 큐에서 처리하므로 목표를 처음 발견했을 때 거리가 최단임. 거리 배열의 -1은 미방문 표시도 겸함.
