# P171. 다리를 지나는 트럭

- 출처: 프로그래머스 공개 연습 https://school.programmers.co.kr/learn/courses/30/lessons/42583
- 확인일: 2026-11-27. 출제 연도 미확인(공식 테스트 추가 공지2020년).
- 유형: 제출 또는 요청 전 비공개
- 난이도: SWEA D3 수준 비공식 추정
- 권장 시간: 30분
- 상태: 미제출

정해진 순서의 트럭이 일차선 다리를 지난다. 다리에 있는 트럭 수는 bridge_length 이하, 무게 합은 weight 이하를 유지해야 한다. 1초에 최대 한 대 진입하고 진입 후 bridge_length초가 지나면 빠져나온다. 같은 시각에 빠져나온 트럭은 무게·대수에서 제외한 뒤 새 트럭 진입 가능. 시간0에는 다리가 비었고 첫 트럭은1초에 진입 가능. 모든 트럭이 다리를 완전히 건너는 최소 시간을 반환한다. 순서 변경·추월 불가.

Java public int solution(int bridge_length,int weight,int[] truck_weights). bridge_length,weight,트럭수 각1~10000. 트럭무게1~weight.

예시 길이2 한도10 트럭[7,4,5,6] →8. 진입시각1,3,4,6 / 퇴장시각3,5,6,8.
길이100 한도100 트럭[10] →101. 같은조건 트럭10대 모두무게10 →110.
