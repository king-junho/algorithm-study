## 문제

상자 더미 100개가 한 줄에 놓여 있다. 덤프 한 번은 가장 높은 더미에서 상자 하나를 꺼내 가장 낮은 더미에 놓는 작업이다. 같은 높이의 후보가 여러 개면 그중 하나를 골라도 된다.

최대 D번 덤프한 뒤 가장 높은 더미와 가장 낮은 더미의 높이 차이를 구한다. 그 전에 높이 차이가 0 또는 1이 되면 그 상태에서 종료한다.

## 입출력과 제한

테스트 케이스는 10개로 고정이며 맨 앞에 T는 주어지지 않는다. 각 케이스는 덤프 횟수 D와 상자 더미 100개의 높이를 한 줄씩 입력받는다. 1 ≤ D ≤ 1,000이고 각 높이는 1 이상 100 이하다. 각 케이스마다 `#번호 높이차`를 출력한다. 번호는 1부터 시작한다.

## 자체 예시 설명

높이가 2, 4, 7인 더미에 덤프를 한 번 적용하면 3, 4, 6이 되므로 높이 차이는 3이다. 이 예시는 동작 설명을 위해 더미 수를 줄였다. 실제 입력에는 케이스마다 높이 100개가 주어진다.

Java `Solution.main`으로 작성한다. 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
