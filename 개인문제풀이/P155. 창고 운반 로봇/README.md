# P155. 창고 운반 로봇

SSAFY SW전공 적성진단 모의 6회차 1번 · Java · 독립 창작 · SWEA D2~D3 비공식 추정 · 로컬 통과

2026-11-19 확인. [17기 공식 공지](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_menu_cd=&p_pageno=&p_process=select-board-view&p_seq=194&p_tabseq=226504)의 80분과 [15기 후기](https://5-ms.tistory.com/32)의 순차 공개 참고. 회차 전체 80분, 1번 권장 30분. 진입 기준 충족 후 2번 공개, 세부 채점은 종료 후 공개.

H×W 창고에서 S는 시작, 점은 빈칸, #은 벽, 숫자 1~9는 상자의 가치다. 명령 U/D/L/R d는 해당 방향으로 d칸 직선 이동이다. 경로 중 벽이나 범위 밖이 하나라도 있으면 명령 전체가 취소되고 위치와 상자를 모두 유지하며 실패를 하나 센다. 성공하면 지나간 모든 칸의 상자를 회수해 가치 합에 더하고 해당 칸을 빈칸으로 바꾼다. 시작 칸도 다시 들어갈 수 있다.

첫 줄 T(1~10), 케이스마다 H W Q(1≤H,W≤50, 1≤Q≤200), 격자 문자열 H줄, 명령 Q줄. 이동 거리 1~100. 시작점은 정확히 하나. Solution.main에서 #케이스번호 최종행 최종열 회수가치합 실패횟수를 출력한다. 좌표는 1부터 센다.

예시 격자 S1./.#./2.3에서 명령 R3 R2 D2 L2 U2 D1을 적용하면 2행 1열, 회수 가치 6, 실패 1회다.
