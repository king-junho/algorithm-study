# P139. 소득 불균형

D3 · SWEA 공개 연습 · 권장 10분 · 로컬 통과

2026-11-16 확인. [SWEA 10505 공식 문제 및 제한](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AXNP4CvauaMDFAXS&categoryId=AXNP4CvauaMDFAXS&categoryType=CODE)

N명의 소득이 주어질 때 전체 평균 소득 이하인 사람의 수를 구한다. 평균과 소득이 같은 사람도 센다.

첫 줄에 테스트 케이스 수 T가 주어진다. 각 케이스의 첫 줄에 N, 다음 줄에 N명의 소득이 주어진다. 각 케이스마다 `#케이스번호 인원수`를 출력한다.

소득이 1, 2, 3, 6이면 평균은 3이므로 3명이다.

## 제출 기록

5분(12:47~12:52). Java 21 로컬 106개 통과. SWEA 공식 채점 미확인. 케이스당 시간 O(N), 입력 배열 포함 공간 O(N).
