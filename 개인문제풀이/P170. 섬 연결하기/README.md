# P170. 섬 연결하기

- 출처: 프로그래머스 공개 연습 https://school.programmers.co.kr/learn/courses/30/lessons/42861
- 확인일: 2026-11-24. 출제 연도 미확인.
- 유형: 제출 또는 요청 전 비공개
- 난이도: SWEA D3~D4 수준 비공식 추정
- 권장 시간: 30분
- 상태: 미제출

0~n-1번 섬과 건설 가능한 양방향 다리 costs=[a,b,비용]가 주어진다. 일부 다리를 건설해 모든 섬이 서로 이동 가능해지도록 할 때 최소 건설 비용을 반환한다. 다른 섬을 거쳐 이동해도 된다. 명시되지 않은 다리는 건설 불가능, 같은 연결 중복 없음, 모든 섬 연결 가능이 보장된다.

Java public int solution(int n,int[][] costs). n1~100, costs.length≤n(n-1)/2. 공식 설명에 비용의 별도 수치 상한은 명시되지 않음.

예시 n4, costs=[[0,1,1],[0,2,2],[1,2,5],[1,3,1],[2,3,8]] →4. 0-1,0-2,1-3 건설.
