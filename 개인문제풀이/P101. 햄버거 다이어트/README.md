# P101. 햄버거 다이어트

- SWEA 5215 공개 연습 문제다. 2026-11-11에 공식 목록에서 D3를 확인했다. 최초 공개 연도는 확인되지 않았다. [문제 페이지](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AWT-lPB6dHUDFAVT) · [공식 D3 목록](https://swexpertacademy.com/main/code/problem/problemList.do?pageIndex=5&pageSize=30&problemLevel=3)
- 풀이 유형은 비공개다.
- 권장 시간은 25분이다.

재료마다 맛 점수와 칼로리가 주어진다. 재료 하나는 최대 한 번 쓸 수 있다. 선택한 재료의 칼로리 합이 L 이하인 조합 중 맛 점수 합의 최댓값을 구한다.

첫 줄에 테스트 케이스 수 T가 주어진다. 각 케이스의 첫 줄에 재료 수 N과 제한 칼로리 L이 주어진다. 다음 N줄에는 각 재료의 맛 점수와 칼로리가 차례로 주어진다. 1 ≤ N ≤ 20, 1 ≤ L ≤ 10,000이며 각 맛 점수와 칼로리는 1 이상 1,000 이하다. 각 케이스마다 `#번호 최댓값`을 출력한다. 번호는 1부터 시작한다.

자체 예시 입력

```text
1
4 500
80 320
55 240
45 180
30 80
```

예시 출력

```text
#1 130
```

두 번째부터 네 번째까지의 재료를 고르면 칼로리 합은 500이고 점수 합은 130이다.

Java `Solution.main`으로 작성한다. 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
