# P048. 마을 연결하기

- 난이도: MST 입문 / 유형: 최소 신장 트리
- 출처 구분: 독립 창작. 특정 채용·SWEA 기출이 아님.
- 개념 참고: https://cp-algorithms.com/graph/mst_kruskal_with_dsu.html (확인일 2026-10-27). 출제 연도 2026.
- 권장 시간: 30~40분 / 상태: 제출 대기

## 문제

1~N번 마을과 M개의 양방향 도로 후보가 주어진다. 일부 도로를 건설해 모든 마을 사이를 이동할 수 있게 하면서 건설 비용 합을 최소화하라. 사이클 없이 모든 마을을 연결하는 도로 집합을 구하며 비용 합만 출력한다. 모든 마을을 연결할 수 있는 입력만 주어진다.

## 입출력

첫 줄 T(1~10), 각 케이스 첫 줄 N M, 이어 M줄 a b cost. 2≤N≤1000, N-1≤M≤min(10000,N(N-1)/2), 1≤cost≤1000. 자기 자신을 잇는 도로와 같은 두 마을 사이의 중복 도로는 없다. 출력은 #번호 최소비용. Java main, class Solution.

```text
입력
2
3 3
1 2 1
2 3 2
1 3 5
4 5
1 2 1
2 3 2
1 3 3
3 4 4
2 4 10

출력
#1 3
#2 7
```

첫째 1-2,2-3 선택. 둘째 1-2,2-3,3-4 선택. 비용은 1+2+4=7.

이번 목표는 배운 MST 알고리즘의 기본 구조를 직접 구현하는 것이다. 코드와 풀이 설명, 시간·공간 복잡도, 실제 풀이 시간을 제출한다. 핵심 풀이·정답 코드는 요청 전 공개하지 않는다.

## 제출 평가 — 2026-10-27

Prim + 인접 리스트 + PriorityQueue. 15분. 93점(정확성40, 효율성20, 품질13, 경계15, 설명5), 운영상 통과. Java21에서 표준입출력 505케이스를 독립 Kruskal 결과와 비교해 모두 일치. 예시, N=2, 동일 비용, 사이클, 최대 N=1000/M=10000, 최대 가중치, 다중 테스트 초기화 포함. 외부 채점기 미실행. 시간 O(E log E), 공간 O(V+E). 원 제출의 공간 O(VE)는 수정 필요. 주석의 long/count는 실제 int/미사용과 불일치. 입력 범위에서는 최대 비용 999000으로 int 안전.
