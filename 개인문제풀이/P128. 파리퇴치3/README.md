# P128. 파리퇴치3

- D2 · SWEA 공개 사용자 문제 · 격자·방향 탐색
- 권장 시간 20분
- 확인일 2026-11-14 · [SWEA 사용자 문제 목록 12712](https://swexpertacademy.com/main/code/userProblem/userProblemList.do?orderBy=INQUERY_COUNT&pageIndex=1&pageSize=30&problemTitle=&select-1=)

N×N 격자의 각 칸에 파리 수가 주어진다. 한 칸을 중심으로 골라 상하좌우(+) 또는 네 대각선(×)으로 한 번 분사한다. 각 방향으로 중심에서 M-1칸까지 닿으며, 격자 안의 칸만 합산한다. 중심은 한 번만 더한다. 잡을 수 있는 최대 파리 수를 구한다.

Java Solution.main으로 구현한다. 첫 줄에 T, 각 케이스 첫 줄에 N과 M, 다음 N줄에 각 행의 파리 수 N개가 주어진다. 5 ≤ N ≤ 15, 2 ≤ M ≤ N. 각 케이스에 #케이스번호 최댓값을 출력한다.

```text
1
5 2
1 1 1 1 1
1 9 1 9 1
1 1 9 1 1
1 9 1 9 1
1 1 1 1 1
```

```text
#1 45
```

정가운데에서 × 모양으로 분사하면 중심과 대각선 네 칸에서 9마리씩 잡는다.
