## 문제

정수 8개가 한 줄에 놓여 있다. 매번 맨 앞의 수를 꺼내 정해진 만큼 줄인 뒤 맨 뒤로 보낸다. 감소량은 1, 2, 3, 4, 5 순서로 진행하고, 그다음 다시 1부터 반복한다. 줄인 값이 0 이하가 되는 순간, 그 값을 0으로 바꿔 맨 뒤에 넣고 종료한다. 종료 시점의 수 8개를 앞에서부터 출력한다.

## 입출력과 제한

테스트 케이스는 10개로 고정이다. 맨 앞에 전체 케이스 수 T는 주어지지 않는다. 각 케이스의 첫 줄에 테스트 케이스 번호, 둘째 줄에 공백으로 구분된 정수 8개가 주어진다. 입력의 각 수는 int 범위에 들어가며 최종 암호의 각 값은 한 자리다. 각 케이스마다 `#번호`와 종료 시점의 정수 8개를 공백으로 구분해 한 줄에 출력한다.

## 자체 예시

첫 번째 케이스만 보여 준다.

입력

```text
1
8 7 6 5 4 3 2 1
```

출력

```text
#1 3 2 1 7 5 3 1 0
```

다섯 번째 연산에서 4에서 5를 빼므로 0을 맨 뒤에 넣고 종료한다.
