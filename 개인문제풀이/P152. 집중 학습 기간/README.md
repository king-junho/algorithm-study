# P152. 집중 학습 기간

독립 창작 · 비공식 SWEA D2~D3 추정 · 투 포인터 · Java · 권장 20분 · 로컬 통과

2026-11-19 출제. 앞선 투 포인터 학습 기록을 바탕으로 구성했다.

N일의 학습 기록은 1(학습), 0(미학습)이다. 연속 구간 하나를 고르고 그 안의 미학습 날을 최대 K일 보충할 수 있다. 구간 전체를 학습한 날로 만들 수 있는 가장 긴 구간의 길이를 구한다.

첫 줄 T(1~10). 각 케이스의 첫 줄에 N K(1≤N≤100,000, 0≤K≤N), 다음 줄에 0 또는 1인 정수 N개가 주어진다. Solution.main에서 #케이스번호 최대길이를 출력한다.

예시 N=8, K=1, 기록 1 0 1 1 0 1 1 1이면 3~8일의 미학습 날 하나를 보충해 답은 6이다.

## 제출 평가

Java 21 로컬 1795개 통과. 96점. 풀이 시간 미확인. 시간 O(N), 입력 포함 공간 O(N), 함수 추가 공간 O(1).
