# P120. 쉬운 거스름돈

- D2 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 10분
- 확인일 2026-11-13 · [SWEA 1970](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV5PsIl6AXIDFAUq)

50,000원, 10,000원, 5,000원, 1,000원, 500원, 100원, 50원, 10원으로 거스름돈 N원을 만들 때 사용하는 지폐와 동전의 총개수를 최소화한다. 각 화폐를 몇 개씩 사용하는지 구한다.

Java `Solution.main`으로 구현한다. 첫 줄에 테스트 케이스 수 T가 주어지고, 이후 각 줄에 거스름돈 N이 주어진다. 10 ≤ N ≤ 1,000,000이며 N의 일의 자리는 0이다. 각 케이스마다 첫 줄에 `#케이스번호`, 다음 줄에 위 화폐 순서대로 개수 8개를 공백으로 구분해 출력한다.

## 자체 예시

```text
2
68570
110
```

```text
#1
1 1 1 3 1 0 1 2
#2
0 0 0 0 0 1 0 1
```

110원은 100원과 10원을 하나씩 사용하면 만들 수 있다.
