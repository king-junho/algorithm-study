# P031 — target 이상인 첫 위치

- 출처 구분: 독립 창작 학습 문제, 특정 시험 기출 아님

- 권장 시간: 25분 / 상태: 학습 통과97점 · 풀이시간미보고

## 문제

비내림차순 정렬된 정수 배열 numbers와 정수 target이 주어진다. numbers[i] >= target을 만족하는 가장 작은 인덱스 i를 반환한다. 없으면 numbers.length를 반환한다(-1이아님). 중복 허용. 배열은 이미 정렬되어 있다.

`public int solution(int[] numbers, int target)`

## 제한

- 1 ≤ numbers.length ≤ 100,000
- -1,000,000,000 ≤ numbers[i],target ≤ 1,000,000,000
- 비내림차순,중복가능. 인덱스0부터시작
- 이진 탐색 직접 구현,전체선형탐색·Arrays.binarySearch로대체하지않음
- 재귀/반복문 모두가능

## 예시

| numbers | target | 반환 |
| --- | --- | --- |
| [1,3,3,3,7,9] | 3 | 1 |
| [1,3,3,3,7,9] | 4 | 4 |
| [1,3,3,3,7,9] | 0 | 0 |
| [1,3,3,3,7,9] | 10 | 6 |
| [5] | 5 | 0 |

3이여러개면첫위치1,4가없어도이상인첫원소7의위치4,모두작으면길이6.

## 제출

코드,풀이설명,시간·공간복잡도와근거,실제풀이시간. 재귀라면호출스택포함. 직접테스트제출요구없음. 정답·핵심범위갱신규칙요청전미공개.
