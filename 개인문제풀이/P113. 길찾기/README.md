# P113. 길찾기

- D4 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 20분
- 확인일 2026-11-12 · [SWEA 1219](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV14geLqABQCFAYD)

0번에서 출발해 일방통행 길을 따라 99번에 도착할 수 있으면 1, 없으면 0을 출력한다. 지점 번호는 0부터 99까지이며, 각 지점에서 나가는 길은 최대 두 개다.

Java `Solution.main`으로 구현한다. 테스트 케이스는 10개이며 첫 줄에 별도의 T는 없다. 각 케이스의 첫 줄에는 케이스 번호와 길의 수 E가 주어진다. 다음 줄의 정수 2E개를 두 개씩 묶으면 각 길의 출발점과 도착점이 된다. 각 결과는 `#케이스번호 결과` 형식으로 출력한다.

## 자체 예시

아래는 두 케이스만 발췌한 입력이다.

```text
1 4
0 1 0 2 1 3 2 99
2 3
0 4 4 7 99 7
```

```text
#1 1
#2 0
```

첫 케이스에는 0 → 2 → 99가 있다. 둘째 케이스에서 99 → 7은 일방통행이어서 7에서 99로 이동할 수 없다.
