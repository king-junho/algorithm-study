# P055. 하루 행사 배정

- 독립 창작(2026), 학습용 D3 상당(공식 등급 아님), 유형 비공개.
- 난이도 참고: SWEA 공식 D3 목록 https://swexpertacademy.com/main/code/problem/problemList.do?orderBy=RECOMMEND_COUNT&pageIndex=1&pageSize=10&problemLevel=3&select-1=3&selectCodeLang=CCPP / 확인2026-10-28. 실제 기출이나 등록문제 아님.
- 권장30분 / 제출 대기

행사장 하나에 N개 행사 신청,각 시작 s/종료 e가 주어진다. 일부를 골라 시간이 겹치지 않게 개최할 때 최대 행사 개수를 구한다. 행사 시간을 변경하거나 일부만 개최할 수 없음. 한 행사 종료시각과 다른 행사 시작시각이 같으면 이어서 개최 가능, 준비시간0. 입력은 시간순 정렬 보장없음. 목표는 총진행시간이 아닌 개최개수.

입력 T(1~10),각 케이스 N,이어 N줄 s e. 1≤N≤100000,0≤s<e≤1000000000. 같은 시간의 신청도 각각 별개지만 겹쳐 동시 개최 불가. 출력 #번호 최대행사수. Java class Solution/main.

```text
입력
3
6
1 4
3 5
0 6
5 7
7 9
5 9
3
1 5
2 6
3 7
1
0 1

출력
#1 3
#2 1
#3 1
```

첫째(1,4),(5,7),(7,9) 개최가능. 둘째 모두 겹쳐 하나만. 셋째유일한행사선택. 코드·기법선택과 이유·시간공간복잡도·실제풀이시간 제출. 핵심풀이/유형은 요청전 비공개.

## 제출 통과·재도전 예정

2026-10-28,20분,92점(정확성40/효율성20/품질13/경계15/설명4). 종료시각 정렬 기준은 외부 자료 참고 후 구현했다고 사용자 명시. 통과 기록 유지하고 사용자 요청으로 복습 재도전 대상으로 지정. Java21 실제1084 표준입출력 사례가 독립 부분집합 전수 정답과 일치(작은 행사열780,무작위300,경계4). N100000,동일종료·중복,종료=시작,시각0,10^9 포함. 개선 Arrays.sort 예시도 동일1084케이스 통과. 공개채점기 미실행.

시간 O(N log N),공간 O(N). PriorityQueue 삽입·poll 비용을 누락한 O(N) 설명 수정 필요. 모든 행사를 미리 알고 순서대로 한번 처리하므로 배열 정렬도 적합하며 Comparable 대신 Comparator 가능. 동일 종료 시각이면 이 문제(s<e)의 개수 최적화에는 시작시각 타이브레이크 불필요. 재도전 때 가장 먼저 끝나는 선택을 임의 최적해 첫 행사와 교체해도 뒤 일정이 유지되는 이유 설명.
