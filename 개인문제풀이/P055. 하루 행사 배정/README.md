# P055. 하루 행사 배정

- 독립 창작(2026), 학습용 D3 상당(공식 등급 아님), 유형 비공개.

행사장 하나에 N개 행사 신청,각 시작 s/종료 e가 주어진다. 일부를 골라 시간이 겹치지 않게 개최할 때 최대 행사 개수를 구한다. 행사 시간을 변경하거나 일부만 개최할 수 없음. 한 행사 종료시각과 다른 행사 시작시각이 같으면 이어서 개최 가능, 준비시간0. 입력은 시간순 정렬 보장없음. 목표는 총진행시간이 아닌 개최개수.

입력 T(1~10),각 케이스 N,이어 N줄 s e. 1≤N≤100000,0≤s<e≤1000000000. 같은 시간의 신청도 각각 별개지만 겹쳐 동시 개최 불가. 출력 #번호 최대행사수. Java class Solution/main.

```text
입력
3
6
1 4
3 5
0 6
5 7
7 9
5 9
3
1 5
2 6
3 7
1
0 1

출력
#1 3
#2 1
#3 1
```

첫째(1,4),(5,7),(7,9) 개최가능. 둘째 모두 겹쳐 하나만. 셋째유일한행사선택. 코드·기법선택과 이유·시간공간복잡도·실제풀이시간 제출. 핵심풀이/유형은 요청전 비공개.
