# P172. 기능개발

- 출처: 프로그래머스 공개 연습 https://school.programmers.co.kr/learn/courses/30/lessons/42586
- 확인일: 2026-11-27. 출제 연도 미확인(테스트 추가 공지2020년).
- 난이도: SWEA D2~D3 수준 비공식 추정
- 유형: 제출 또는 요청 전 비공개
- 권장 시간: 25분
- 상태: 미제출

기능은 입력 순서대로 배포한다. 각 기능의 현재 진도 progresses와 하루 작업량 speeds가 주어진다. 매일 모든 미완료 작업이 진행되고 하루 끝에 배포한다. 앞의 기능이 미완료라면 뒤의 완성 기능도 기다리며, 배포 가능한 앞부분의 연속된 완료 기능들을 같은 날 모두 배포한다. 배포일별 기능 개수를 순서대로 반환.

Java public int[] solution(int[] progresses,int[] speeds). 길이1~100, progresses각1~99, speeds각1~100. 두배열같은길이.
예시 [93,30,55],[1,30,5]→[2,1]. 7일째2개,9일째1개.
예시 [95,90,99,99,80,99],[1,1,1,1,1,1]→[1,3,2].
