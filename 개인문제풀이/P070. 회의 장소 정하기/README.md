# P070. 회의 장소 정하기

- 유형플로이드–워셜기본응용 / 독립창작(2026),기출아님.
- 개념참고 https://cp-algorithms.com/graph/all-pair-shortest-path-floyd-warshall.html /확인2026-10-29.
- 권장35분/제출대기

1~N번마을에각각대표1명,모두회의마을하나로이동. M개양방향도로와시간.각대표는자기마을에서회의마을까지최소시간으로이동하며그시간합이최소인회의마을선택. 동률이면작은번호.어느마을을선택해도모든대표가모일수없으면-1. 왕복아님,시작과회의마을같으면시간0. 동시에이동해도목표는합계이며마지막도착시각아님.

입력T(1~10),각케이스N M,다음M줄a b time.1≤N≤100,0≤M≤N(N-1)/2,1≤time≤10^9.자기간선/중복없음.출력 #번호 마을번호 최소시간합,불가능은 #번호 -1. Java class Solution/main.

```text
입력
3
4 3
1 2 1
2 3 1
3 4 1
3 1
1 2 5
1 0

출력
#1 2 4
#2 -1
#3 1 0
```

첫째회의마을1/2/3/4일때합6/4/4/6,동률작은2선택.둘째3번고립.셋째이동없이1번선택0. 코드/거리배열뜻/선택조건/시간공간복잡도/풀이시간제출.정답코드요청전비공개.


## 제출 평가 — 2026-10-30

- 풀이 시간: 15분(12:00~12:15). 운영상 통과 98점: 정확성 40, 효율성 20, 코드 품질 14, 테스트·경계 조건 15, 설명 9.
