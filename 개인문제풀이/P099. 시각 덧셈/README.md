# P099. 시각 덧셈

- SWEA 1976 공개 연습 문제다. 2026-11-11에 공식 목록에서 D2를 확인했다. 최초 공개 연도는 확인되지 않았다. [문제 페이지](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV5PttaaAZIDFAUq) · [공식 D2 목록](https://swexpertacademy.com/main/code/problem/problemList.do?orderBy=PASS_RATE&pageIndex=2&pageSize=10&problemLevel=2&select-1=2&selectCodeLang=JAVA)
- 풀이 유형은 비공개다.
- 권장 시간은 10분이다.

두 시각을 더한 결과를 12시간제로 출력한다. 시는 1~12, 분은 0~59로 표현한다.

첫 줄에 테스트 케이스 수 T가 주어진다. 다음 T줄에 `h1 m1 h2 m2`가 주어진다. 각 케이스에서 `#번호 시 분`을 한 줄에 출력한다. 번호는 1부터 시작한다.

자체 예시 입력

```text
3
8 45 4 30
11 30 12 30
12 0 12 0
```

예시 출력

```text
#1 1 15
#2 12 0
#3 12 0
```

첫 케이스의 합인 13시 15분은 12시간제에서 1시 15분이다. 두 번째 케이스의 합인 24시 0분은 12시 0분이다.

Java `Solution.main`으로 작성한다. 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
