# P115. 장훈이의 높은 선반

- D4 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 25분
- 확인일 2026-11-12 · [SWEA 1486](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV2b7Yf6ABcBBASw)

점원 중 한 명 이상을 골라 탑을 쌓는다. 각 점원은 한 번만 선택할 수 있으며, 탑의 높이는 선택한 점원들의 키를 더한 값이다. 높이가 B 이상인 탑 중 가장 낮은 탑을 찾아 그 높이와 B의 차이를 출력한다.

Java `Solution.main`으로 구현한다. 첫 줄에 테스트 케이스 수 T가 주어진다. 각 케이스의 첫 줄에는 점원 수 N과 선반 높이 B, 다음 줄에는 점원들의 키 N개가 주어진다. 1 ≤ N ≤ 20, 1 ≤ Hᵢ ≤ 10,000이며, B는 1 이상이고 모든 점원의 키 합 이하다. 각 답을 `#케이스번호 차이` 형식으로 출력한다.

## 자체 예시

```text
2
4 16
4 6 8 11
3 12
3 5 7
```

```text
#1 1
#2 0
```

첫 케이스에서 16 이상인 최소 높이는 6 + 11 = 17이다. 둘째 케이스에서는 5 + 7 = 12로 선반 높이와 같아진다.
