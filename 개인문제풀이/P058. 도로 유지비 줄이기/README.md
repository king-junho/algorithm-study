# P058. 도로 유지비 줄이기

- 독립 창작(2026),학습용D3상당(비공식),유형비공개.

1~N번마을에M개양방향도로가이미있고각유지비가주어진다. 일부도로를폐쇄해유지비를절약하려한다. 남은도로만으로모든마을사이를이동할수있어야한다(다른마을경유가능). 절약가능한연간유지비최댓값을구한다. 폐쇄비용0,도로추가불가. 원래도모든마을연결불가능이면-1. N1은도로없이연결완료.

입력T(1~10),각케이스N M,이어M줄a b cost.1≤N≤1000,0≤M≤min(10000,N(N-1)/2),1≤cost≤10^9,1≤a,b≤N.자기간선/중복없음. 출력 #번호 최대절약액(남은유지비아님).Java class Solution/main.

```text
입력
3
3 3
1 2 3
2 3 4
1 3 10
4 2
1 2 5
3 4 7
1 0

출력
#1 10
#2 -1
#3 0
```

첫째1-3도로폐쇄해10절약,나머지두도로로모두연결. 둘째원래두그룹분리.셋째폐쇄할도로없음. 코드·기법선택과근거·시간공간복잡도·실제시간제출.정답/핵심풀이요청전비공개.
