# P114. 미로1

- D4 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 20분
- 확인일 2026-11-12 · [SWEA 1226](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV14vXUqAGMCFAYD)

16×16 미로에서 출발점 2에서 도착점 3으로 갈 수 있는지 구한다. 0은 통로, 1은 벽이다. 상하좌우로 한 칸씩 이동할 수 있다.

Java `Solution.main`으로 구현한다. 테스트 케이스는 10개로 고정이다. 별도의 T 없이 각 케이스는 번호 한 줄과 공백 없는 숫자 16개로 이루어진 16줄로 주어진다. 각 케이스에 대해 `#케이스번호 결과`를 출력한다. 도착할 수 있으면 1, 없으면 0이다.

## 자체 예시

규칙을 설명하기 위해 축소한 미로다.

```text
11111
12011
11031
11111
```

출발점에서 오른쪽, 아래, 오른쪽으로 이동하면 도착점에 닿으므로 결과는 1이다.
