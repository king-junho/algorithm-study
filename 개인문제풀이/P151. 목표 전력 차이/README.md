# P151. 목표 전력 차이

2026-11-18. [17기 공식 공지](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_menu_cd=&p_pageno=&p_process=select-board-view&p_seq=194&p_tabseq=226504)와 [2025년 15기 후기](https://5-ms.tistory.com/32) 참고. 전체 80분 중 1번 풀이 39분 기준으로 2번 최대 41분. 실제 타이머의 잔여 시간을 따른다.

N일의 실제 전력 사용량과 계획량의 차이가 주어진다. 일별 차이는 음수, 0, 양수가 가능하다. 합이 정확히 K인 비어 있지 않은 연속 날짜 구간의 개수를 구한다. 시작일이나 종료일이 다르면 별개의 구간이다.

첫 줄 T(1~10). 케이스마다 N K(1≤N≤100,000, -10^14≤K≤10^14), 다음 줄에 일별 차이 N개(각 -10^9~10^9)가 주어진다. Solution.main에서 `#케이스번호 구간개수` 출력. 없으면 0을 출력한다.

예시: N=5, K=2, 차이 2 -2 2 -2 2의 답은 6.

## 복습 재출제 · 2026-11-20

유형 비공개, 권장 30분. 기존 제한과 출력 형식을 유지한다. N=5, K=2, 기록 1 -1 2 -2 2의 답은 5다. 재제출 대기.
