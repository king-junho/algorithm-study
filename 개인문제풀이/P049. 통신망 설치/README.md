# P049. 통신망 설치

- 난이도: MST 기초 / 유형: MST·연결 가능 여부
- 출처: 독립 창작(2026). 개념 참고 https://cp-algorithms.com/graph/mst_prim.html (확인일 2026-10-27). 채용 기출 및 SWEA 문제가 아님.
- 권장 시간 25~35분 / 통과 94점 · 풀이 15분

1~N번 기지국과 M개의 양방향 케이블 후보가 주어진다. 일부를 선택해 모든 기지국 사이에 통신할 수 있게 할 때 최소 비용을 출력하라. 다른 기지국을 거쳐 통신해도 된다. 불가능하면 -1. N=1이면 케이블 없이 연결 완료, 비용 0.

입력: T(1~10), 각 케이스 N M, 이어 M줄 a b cost. 1≤N≤1000, 0≤M≤min(10000,N(N-1)/2), 1≤cost≤1000000. 자기 간선과 중복 간선 없음. 연결 그래프 보장 없음. 출력 #번호 최소비용 또는 -1. Java class Solution, main.

```text
입력
3
4 5
1 2 4
1 3 2
2 3 1
2 4 5
3 4 8
4 2
1 2 3
3 4 4
1 0

출력
#1 8
#2 -1
#3 0
```

첫째 1-3,3-2,2-4의 비용 합 8. 둘째 두 그룹 간 연결 불가능. 셋째 이미 기지국 하나뿐. 풀이 설명, 시간·공간 복잡도, 실제 풀이 시간 제출. 정답·핵심 풀이 요청 전 미공개.

## 검증·평가

Java21에서 1064개 표준입출력 케이스를 실행해 독립 Kruskal 결과와 일치. N≤4 모든 단순 그래프에 간선 없음/비용1/비용1000000 조합, 무작위300, N=1/M=0, 단절, 최대 N/M, 최대비용 사슬 포함. 공개 채점기 미실행. 점수 94(정확성40/효율성20/품질14/경계15/설명5).

시간 O(V + E log(E+1)), 공간 O(V+E). 입력이 연결된 일반적인 경우 시간은 O(E log E)로 표현 가능하나, 이 문제는 E=0도 가능하므로 초기화 O(V)를 포함한다. 공간 O(VE)는 이전 제출과 같은 오류: 인접리스트·큐·방문배열 크기를 더한다. count는 간선 수가 아니라 확정된 정점 수(시작점 포함). 방문 배열은 함수 내부에 두면 책임이 명확해진다.
