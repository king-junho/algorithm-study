# P146. 집중 생산 구간

2026-11-18 확인. [17기 공식 공지](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_menu_cd=&p_pageno=&p_process=select-board-view&p_seq=194&p_tabseq=226504)와 [2025년 15기 후기](https://5-ms.tistory.com/32) 참고. 전체 80분 중 1번 최초 풀이 41분을 제외하면 39분. 수정에 쓴 시간은 별도 차감한다.

N일의 일별 생산량이 주어진다. 합계가 K 이상인 비어 있지 않은 연속 구간 중 가장 짧은 것을 구한다. 동률이면 시작일이 가장 이른 구간을 선택한다. 날짜는 1부터 센다.

첫 줄 T(1~10). 각 케이스는 N K(1≤N≤100,000, 1≤K≤10^14), 다음 줄에 N개의 생산량(각 0~10^9)이 주어진다. Solution.main에서 `#케이스번호 시작일 구간길이`를 출력하고, 조건을 만족하는 구간이 없으면 `#케이스번호 -1`을 출력한다.

생산량 0 4 3 0 5 2 0에서 목표가 7이면 2~3일과 5~6일이 길이 2로 동률이므로 답은 `#1 2 2`다.

## 제출 기록

최초 15분, 수정 포함 25분(10:35~11:00). Java 21 로컬 30개 통과. 시간 O(N), 입력 포함 공간 O(N), 함수 추가 공간 O(1), 출력 버퍼 별도.
