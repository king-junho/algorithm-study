# P125. 괄호 짝짓기

- D4 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 15분
- 확인일 2026-11-13 · [SWEA 1218](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV14eWb6AAkCFAYD)

네 종류의 괄호 `()`, `[]`, `{}`, `<>`로 이루어진 문자열이 주어진다. 같은 종류끼리 짝을 이루고 괄호가 올바르게 중첩되어 있으면 1, 그렇지 않으면 0을 출력한다.

Java `Solution.main`으로 구현한다. 테스트 케이스는 10개로 고정이며 별도의 T는 없다. 각 케이스의 첫 줄에는 문자열 길이 N, 다음 줄에는 공백 없는 괄호 문자열이 주어진다. 각 답을 `#케이스번호 결과` 형식으로 출력한다.

## 자체 예시

두 케이스만 발췌했다.

```text
6
<([])>
4
([)]
```

```text
#1 1
#2 0
```

첫 케이스는 안쪽부터 각 괄호가 올바르게 닫힌다. 둘째 케이스에서는 대괄호가 닫히기 전에 소괄호가 닫힌다.
