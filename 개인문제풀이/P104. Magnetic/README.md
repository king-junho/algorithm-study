# P104. Magnetic

- 권장 시간 20분
- 확인일 2026-11-11 · [SWEA 1220](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV15FZuqAL4CFAYD)

## 문제

100×100 테이블에서 `0`은 빈칸, `1`은 아래로 이동하는 N극 자성체, `2`는 위로 이동하는 S극 자성체다. 테이블 밖으로 나간 자성체는 떨어진다. 같은 열에서 서로 마주 보며 이동하던 두 자성체가 만나면 교착 상태가 생긴다. 움직임이 모두 끝났을 때 교착 상태의 개수를 구하라.

## 입출력

Java `Solution.main`으로 구현한다. 테스트 케이스는 10개로 고정이며 맨 앞에 별도의 테스트 케이스 수가 없다. 각 케이스는 크기 `100`과 공백으로 구분된 정수 100개씩 100줄로 구성된다. 각 케이스마다 `#케이스번호 교착상태개수`를 출력한다.

## 자체 예시

한 열을 위에서 아래로 `2 1 0 2 1`이라고 하면 맨 위의 `2`와 맨 아래의 `1`은 테이블 밖으로 떨어진다. 가운데의 `1`과 `2`가 만나 교착 상태 1개가 남는다.
