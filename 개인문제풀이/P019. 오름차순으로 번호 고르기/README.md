# P019 — 오름차순으로 번호 고르기

- 출처구분:창작문제(기출아님),P018후속

- 차이:1..n에서m개선택한모든조합반환,소수판별없음
- 확인·창작일:2026-10-20 / 난이도:백트래킹기초 / 유형:재귀·조합

## 설명

1..n중서로다른m개를고르는모든방법을반환한다. 같은번호구성은순서가달라도한방법으로센다. 각결과행은엄격한오름차순이며전체행은사전순반환한다. 중복번호·중복결과불가.

## 함수·제한

`public int[][] solution(int n, int m)`

- 1≤m≤n≤6
- 각행길이m,원소1..n,오름차순
- 전체결과사전순(처음다른위치의값이작은행먼저)
- 재귀백트래킹구현

## 예시

1. n4,m2 → [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]. [2,1]은[1,2]와같은선택이므로추가하지않음.
2. n3,m3 → [[1,2,3]].
3. n3,m1 → [[1],[2],[3]].

## 제출

Java코드,풀이설명,결과저장공간포함여부를밝힌시간·공간복잡도및근거,실제풀이시간. 테스트직접제출요구없음.

- Java21 전유효21입력쌍2회반복42사례·240결과행검증. 제출동일/새객체와개선안모두통과. 독립비트마스크조합열거·사전순·행참조독립성·이전반환결과유지확인. 외부채점기없음,검증코드제외.
- K=C(n,m). 제출코드는아직for후보를n까지선택한후부족분기를함수입구에서제외한다. 안전시간상한O(n·C(n,m-1)+mK),결과제외공간O(n+m),포함O(n+m+mK). 내부유효접두사수Σ[d=0..m-1]C(n-m+d,d)=C(n,m-1),각후보반복최대n회.
- 개선안은반복상한 n-(m-depth)+1로완성불가능후보를호출전제외하고visited제거. 시간O(mK),결과제외공간O(m),결과포함O(mK+m). 출력복사mK포함,모든접두사는완성결과하나이상으로이어져탐색노드수도O(mK).
- 차이예시:m=n일때결과1개이나제출코드후보검사는n+(n-1)+...+1로O(n²). 개선안은매깊이후보1개라탐색·결과복사O(n). 두코드시간을혼동하지말것.
- 품질보완: visited는증가선택으로중복이불가능해불필요,backtrack은private권장. 설명공란의시간·공간과풀이시간은보완과제.
