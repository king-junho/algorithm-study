## 문제 요약

N×N 격자의 각 열에는 인형이 아래부터 쌓여 있다. 0은 빈칸, 1~100은 인형 종류다. moves의 열 번호를 순서대로 처리하며 해당 열의 가장 위 인형 하나를 바구니 맨 위로 옮긴다. 집은 칸은 빈칸이 된다. 빈 열이면 아무 일도 일어나지 않는다. 바구니 맨 위에 같은 종류 두 개가 연속하면 둘 다 사라진다. 사라진 인형 개수를 반환한다. moves는 1번부터 시작하는 열 번호이고 board는 위쪽 행부터 주어진다.

## 함수와 제한

`public int solution(int[][] board, int[] moves)`

- 5 ≤ N ≤ 30, 정사각형
- 칸 값 0~100, 초기 각 열 인형 사이 빈칸 없음
- 1 ≤ moves.length ≤ 1,000
- 1 ≤ moves[i] ≤ N
- 바구니 용량 제한 없음

## 공식 예시

```text
board = [[0,0,0,0,0],
         [0,0,1,0,3],
         [0,2,5,0,1],
         [4,2,4,4,2],
         [3,5,1,3,1]]
moves = [1,5,3,5,1,2,1,4]
반환 = 4
```

꺼낸 인형 순서는 4,3,1,1,3,2,없음,4다. 1 두 개와 3 두 개가 제거되어 총 4개다.
