# P073. 두 개씩 선물 포장

- 독립 창작(2026), 기출 아님. 투 포인터, D2 수준 비공식 추정.
- 개념 참고: CSES Ferris Wheel https://cses.fi/problemset/task/1090 / 확인2026-10-30, 원문 연도 미확인. 원문은 전체 수송 최소 칸 수, 이번 문제는 두 원소 포장 최대 쌍 수이며 입력·출력 조건 별도 구성.
- 권장25분. 제출 대기.

N개 물건의 무게가 주어진다. 한 선물 상자에 물건을 정확히 두 개 넣어야 하며 무게 합은 L 이하이다. 각 물건은 최대 한 번 사용한다. 남는 물건은 사용하지 않아도 된다. 만들 수 있는 선물 상자의 최대 개수를 구하라. 무게 중복 가능, 입력 정렬 보장 없음. 배치 방법의 경우의 수를 세는 문제가 아니다.

입력 T(1~10), 각 케이스 N L, 다음 줄 N개 무게. 1≤N≤100000, 1≤L≤2000000000, 1≤무게≤1000000000.
출력 #번호 최대상자개수. Java Solution/main.

입력
```
4
6 5
1 1 2 3 4 4
5 7
6 2 5 3 4
3 7
4 5 6
1 10
5
```
출력
```
#1 3
#2 2
#3 0
#4 0
```
첫째 (1,4),(1,4),(2,3). 둘째 (2,5),(3,4),6남김. 셋째 어떤 두 개도 합7이하 아님. 넷째 두 개 필요하므로 불가.
