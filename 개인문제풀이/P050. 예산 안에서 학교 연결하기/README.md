# P050. 예산 안에서 학교 연결하기

- 난이도 MST 기초 / 유형 MST·예산 판정 / 독립 창작(2026)
- 개념 참고 https://cp-algorithms.com/graph/mst_prim.html / 확인일 2026-10-27. 채용 기출·SWEA 문제 아님.
- 권장 25~35분 / 통과 95점 · 풀이 20분

1~N번 학교를 양방향 전용선으로 연결한다. M개의 후보 a b cost 중 일부를 선택해 모든 학교가 직접 또는 다른 학교를 거쳐 통신할 수 있도록 한다. 예산 B 이내에서 가능하면 최소비용을, 연결 불가능하거나 최소비용이 B보다 크면 -1을 출력한다. 비용이 B와 같으면 가능. N=1은 비용0.

입력 첫줄 T(1~10), 각 테스트 첫줄 N M B, 이어 M줄 a b cost. 1≤N≤1000, 0≤M≤min(10000,N(N-1)/2), 0≤B≤10^12, 1≤cost≤10^9, 학교번호 1~N. 자기 간선·중복 간선 없음. 연결 여부 보장 없음. Java class Solution/main. 출력 #번호 최소비용 또는 -1.

```text
입력
4
3 3 7
1 2 3
2 3 4
1 3 10
3 3 6
1 2 3
2 3 4
1 3 10
4 2 100
1 2 1
3 4 1
1 0 0

출력
#1 7
#2 -1
#3 -1
#4 0
```

첫째 최소7로 예산과 동일. 둘째 최소7로 예산6 초과. 셋째 단절. 넷째 학교 하나라 비용0. 코드·설명·시간공간복잡도·실제풀이시간 제출. 정답 및 핵심풀이 요청 전 공개하지 않음.

## 평가·검증

95점(정확성40/효율성20/품질12/경계15/설명8), 운영상 통과。Java21에서 3813개 표준입출력 케이스를 실제 실행해 독립 Kruskal 결과에 예산 조건을 적용한 정답과 모두 일치。작은 그래프 전수(간선 없음/1/10^9), 무작위300개 기반, 예산0·동일·1부족·10^12, 단절, N=1, 최대 N/M, 999×10^9 비용 합 포함。외부 채점기 미실행。

시간 O(V+E log(E+1)), 공간 O(V+E)。양수 간선이므로 누적비용의 예산 초과 조기 종료는 안전。Comparable raw type 대신 Comparable<Edge> 사용, msp→prim 또는 mst, K→budget, totalCost 주석 int→long 수정 권장。count==n은 정점 확정 직후 확인하면 불필요한 큐 poll/인접 간선 순회를 줄일 수 있음。
