# P131. 암호문1

D3 · SWEA 1228 공개 연습 · 연결 리스트·삽입 · 권장 20분

2026-11-14 확인. [SWEA 문제 원문](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV15MkhqAL4CFAYD)

암호문은 6자리 숫자들의 순서열이다. 명령 `I x y s1 ... sy`는 현재 암호문의 앞 `x`개를 지나 그 위치에 `y`개를 주어진 순서대로 삽입한다. `x = 0`이면 맨 앞에 삽입한다. 모든 명령을 적용한 뒤 앞 10개를 출력한다.

Java `Solution.main`으로 구현한다. 테스트 케이스는 10개이며 첫 줄에 별도의 T는 없다. 각 케이스는 원본 길이 N, 원본 숫자 N개, 명령 개수 C, 명령 C개 순서다. 원문 기준 10 ≤ N ≤ 20, 5 ≤ C ≤ 10. 각 결과는 `#케이스번호` 뒤에 앞 10개를 공백으로 구분해 출력한다.

자체 예시 한 케이스

```text
10
100001 100002 100003 100004 100005 100006 100007 100008 100009 100010
5
I 0 1 200001 I 3 2 200002 200003 I 13 1 200004 I 1 1 200005 I 14 1 200006
```

```text
#1 200001 200005 100001 100002 200002 200003 100003 100004 100005 100006
```

두 번째 명령에서는 당시 맨 앞의 세 숫자 바로 뒤에 `200002 200003`을 삽입한다.
