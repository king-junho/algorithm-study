# P030 — 정렬된 배열에서 값 찾기

- 출처 구분: 독립 창작 학습 문제. 특정 시험 기출 아님.
- 개념 확인 자료: https://cp-algorithms.com/num_methods/binary_search.html
- 확인일: 2026-10-23 / 출제연도2026(학습문제 작성연도)
- 난이도: 이진 탐색 입문 / 유형: 정렬 배열 값 검색
- 권장 시간: 20분 / 상태: 수정 통과95점 · 최초30분/추가시간미보고

## 문제

오름차순으로 정렬된 서로 다른 정수 배열 numbers와 정수 target이 주어진다. target이 있으면 해당 원소의 0기반 인덱스를 반환하고,없으면-1을반환한다. 배열은 이미 정렬되어 있으므로 다시 정렬하지 않는다.

`public int solution(int[] numbers, int target)`

## 제한

- 1 ≤ numbers.length ≤ 100,000
- -1,000,000,000 ≤ numbers[i], target ≤ 1,000,000,000
- numbers는 엄격한 오름차순, 중복 없음
- 직접 이진 탐색을 구현할 것. Arrays.binarySearch,indexOf,전체 선형 탐색으로 대체하지 않음.

## 예시

| numbers | target | 반환 |
| --- | --- | --- |
| [-8,-3,2,6,11,17] | 6 | 3 |
| [-8,-3,2,6,11,17] | 5 | -1 |
| [4] | 4 | 0 |
| [4] | 2 | -1 |

첫 예시 numbers[3]=6. 둘째는5없음. 단일원소도정상탐색해야함.

## 제출

Java코드,풀이설명,시간·공간복잡도와근거,실제풀이시간. 직접테스트제출요구없음. 요청전정답·범위갱신코드미공개.

## 첫 제출 피드백

Java21실행반례: [1,2,3],2→기대1/실제-1; [1,2,3,4,5,6,7],7→기대6/실제3. 동일객체상태잔존도확인. 반환계약을검색결과인덱스또는-1로정의할것. 재귀공간O(logN). 풀이30분,48점(10/20/7/5/6). 미통과,최종풀이저장없음.
