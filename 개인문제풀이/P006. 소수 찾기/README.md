## 문제 요약

문자열 numbers의 각 문자는 해당 숫자가 적힌 종이 조각 하나다. 조각을 한 개 이상 골라 원하는 순서로 이어 붙여 만들 수 있는 서로 다른 소수의 개수를 반환한다.
각 조각은 한 숫자를 만들 때 최대 한 번만 쓰며 모든 조각을 쓸 필요는 없다. 같은 숫자의 조각도 각각 주어진 개수만큼 사용할 수 있다. 앞의 0은 수의 값을 바꾸지 않으며, 같은 정수는 한 번만 센다. 소수는 1보다 크고 양의 약수가 1과 자기 자신뿐인 정수다.

## 함수와 제한

`public int solution(String numbers)`

- 1 ≤ numbers.length() ≤ 7
- 각 문자는 0~9
- 서로 다른 소수의 개수를 int로 반환

## 예시

- "17" → 3. 만들 수 있는 소수는 7,17,71.
- "011" → 2. 만들 수 있는 소수는 11,101. 011과 11은 같은 정수.

## 제출

Java 코드, 모든 후보를 빠짐없이 다루는 이유를 포함한 풀이 설명, 시간·공간 복잡도와 근거, 직접 만든 테스트 2개 이상의 예상값·실행 여부, 실제 풀이 시간.
