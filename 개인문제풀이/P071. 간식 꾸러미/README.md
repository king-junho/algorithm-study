# P071. 간식 꾸러미

- 독립 창작(2026), 기출 아님. SWEA D2 수준 비공식 추정.
- 유형: 복습을 위해 제출 전 비공개.
- 개념 참고: https://usaco.guide/silver/two-pointers (확인 2026-10-30). 문제 문장은 독립 작성.
- 권장 시간: 25분. 제출 대기.

N개의 간식 봉지가 일렬로 놓여 있고 각 봉지의 가격이 주어진다. 연속된 봉지만 선택할 수 있다. 가격 합이 예산 B 이하가 되도록 선택할 수 있는 최대 봉지 수를 구하라. 순서 변경과 중간 봉지 제외는 불가능하다. 하나도 살 수 없으면 0이다.

입력: T, 각 테스트 케이스 N B, 이어서 N개 가격.
제한: 1≤T≤10, 1≤N≤100000, 1≤B≤10^9, 1≤가격≤100000.
출력: #테스트번호 최대봉지수. Java Solution/main.

입력
```
3
6 5
2 1 1 3 2 1
4 3
4 5 6 7
5 5
1 1 1 1 1
```
출력
```
#1 3
#2 0
#3 5
```
첫째 첫 세 봉지 합4, 연속 네 봉지는 모두 예산 초과. 둘째 한 봉지도 불가능. 셋째 전체 선택 가능.
