# P117. 백만 장자 프로젝트

- D2 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 20분
- 확인일 2026-11-13 · [SWEA 1859](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV5LrsUaDxcDFAXc)

N일 동안의 물건 가격을 미리 알고 있다. 하루에 최대 한 개를 살 수 있고, 가진 물건은 원하는 만큼 팔 수 있다. 아무 거래도 하지 않아도 된다. 얻을 수 있는 최대 이익을 구한다.

Java `Solution.main`으로 구현한다. 첫 줄에 테스트 케이스 수 T가 주어진다. 각 케이스는 첫 줄의 N과 다음 줄의 가격 N개로 이루어진다. 2 ≤ N ≤ 1,000,000이며 각 가격은 10,000 이하다. 각 답을 `#케이스번호 최대이익` 형식으로 출력한다.

## 자체 예시

```text
2
5
3 1 5 2 4
3
9 7 2
```

```text
#1 8
#2 0
```

첫 케이스에서는 1일과 2일에 산 물건을 3일에 팔아 6을 얻는다. 4일에 산 물건을 5일에 팔아 2를 더 얻는다. 둘째 케이스에서는 거래하지 않을 때 최대 이익이 0이다.
