# P135. 중위순회

D4 · SWEA 1231 공개 연습 · 이진 트리 순회 · 권장 20분

2026-11-14 확인. [SWEA 문제 원문](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV140YnqAIECFAYD)

완전 이진 트리의 각 노드에 알파벳 하나가 있다. 루트 1에서 시작해 각 서브트리를 왼쪽 서브트리, 현재 노드, 오른쪽 서브트리 순으로 읽고 이어 붙인다.

Java Solution.main으로 구현한다. 테스트는 10개 고정이며 별도 T가 없다. 각 테스트에서 노드 수 N(1 ≤ N ≤ 100)을 읽고 다음 N줄을 노드 번호, 문자, 있으면 왼쪽 자식 번호, 있으면 오른쪽 자식 번호 순으로 읽는다. 각 결과는 #케이스번호 문자열 형식이다.

자체 예시 한 케이스

```text
5
1 D 2 3
2 B 4 5
3 E
4 A
5 C
```

```text
#1 ABCDE
```

왼쪽 서브트리는 ABC, 루트는 D, 오른쪽 서브트리는 E다.

## 제출 결과

25분, 92점. 노드 수 1~100의 Java 로컬 테스트 100개 중 실패 0개.
