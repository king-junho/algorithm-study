# P106. 지그재그 숫자

## 문제

1부터 N까지 홀수는 더하고 짝수는 뺀 결과를 구한다. N은 1 이상 10 이하의 정수다.

## 입출력

Java `Solution.main`으로 구현한다. 첫 줄에 테스트 케이스 수 T가 주어진다. 이후 케이스마다 N이 한 줄에 주어진다. 각 답을 `#케이스번호 결과` 형식으로 출력한다.

## 자체 예시

```text
2
3
8
```

```text
#1 2
#2 -4
```

N이 3이면 1 − 2 + 3 = 2다. N이 8이면 1 − 2 + 3 − 4 + 5 − 6 + 7 − 8 = −4다.
