# P043 — 계단을 오르는 방법

- 출처구분:독립창작학습문제,실제시험기출/SWEA공식문제아님。
- 개념확인 https://cp-algorithms.com/dynamic_programming/intro-to-dp.html 。확인일2026-10-26,학습문제작성연도2026。
- 난이도:DP첫입문(공식D등급없음) / 유형:경우수DP·이전결과재사용
- 권장시간25분 / 상태:통과96점 · 풀이10분

## 문제

0번째바닥에서N번째계단까지올라간다。한번에1칸또는2칸만이동하고뒤로이동불가。정확히N번째에도착하는방법수를구한다。이동순서가다르면다른방법이다。

## 입출력·제한

첫줄T(1~10),테스트마다N(1~40)。출력 #번호 방법수。이범위정답int저장가능。Java전체코드,class Solution,package없음。

## 예시

```text
입력
4
1
2
4
5

출력
#1 1
#2 2
#3 5
#4 8
```

N4는1+1+1+1,1+1+2,1+2+1,2+1+1,2+2。

## 학습목표·제출

재귀로모든이동경로를직접열거하는것대신배열에계산결과저장·재사용하는DP로구현。dp[i]에무엇을저장하는지한문장정의부터해볼것。전체코드,풀이설명,시간공간복잡도와근거,실제풀이시간。직접테스트제출요구없음。정답코드·점화식요청전미공개。

## 제출 통과 — 2026-10-26

- 96/100(정확성40/효율성20/품질14/경계15/설명7),풀이10분.
- Java21제출과개선배열버전각180사례를T≤10인18회main표준입출력실행. N1~40전체·역순·고정시드무작위100. 독립조합식ΣC(N-t,t)와일치. N40정답165580141로int안전. 외부채점기미실행,검증소스제외.
- dp[i]는i번째계단정확도착방법수. 마지막이동1칸이면dp[i-1],2칸이면dp[i-2],두경우겹치지않아합산. N1/2분기와배열점화구현정확.
- 시간O(N),공간O(N)정확. 주석N=N-1+N-2는값자체등식이아니고dp[i]=dp[i-1]+dp[i-2]로정정,상태정의와마지막이동근거보완. 미사용result제거가능.
- 개선예시countWays함수분리,dp[0]=1(아무이동안하는방법하나),dp[1]=1,2부터점화로작은입력분기제거. 사용자제출은보존. 더나중에는직전두값만저장해보조공간상수화가능하나입문은배열유지.
