# P078. 정확히 고르는 간식

- 독립 창작(2026), 기출 아님. 백트래킹·조합, D2~D3 수준 비공식 추정. 권장30분, 제출 대기.
- 공개 개념 참고: CSES Apple Division https://cses.fi/problemset/task/1623 확인2026-10-30. 원문은 두 그룹 합 차이 최소화, 이번 문제는 정확히 M개/목표합의 선택 수로 별도 창작. 원문 출제 연도 미확인.

가격이 주어진 N개 간식 중 정확히 M개를 골라 가격 합이 K가 되는 선택 방법 수를 구하라. 각 간식은 최대 한 번 사용. 순서는 무시. 같은 가격이라도 위치가 다르면 다른 간식. 연속 선택 조건 없음. 불가능0.

입력 T(1~10), 각케이스 N M K, 다음줄 N개 가격. 1≤M≤N≤20, 1≤가격≤1000000000, 1≤K≤20000000000. 출력 #번호 방법수. Java Solution/main.

입력
```
3
5 2 6
1 2 3 4 5
4 2 4
2 2 2 2
3 2 10
1 2 3
```
출력
```
#1 2
#2 6
#3 0
```
첫째1+5,2+4. 둘째서로다른위치두개선택: (1,2),(1,3),(1,4),(2,3),(2,4),(3,4). 셋째불가. 코드/재귀함수역할/시간공간복잡도/풀이시간 제출. 정답·핵심풀이 비공개.


## 2026-10-30 — P078 첫 제출: 수정 대기

- 15분(18:35~18:50), 잠정71점(정확성30/효율성17/품질11/테스트·경계6/설명7).
- Java21 실제 예시3개는2/6/0으로 일치. 경계입력 N=3 M=3 K=3000000000, 가격각1000000000은 기대1이나 nextInt()에서 InputMismatchException 발생. k는long, 입력nextLong 필요. sum만long으로 두어서는 입력범위 해결 안 됨.
- 재귀 반환1/0 및 count 누적, 다음인덱스 i+1로 순서 중복 제거 정확. 이는 중복 없는 인덱스 조합이며 가격 중복 허용과 별개. 호출수 sum(d=0..M) C(N,d), 시간O(해당 합)≤O(2^N), M=N이면 실제2^N(남은 개수 가지치기 없음). 말단수C(N,M)만으로 전체 호출비용을 판단하면 안 됨. 호출깊이O(M), 입력포함공간O(N+M)=O(N).
- visited는 사용하지 않으며 증가 인덱스로 재사용 방지. 불필요import/방문처리 주석 제거 권장. 현재 사용자 요청 전 전체정답 미제공, 큰목표형 수정 유도. 완료풀이 저장/커밋/푸시 없음.


## 2026-10-30 — P078 수정 통과

- 92점(정확성40/효율성18/품질12/테스트·경계15/설명7). 최초15분, 추가수정시간 미보고. k와입력long 수정으로 범위 오류 해결. 재귀반환값 합산과 증가 인덱스 조합 구조 정확.
- Java21 제출 코드 실제7,007사례 통과: 값1~3 길이1~6 중복조합/모든M/목표1~18 전수6,804, 무작위200, 최대경계3(N20 전체선택200억/모두1 M10 정답184756/불가). 독립 인덱스 조합 나열 정답 대조. 같은검증으로 남은개수·양수합 가지치기 개선안도 별도실행통과. 공개채점기 미실행.
- 제출 시간은 sum(d=0..M) C(N,d) 호출에 비례, 최악O(2^N). 호출스택O(M), 입력포함O(N). 최대출력C(20,10)=184756이므로int안전. 개선안은 남은간식수<필요수면0, 반복끝을N-필요수로 제한, depth<M이며sum>=K면양수가격으로불가종료. 가지치기에도 일반적 최악상한O(2^N) 유지, N=M 등에서 크게감소.
- 주석 N!/중복조합/visited와 불필요import 정정 필요. 반환형재귀 구조는 개선됐으나 전체호출수와완성선택수 구분 학습 필요. P076/P077보류유지. 총67문제통과, 자동다음출제없음.
