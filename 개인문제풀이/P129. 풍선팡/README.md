# P129. 풍선팡

- SWEA 공개 사용자 문제 9490 · D2 · 격자·방향 탐색 · 권장 15분
- 확인일 2026-11-14 · [SWEA 사용자 문제 목록](https://swexpertacademy.com/main/code/userProblem/userProblemList.do?orderBy=INQUERY_COUNT&pageIndex=1&pageSize=30&problemTitle=&select-1=)

N행 M열에 풍선이 하나씩 있고, 각 풍선에는 꽃가루가 들어 있다. 꽃가루가 K개인 풍선을 고르면 그 풍선과 상하좌우 각 방향으로 K칸까지의 풍선이 터진다. 격자 밖은 제외하고, 추가로 터진 풍선에서 꽃가루 수만큼 다시 퍼지지는 않는다. 한 번 골랐을 때 얻을 수 있는 최대 꽃가루 수를 구한다.

Java Solution.main으로 구현한다. 첫 줄에 T, 각 케이스에 N M과 N줄의 격자가 주어진다. 이 연습의 제한은 3 ≤ N, M ≤ 100, 칸당 꽃가루 1~5개다. 각 케이스는 #케이스번호 최댓값 형식으로 출력한다.

예시 입력

```text
1
3 4
3 1 1 1
1 2 1 1
1 1 1 1
```

예시 출력

```text
#1 8
```

왼쪽 위 풍선을 고르면 중심 3개, 오른쪽 3개, 아래쪽 2개를 얻는다.
