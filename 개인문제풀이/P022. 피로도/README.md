- 출처 구분: 일반 공개 연습 문제. 특정 카카오·SSAFY 기출로 분류하지 않음.

## 문제 요약

초기 피로도 k와 던전 목록이 주어진다. dungeons[i]=[최소 필요 피로도,소모 피로도]다. 현재 피로도가 최소 필요 피로도 이상이어야 입장할 수 있으며, 탐험 후 소모 피로도만큼 현재 값이 감소한다. 각 던전은 최대 한 번 탐험하고 순서는 자유다. 탐험할 수 있는 던전 수의 최댓값을 반환한다. 최소 필요 피로도는 입장 조건이지 차감량이 아니다.

## 함수와 제한

`public int solution(int k, int[][] dungeons)`

- 1≤k≤5,000
- 던전 개수1~8, 각 행 길이2
- 1≤소모 피로도≤최소 필요 피로도≤1,000
- 값이 같은 행도 서로 다른 던전
- 아무 던전도 탐험할 수 없으면0
- 이번 학습에서는 재귀 DFS·백트래킹으로 구현

## 예시

1. 공식 예시: k80,dungeons=[[80,20],[50,40],[30,10]] →3. 0→2→1 순서에서 남은 값80→60→50→10. 0→1→2 순서면 마지막 입장 조건 미충족.
2. 추가 학습 예시: k10,dungeons=[[20,5],[15,10]] →0. 처음부터 어느 곳도 입장 불가.

## 제출

Java 코드, 풀이 설명, 던전 수를 정의한 시간·공간 복잡도와 근거, 실제 풀이 시간. 직접 테스트 제출 요구 없음.
