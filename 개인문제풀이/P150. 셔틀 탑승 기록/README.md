# P150. 셔틀 탑승 기록

2026-11-18 확인. [17기 공식 공지](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_menu_cd=&p_pageno=&p_process=select-board-view&p_seq=194&p_tabseq=226504)의 80분과 [2025년 15기 응시 후기](https://5-ms.tistory.com/32)의 순차 공개를 참고했다. 1번 권장 30분. 모의 기준에 도달하면 2번 공개. 상세 결과는 회차 종료 후 공개.

승객은 도착 시각의 비내림차순이며 같은 시각은 입력 순서다. 셔틀도 출발 시각의 비내림차순이며 같은 시각은 입력 순서다. 출발 시각까지 도착해 아직 탑승하지 않은 승객 중 우선 승객 E를 도착 순서로 최대 P명 태운 뒤, 남는 자리를 등급과 무관하게 도착 순서로 채운다. 출발 시각과 도착 시각이 같아도 탑승할 수 있다.

첫 줄 T(1~10). 케이스마다 N M(각 1~500), 승객 N줄에 도착 시각 A와 등급 E/G, 셔틀 M줄에 출발 시각 D, 정원 C(1~500), 우선 인원 한도 P(0≤P≤C). 시각은 0~10^9 정수. Solution.main에서 `#케이스번호 탑승인원 미탑승인원 최대대기시간`을 출력한다. 대기시간은 탑승한 셔틀의 출발 시각 빼기 도착 시각이다. 탑승자가 없으면 최대 대기는 0이다.

```text
1
7 3
0 G
1 E
2 G
2 E
3 G
4 E
7 G
2 3 1
4 2 1
6 1 0
```

