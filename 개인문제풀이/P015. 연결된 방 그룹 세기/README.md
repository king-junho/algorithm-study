# P015 — 연결된 방 그룹 세기

- 출처 구분: 공개 연습 문제 변형(기출 아님)
- 참고: https://school.programmers.co.kr/learn/courses/30/lessons/43162
- 원문과의 차이: 컴퓨터 연결행렬 대신 방별 이웃목록,재귀DFS 학습조건 추가. 그룹수 목표는 동일.
- 확인·작성일:2026-10-19 / 특정시험 출제연도 미확인
- 난이도:DFS 기초+ / 유형:재귀DFS·연결요소
- 권장시간:25분 / 상태: 로컬 검증 통과 · 98/100 · 10분

## 설명

rooms[i]는 i번방과 직접 연결된 방 목록이다. 직접또는여러방을거쳐 연결되면 같은그룹이다. 전체방이 몇개의 독립된그룹으로 나뉘는지 반환한다. 고립된방도 하나의그룹이며 모든방은 정확히 하나의그룹에 속한다. 시작방 매개변수는 없다.

## 함수·제한

`public int solution(int[][] rooms)`

- 방수1~20,번호0..rooms.length-1
- 양방향문,양쪽연결정보 제공
- 자기연결·목록내중복없음,빈목록·순환가능
- 목록순서임의
- 재귀DFS 구현,보조메서드가능

## 예시

1. rooms=[[1],[0,2],[1],[4],[3],[]] →3. {0,1,2},{3,4},{5}.
2. rooms=[[1,2],[0,2],[0,1]] →1. 세방모두연결.
3. rooms=[[],[],[]] →3. 각방독립.

## 최종 평가

- 정확성40/40, 효율성20/20, 품질14/15, 경계15/15, 설명9/10 =98/100,10분.
- [P015.java](P015.java): 제출로직과공개메서드 유지, 클래스·공백·중괄호 정리.
- Java21 실제34,870개 입력을 동일·새인스턴스로 각각 실행해 모두통과(총69,740호출). n≤6 모든단순무방향그래프33,867개, 무작위1,000(n≤20), n20완전연결·고립·일렬3. 이웃목록순서무작위, 독립union-find로그룹수비교, 입력불변. 외부채점기없음,검증코드제외.
- 정확성: 미방문시작점1개당그룹1증가, DFS가그그룹의모든방방문표시. 다음반복에서동일그룹중복카운트없음. 재귀입구visited검사는유효한정석패턴.
- 시간O(V+E): 바깥V검사,각방연결목록1회확장,문하나양방향총2회재귀호출. 이미방문한방호출은O(1)반환. 바깥반복마다그래프전체를재탐색하지않음.
- 추가공간O(V): visited와최대V깊이재귀스택. 호출총횟수O(V+E)와동시쌓이는호출깊이O(V)를구분할것.
- 품질보완: dfs는private권장. index→current, 향상된for문가능. 재귀호출전visited검사로불필요호출감소가능하나필수아니며최악복잡도동일.
