# P061. 시간 안에 배달하기

- 유형:다익스트라 기본응용 / 난이도:입문다음단계(공식SWEA등급없음)
- 독립창작(2026),개념참고 https://cp-algorithms.com/graph/dijkstra.html /확인2026-10-29. 공개기출이나등록문제아님.
- 권장30분/제출대기

1~N번마을,M개양방향도로. 출발S에서각목적지까지의최소이동시간이K이하인마을수를구한다. 출발마을포함. 각배달은S에서따로출발하고왕복하지않는다.한경로로여러마을을돌며K를나누는문제아님. 도달불가제외,시간정확히K허용.

입력T(1~10),각케이스N M S K,이후M줄a b time.1≤N≤1000,0≤M≤min(10000,N(N-1)/2),1≤S≤N,0≤K≤1000000000000,1≤time≤1000000000.자기도로/중복도로없음.출력 #번호 마을수. Java class Solution/main.

```text
입력
3
5 5 1 6
1 2 5
1 3 2
3 2 1
2 4 3
3 4 10
3 1 1 0
1 2 4
1 0 1 100

출력
#1 4
#2 1
#3 1
```

첫째최소시간0,3,2,6,도달불가로4개.둘째출발지만0.셋째출발지만존재. 코드/설명/복잡도/실제풀이시간제출. 정답및핵심풀이요청전미공개.
