# P046 — 이웃하지 않게 보상 고르기

- 출처구분:독립창작학습문제,실제평가기출/SWEA공식문제아님。

- 난이도:DP기초 / 유형:1차원DP·최댓값·선택제약
- 권장시간30분 / 상태:수정 통과85점 · 풀이시간미보고

## 문제

일렬로놓인N개상자에보상이있다。원하는상자를골라보상합을최대로만들되바로이웃한두상자는동시에고를수없다。각상자는최대한번,아무것도선택하지않아도됨。원형아니므로첫상자와마지막상자는N>2일때인접하지않음。최대합만출력。

## 입출력·제한

첫줄T(1~10),각케이스첫줄N(1~10000),다음줄N개보상(0~1000)。출력 #번호 최대합。Java전체코드,class Solution,package없음。DP로구현,모든부분집합열거방식은크기제한부적합。

## 예시

```text
입력
4
4
1 3 1 5
5
2 7 9 3 1
3
4 5 4
1
0

출력
#1 8
#2 12
#3 8
#4 0
```

첫째2번/4번상자3+5。둘째1/3/5번2+9+1。셋째1/3번4+4,가운데5하나보다큼。넷째최대0。

## 제출

전체코드,dp[i]의의미,이전결과를고르는근거·초깃값,시간공간복잡도,실제풀이시간。직접테스트제출요구없음。정답·점화식요청전미공개。
