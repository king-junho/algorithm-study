# P064. 보급소를 거쳐 배송하기

- 독립창작(2026),기초응용,유형비공개.
- 참고 https://cp-algorithms.com/graph/dijkstra.html 및 https://cp-algorithms.com/graph/mst_prim.html /확인2026-10-29.실제기출아님.
- 권장35분/제출대기

N개마을,M개양방향도로. S출발,P보급소를적어도한번방문한뒤D도착하는최소이동시간. 경로상같은마을/도로반복가능하고통과할때마다시간지불. P의작업시간0. S/P/D같아도가능(처음부터P에있으면방문완료,목적지와S가같아도P방문후복귀필요). 경로불가-1.

입력T(1~10),각케이스N M S P D,이어M줄a b time.1≤N≤1000,0≤M≤min(10000,N(N-1)/2),1≤S,P,D,a,b≤N,1≤time≤10^9.자기간선/중복없음.출력 #번호 최소이동시간. Java class Solution/main.

```text
입력
3
4 4 1 3 4
1 2 2
2 3 3
3 4 4
1 4 1
3 1 1 2 3
1 3 5
1 0 1 1 1

출력
#1 9
#2 -1
#3 0
```

첫째1→2→3→4총9,1→4→3→4도9.목적지를먼저통과할수있지만보급소방문후다시D에도착해야함.둘째P2에갈수없음.셋째모두동일0.코드/선택기법근거/복잡도/실제시간제출.핵심풀이요청전비공개.
