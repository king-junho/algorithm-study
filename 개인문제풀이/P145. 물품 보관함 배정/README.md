보관함은 1번부터 N번까지이고 각각 고정된 크기가 있다. 요청 (t, s, d)는 시각 t에 크기 s인 물품을 d만큼 보관한다는 뜻이다. 해당 시각까지 사용이 끝난 보관함은 즉시 사용 가능하다. 빈 보관함 중 크기가 s 이상인 보관함을 골라야 한다. 크기가 가장 작은 곳을 우선하고, 그 크기가 같으면 번호가 가장 작은 곳을 사용한다. 배정하면 t+d에 비워진다. 배정할 수 없으면 요청을 거절한다. 같은 시각의 요청은 입력 순서로 처리한다.

첫 줄은 T(1~10). 각 케이스는 N Q(1≤N≤100, 1≤Q≤1,000), 보관함 크기 N개, 요청 t s d가 적힌 Q줄이다. 시각 t는 0~100,000의 정수이며 비내림차순이다. 보관함 크기와 s는 1~100, d는 1~1,000이다.

Solution.main에서 `#케이스번호 거절횟수 가장많이사용된보관함번호`를 출력한다. 사용 횟수가 같으면 번호가 작은 쪽, 모든 요청이 거절되면 번호는 0이다.

```text
1
3 6
2 1 2
0 2 3
0 1 2
1 1 2
1 1 1
2 1 2
3 2 1
```

```text
#1 1 1
```

배정 순서는 1, 2, 3, 거절, 2, 1이다. 1번과 2번 보관함이 두 번씩 사용됐다.

## 제출 기록

최초 41분, 수정 시간 미확인. Java 21 로컬 32개 통과. 케이스당 시간 상한 O(N log N + Q log Q + NQ), 공간 O(N+Q).
