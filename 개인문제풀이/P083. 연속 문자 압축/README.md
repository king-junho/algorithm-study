# P083. 연속 문자 압축

- D2 수준 추정. 유형은 문자열 처리. 권장 20분.
- [LeetCode 443](https://leetcode.com/problems/string-compression/)의 공개 연습 문제를 2026-11-09에 확인했다. 원문 출제 연도는 미확인이다. 연속 문자 압축 규칙을 유지하고 문자열 출력, 제한, 예시, SWEA 입출력 형식을 별도로 구성했다.

같은 문자가 연속해서 등장하는 구간을 한 묶음으로 본다. 각 묶음을 문자 하나로 적고, 길이가 2 이상이면 바로 뒤에 길이를 붙인다. 묶음은 원래 순서대로 기록한다.

첫 줄에 T, 이어서 케이스마다 문자열 S가 한 줄씩 주어진다. 1 ≤ T ≤ 10, 1 ≤ S의 길이 ≤ 100,000. S는 공백 없이 영문 소문자로만 구성된다. 케이스마다 `#번호 압축문자열`을 출력한다.

입력 예시

```text
3
aaabbccccaa
abc
zzzzzzzzzzq
```

출력 예시

```text
#1 a3b2c4a2
#2 abc
#3 z10q
```

첫째에서 처음과 끝의 a는 서로 다른 묶음이다. 둘째의 모든 묶음 길이는 1이다. 셋째는 z 열 개 뒤에 q 하나가 나온다.

Java `Solution` 클래스의 `main`으로 작성한다. 풀이 설명, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
