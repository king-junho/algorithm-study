시각0에N개인쇄작업이모두준비된다.프린터한대는한번에한작업만처리,시작한작업중단불가.작업순서를자유롭게정하고모든작업을완료해야한다.완료시각은시각0부터그작업종료까지의시간.모든작업의완료시각합최솟값을구하라.우선순위/도착시각차이/준비시간없음.총실제인쇄시간이아닌각완료시각합.

입력T(1~10),각케이스N,다음줄N개인쇄소요시간.1≤N≤100000,1≤시간≤1000000. 출력 #번호 최소완료시각합. Java class Solution/main.
