# P153. 연속 3일 학습 기록

투 포인터 · 독립 창작 · 비공식 SWEA D2 추정 · Java · 권장 15분 · 로컬 통과

2026-11-19. P152의 구간 확장·축소를 보완하는 고정 길이 연습이다.

N일 기록에서 1은 학습한 날, 0은 학습하지 않은 날이다. 연속된 정확히 3일을 골라 그 안에서 학습한 날 수의 최댓값을 구한다.

첫 줄 T(1~10). 케이스마다 N(3~100,000), 다음 줄에 기록 N개가 주어진다. Solution.main에서 #케이스번호 최대학습일수를 출력한다.

예시 기록 1 0 1 0 0 1 1의 답은 2다.

## 제출 기록

5분(14:30~14:35). Java 21 로컬 2042개 통과. 96점. 시간 O(N), 입력 포함 공간 O(N), 함수 추가 공간 O(1).
