# P026 — 숫자의 표현

- 출처 구분: 일반 공개 연습 문제. 특정 채용·SSAFY 기출 아님.
- 공식 출처: https://school.programmers.co.kr/learn/courses/30/lessons/12924
- 확인일: 2026-10-22 / 특정 시험 출제 연도: 미확인
- 난이도: 투 포인터 입문(학습용) / 유형: 연속 구간 합·투 포인터
- 권장 시간: 25분 / 상태: 학습 통과98점 · 수정 풀이10분

## 문제 요약

양의 정수 n을 하나 이상의 연속된 양의 정수의 합으로 나타내는 방법 수를 반환한다. 0과 음수는 포함하지 않으며 n 하나만 사용하는 경우도 센다. 이 학습에서는 투 포인터 방식으로 구현한다. 공식 문제의 조건을 추가로 변경하지 않는다.

## 함수와 제한

`public int solution(int n)`

- 1 ≤ n ≤ 10,000
- 반환: 조건을 만족하는 서로 다른 연속 구간의 개수

## 예시

- 공식: n=15 → 4. 1+2+3+4+5, 4+5+6, 7+8, 15.
- 학습용 추가: n=1 → 1. 1 하나만 가능.
- 학습용 추가: n=9 → 3. 2+3+4, 4+5, 9.

## 제출

Java 코드, 풀이 설명, 시간·공간 복잡도와 근거, 실제 풀이 시간. 직접 테스트 제출 요구 없음. 정답 코드·포인터 이동 규칙은 요청 전 공개하지 않는다.

## 최종 제출 평가 — 2026-10-22

- 98/100: 정확성40/40, 효율성20/20, 코드품질14/15, 테스트·경계15/15, 설명9/10. 학습 통과, 수정 풀이 시간10분(이전 이중 반복문 풀이 시간 미보고).
- Java21 실제 전 입력 n=1~10,000을 동일·새 객체로 실행, 독립 등차수열 식 기준 구현과 모두 일치. 외부 채점기는 실행하지 않음. 검증 파일 저장소 제외.
- sum은 [left,right] 합으로 유지하며 같으면 계수, 이상이면 왼쪽 제거, 미만이면 오른쪽 확장. 양수 조건을 이용한 이동 정확.
- right==n이면서 sum<n인 상태는 현재 입력에서 도달하지 않음: left≤n이면 구간은 n을 포함해 sum≥n. left가 n+1이면 반복 종료. 따라서 else 내부에 동작 없는 분기가 있어도 무한 루프 없음. 일반 배열 문제에 그대로 적용할 때는 별도 종료 검토 필요.
- 시간O(n): 각 포인터가 최대n회 전진. 공간O(1). 기존 이중 반복문 주석은 삭제하고 현재 구현 설명만 유지할 것. 합과 구간의 관계 및 포인터 총 이동 횟수를 설명에 보완할 것.
