# P028 — 구명보트

- 출처 구분: 일반 공개 연습, 특정 카카오·SSAFY 기출로 분류하지 않음
- 공식 출처: https://school.programmers.co.kr/learn/courses/30/lessons/42885
- 확인일: 2026-10-22 / 특정 시험 출제 연도 미확인
- 난이도: 투 포인터 기초 응용(그리디 도입) / 유형: 정렬·양끝 투 포인터·그리디
- 권장 시간: 35분 / 상태: 학습 통과95점 · 풀이40분 초과

## 문제 요약

몸무게 배열 people의 모든 사람을 구명보트로 구출한다. 보트 한 대에는 최대2명, 합산 무게는 limit 이하만 가능하다. 한 명만 타도 된다. 모든 사람을 정확히 한 번 태우는 데 필요한 최소 보트 수를 반환한다. 배열에서 이웃한 사람끼리만 탈 필요는 없다. 이번에는 투 포인터를 활용한다.

`public int solution(int[] people, int limit)`

## 제한

- 1 ≤ people.length ≤ 50,000
- 40 ≤ people[i] ≤ 240
- 40 ≤ limit ≤ 240
- 공식 안내: limit는 가장 무거운 사람보다 크게 주어져 모두 구출 가능
- 최대2명 조건은 합산무게 조건과 별도로 적용

## 공식 예시

| people | limit | 반환 |
| --- | --- | --- |
| [70,50,80,50] | 100 | 3 |
| [70,80,50] | 100 | 3 |

첫 예시는50과50을함께,70과80은각자타서3대. 둘째는어떤두사람도함께탈수없어3대.

## 제출

Java코드,풀이설명,시간·공간복잡도와근거,실제풀이시간. 선택방법이최소보트수를보장하는이유도설명할것. 직접테스트제출요구없음. 정답·핵심이동규칙은요청전공개하지않음.

## 제출 평가 — 2026-10-22

- 95/100: 정확성40/40, 효율성20/20, 코드품질12/15, 테스트·경계15/15, 설명8/10. 학습 통과, 풀이 시간40분 초과(정확한 분 미보고).
- Java21 실제9,151입력. 제출 동일·새 객체와 오름차순 개선안 모두 통과. 공식2, 길이1~9·무게40/50/60/80/120의 다중집합과유효제한 전수, 무작위3,000, 최대50,000명3개,단일인원2개. 작은입력은 부분집합DP로 모든 단독·쌍 선택을 비교한 독립 최적값과 비교했다. 최대입력은 명시적 기대값. 입력불변. 외부채점기는 실행하지 않았다. 검증소스 제외.
- 내림차순에서left최대,right최소 처리 정확. 한명남으면 동일인원무게를두번합산하지만 어느분기든보트한대를세고종료하여정답에영향없음. 합==limit,전원단독,전원짝,홀수인원도정확.
- 시간O(N log N): boxing O(N),객체배열정렬O(N log N),unboxing O(N),탐색O(N). 추가공간O(N): Integer배열·박싱객체·새int배열·정렬보조공간,동시에선형규모. 원래배열은변경없음.
- 개선: int[]오름차순정렬을사용하고left최소,right최대로역할변경. result++공통화,한명남으면짝비교생략. 투포인터자체보조공간O(1),전체공간은정렬구현보조공간및입력복사여부를별도고려할것.
- 그리디근거보완: 최대+최소가초과하면최대는누구와도못타므로단독필수. 함께탈수있으면둘을묶는최적해가존재한다. 각각의다른짝a,b가있던최적해도최소+최대, a+b로바꿀수있다(최대+a≤limit이고 b≤최대이므로 a+b≤limit). 단독인경우도보트증가없이교환가능.
