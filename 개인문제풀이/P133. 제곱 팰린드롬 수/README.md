# P133. 제곱 팰린드롬 수

D3 · SWEA 10570 공개 연습 · 완전탐색·회문 · 권장 20분

2026-11-14 확인. [SWEA 문제 원문](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AXO72aaqPrcDFAXS)

A 이상 B 이하인 정수 중 그 수와 그 수의 양의 정수 제곱근이 모두 팰린드롬인 수의 개수를 구한다. 팰린드롬은 십진수로 앞뒤 어느 쪽에서 읽어도 같은 수다.

Java Solution.main으로 구현한다. 첫 줄에 테스트 케이스 수 T, 이어서 T줄에 A B가 주어진다. 1 ≤ A ≤ B ≤ 1000. 각 케이스에 #케이스번호 개수를 출력한다.

예시 입력

```text
2
1 10
10 150
```

예시 출력

```text
#1 3
#2 1
```

첫 구간에는 1, 4, 9가 해당한다. 둘째 구간에는 제곱근이 11인 121이 해당한다.

## 제출 결과

13분(21:30~21:43), 94점. 가능한 입력 구간 500,500개를 실행해 실패 0개를 확인했다.
