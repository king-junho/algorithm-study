# P018 — 중복 없이 번호 나열하기

- 출처구분:창작문제(기출아님)
- 참고:https://school.programmers.co.kr/learn/courses/30/lessons/42839 (숫자조각을골라순서대로배치하는개념참고)
- 차이:1..n의서로다른번호,m개길이고정,소수판별없이모든수열반환
- 확인·창작일:2026-10-20 / 난이도:백트래킹입문 / 유형:재귀·순열·선택복원
- 권장시간:25분 / 상태: 로컬 검증 통과 · 93/100 · 15분

## 설명

1부터n까지번호중서로다른m개를골라순서대로나열하는모든수열을반환한다. 한수열에서같은번호는재사용할수없지만다른수열에서는다시사용할수있다. 순서가다르면다른수열이다. 중복결과없이사전순으로반환한다.

## 함수·제한

`public int[][] solution(int n, int m)`

- 1≤m≤n≤6
- 각행은길이m,값1..n,행안에서중복없음
- 사전순:첫번째로다른위치의숫자가작은행이먼저
- 재귀백트래킹구현

## 예시

1. n3,m2 → [[1,2],[1,3],[2,1],[2,3],[3,1],[3,2]]. [1,1]불가,[1,2]와[2,1]은다른수열.
2. n3,m1 → [[1],[2],[3]].
3. n2,m2 → [[1,2],[2,1]].

## 제출

Java코드,풀이설명(선택과복원포함),시간·공간복잡도와근거(결과저장공간포함여부명시),실제풀이시간. 직접테스트제출요구없음.

## 최종 평가

- 정확성40/40,효율성20/20,품질13/15,경계15/15,설명5/10 =93/100,15분. 첫 제출정답.
- [P018.java](P018.java): 제출필드·재귀·스트림복사로직유지,클래스·import·서식정리.
- Java21에서전범위21개(n,m)쌍을2회반복한42사례,4,730결과행검증. 제출은동일·새객체각각,개선안은동일객체로검증. 독립n진수완전열거로기대값생성,사전순·각수열내용·행배열객체독립성·이후호출에도이전결과유지확인. 외부채점기없음,검증파일제외.
- 핵심: 선택→재귀→visited복원·마지막선택제거 정확. 종료시스트림toArray로새배열복사하여결과공유오류없음. 모든필드를매solution호출초기화해반복호출안전.
- K=P(n,m)=n!/(n-m)!개수열. 결과복사포함시간O(mK). m=n이면O(n·n!). 내부노드후보n개검사총비용도이상한내에포함. 정밀식O(n·Σ[d=0..m-1]P(n,d)+mK).
- 스택깊이O(m),used배열O(n),현재경로O(m). 결과제외추가공간O(n+m),결과포함O(n+m+mK). 재귀호출총횟수와동시깊이구분필요.
- 품질: recursion은private, num→depth, list→path, N/M→n/m또는limit/length가명확. 길이고정이므로int[m]경로+복사도적합. 필드방식자체는정석이며이번코드초기화정확. 지역상태를매개변수로전달하면호출간상태분리가더명시적.
- 개선예시는필드없이(n,depth,path,used,result)를전달하고완성시path.clone(). 배열경로는depth위치에덮어쓰므로used만복원하고경로삭제는불필요. 실측최속주장없음,제출파일교체없음.
