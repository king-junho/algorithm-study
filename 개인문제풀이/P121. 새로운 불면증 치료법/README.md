# P121. 새로운 불면증 치료법

- D2 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 15분
- 확인일 2026-11-13 · [SWEA 1288](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV18_yw6I9MCFAZN)

양의 정수 N이 주어진다. N, 2N, 3N, … 순서로 각 수의 자릿수를 본다. 지금까지 본 자릿수를 합쳐 0부터 9까지 모두 처음 등장했을 때, 마지막으로 본 배수의 값을 구한다.

Java `Solution.main`으로 구현한다. 첫 줄에 테스트 케이스 수 T, 다음 T줄에 N이 하나씩 주어진다. 1 ≤ N ≤ 1,000,000이다. 각 케이스마다 `#케이스번호 마지막배수`를 출력한다.

## 자체 예시

```text
2
5
12
```

```text
#1 90
#2 156
```

N이 5이면 5, 10, 15, …, 85까지는 숫자 9를 보지 못한다. 90에서 9가 등장해 모든 숫자가 모인다.
