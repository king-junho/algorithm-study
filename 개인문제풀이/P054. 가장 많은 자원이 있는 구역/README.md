# P054. 가장 많은 자원이 있는 구역

- 출처 구분: 독립 창작(2026), 공식 SWEA 문제·채용 기출 아님.
- 난이도: 학습용 D3 상당(비공식 추정), 유형 비공개.
- 참고: SWEA 공식 D3 목록 https://swexpertacademy.com/main/code/problem/problemList.do?orderBy=RECOMMEND_COUNT&pageIndex=1&pageSize=10&problemLevel=3&select-1=3&selectCodeLang=CCPP / 확인일2026-10-28. 조건과 예시는 독립 작성.
- 권장35분 / 제출 대기

H행 W열 지도,0은 통과 불가 바다,양수는 육지의 자원량. 상하좌우 육지로 이어진 칸은 같은 구역. 대각선 연결 아님. 한 구역의 모든 육지 칸 자원량을 한 번씩 합산할 때 가장 큰 구역 자원합을 구하라. 육지가 없으면0. 최대 칸수 아닌 자원 합.

입력 T(1~10), 각 케이스 H W, 이어 H줄 W개 정수. 1≤H,W≤50,0≤각값≤1000. 출력 #번호 최대자원합. Java class Solution/main.

```text
입력
3
3 4
1 2 0 5
0 3 0 0
4 0 6 7
2 2
0 0
0 0
1 1
9

출력
#1 13
#2 0
#3 9
```

첫째 구역별합6,5,4,13. 둘째육지없음. 셋째단일육지9. 코드·선택기법과 근거·시간공간복잡도·실제풀이시간 제출. 반환함수가 있다면 반환값 의미를 먼저 한 문장으로 정의. 정답·핵심풀이 요청전 비공개.


## 2026-10-28 — P054 첫 제출 수정 필요

- 주석25분~38분으로 약13분 소요로 기록. 잠정64점(정확성20/효율성20/품질10/경계5/설명9). Java21 실제3케이스 실행: 2x2 [0,1;2,0] 기대2 실제3, 단일9 기대9 실제9, 전체바다 기대0 실제0. 바다에서도 탐색 시작해 서로 다른 육지 구역을 합치는 오류.
- main 시작 조건에 육지 여부가 누락(사용자 풀이 주석에는 조건 명시되어 있으나 코드 불일치). 반환값 합산은 올바른 방향. bfs 이름이나 구현은 재귀 DFS. 반환값은 자기 칸뿐 아닌 이번 호출에서 새로 방문한 연결 육지의 자원 합.
- 직사각형이므로 시간/공간 O(HW), 호출스택 최대 O(HW) 포함. 시작점 조건을 직접 수정하도록 안내. 완료 풀이 파일·커밋·푸시 없음.

## 수정 통과

2026-10-28,95점(정확성40/효율성20/품질14/경계15/설명6), 약13분(초기 주석 기준,수정시간 별도 미보고). 시작점 육지 조건 수정. Java21 표준입출력1872케이스를 독립 반복 BFS와 비교해 통과. 작은 격자1569·무작위300·50x50 최대경계3. 전체 육지 최대합2500000,전체바다,대각선 분리,직사각형 및 다중 테스트 포함. 외부 채점기 미실행. 시간/공간 O(HW),재귀스택 최악 O(HW).

DFS/BFS 모두 구역의 모든 칸을 한 번 방문하므로 점근적 차이 없음. 재귀DFS는 반환형 합산 연습에 적합,반복BFS는 재귀스택 한계 회피에 유리. 이번 Java21 환경에서 최대격자 실행 통과하였으나 다른 채점환경 스택 크기까지 보장하지 않음. 반환값은 본인만의 자원 아닌 새로 방문한 연결육지 합. 주석 N²를 H×W로 명확히 수정 권장.
