# P085. 창고 구역별 재고 합계

- 난이도는 D3 수준 추정이다.
- 유형은 격자·구간 합이다.
- 권장 시간은 30분이다.
- 공개 연습 문제의 조건을 변형했다. 정사각형의 나무 유무를 직사각형의 재고 수량으로 바꾸고 SWEA 형식의 입출력을 적용했다. 2026-11-09에 원문을 확인했다. [CSES 1652 Forest Queries](https://cses.fi/problemset/task/1652)

## 문제

창고에는 H행 W열로 물품이 배치되어 있다. 각 칸에는 해당 칸의 재고 수량이 적혀 있다. 재고가 바뀌지 않는 동안 Q개의 조회가 들어온다. 각 조회의 왼쪽 위 좌표와 오른쪽 아래 좌표로 정해지는 직사각형 안의 재고 합을 구하라. 직사각형의 경계 칸도 포함한다.

## 입력

첫 줄에 테스트 케이스 수 T가 주어진다. 각 테스트 케이스의 첫 줄에 H, W, Q가 주어진다. 다음 H줄에는 각 행의 재고 수량 W개가 주어진다. 이어지는 Q줄에는 조회 좌표 r1, c1, r2, c2가 순서대로 주어진다. 행과 열은 1부터 시작한다.

- 1 ≤ T ≤ 10
- 1 ≤ H, W ≤ 500
- 1 ≤ Q ≤ 100,000
- 0 ≤ 칸별 재고 수량 ≤ 1,000,000,000
- 1 ≤ r1 ≤ r2 ≤ H, 1 ≤ c1 ≤ c2 ≤ W

## 출력

각 테스트 케이스마다 `#테스트케이스번호`로 시작하고, 각 조회의 합을 입력 순서대로 공백으로 구분해 한 줄에 출력한다. 테스트 케이스 번호는 1부터 시작한다.

## 예시

입력

```text
2
3 4 4
1 0 2 3
4 5 0 1
0 2 1 4
1 1 3 4
1 2 2 3
2 4 3 4
2 2 2 2
1 3 2
1000000000 1000000000 1000000000
1 1 1 3
1 2 1 2
```

출력

```text
#1 23 7 5 5
#2 3000000000 1000000000
```

첫 번째 테스트의 두 번째 조회는 1~2행과 2~3열을 포함하므로 0 + 2 + 5 + 0 = 7이다. 마지막 조회는 (2, 2) 한 칸의 수량 5를 구한다.

Java `Solution` 클래스의 `main`으로 작성한다. 풀이 설명, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.

- Java 21에서 테스트 케이스 10개, 조회 100,650개를 실행했다. 예시, 1칸·한 행·한 열, 작은 직사각형의 모든 조회, 최대 격자의 합과 최대 조회 수를 각각 확인했다. 출력은 줄 끝 공백을 제외하고 비교했다. 최대 격자와 최대 조회 수를 동시에 둔 입력의 실행 시간은 측정하지 않았다.
- 최악에 500×500 전체 구역을 100,000번 조회하면 덧셈이 250억 번이다. 시간은 입력 포함 O(HW + QHW)이고, 테스트 케이스당 격자는 O(HW), 출력 버퍼는 O(Q)다. 전체 출력을 모으므로 여러 케이스의 출력은 합산한다.
- 다음 시도에서는 고정 격자의 왼쪽 위부터의 합을 재사용하는 방법을 생각한다. 재고 합은 long으로 유지한다.
