# P060. 출발지에서 각 마을까지

- 유형: 다익스트라 기본 / 난이도: 입문(공식 SWEA 등급 없음)
- 독립 창작(2026). 개념 참고 https://cp-algorithms.com/graph/dijkstra_sparse.html / 확인2026-10-28. 채용 기출·SWEA 문제 아님.
- 권장30~40분 / 제출 대기

1~N번마을과M개단방향도로가주어진다.도로a b time은a에서b로만이동가능하며시간time필요.출발마을S에서각마을까지최소이동시간출력.경유가능,경로의도로시간합이이동시간.출발지0,도달불가-1.모든마을을방문하는하나의여행이아니라각목적지까지독립최솟값이다.

입력T(1~10),각케이스N M S,이어M줄a b time.1≤N≤1000,0≤M≤min(10000,N(N-1)),1≤S≤N,1≤a,b≤N,1≤time≤1000.자기도로/같은방향중복없음.역방향존재가능.양수가중치.출력 #번호 뒤에1~N번마을최소시간N개. Java class Solution/main.

```text
입력
3
5 5 1
1 2 5
1 3 2
3 2 1
2 4 3
3 4 10
3 1 2
1 2 4
1 0 1

출력
#1 0 3 2 6 -1
#2 -1 0 -1
#3 0
```

첫째2번은1→3→2로3,4번은1→3→2→4로6,5번불가.둘째2에서1로갈수없음.셋째출발지한개0. 코드/설명/시간공간복잡도/풀이시간제출. 정답및핵심풀이요청전미공개.
