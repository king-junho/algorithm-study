# P069. 모든 마을 사이의 이동 시간

- 유형:플로이드–워셜 / 난이도:입문 / 독립창작(2026),기출아님.
- 개념참고 https://cp-algorithms.com/graph/all-pair-shortest-path-floyd-warshall.html /확인2026-10-29.
- 권장30분/제출대기

1~N번마을,M개단방향도로및시간.모든출발마을i와도착마을j에대해최소이동시간을출력.경유가능,자기자신0,도달불가-1.도로a b time은a→b만가능.음수비용없음.

입력T(1~10),각케이스N M,다음M줄a b time.1≤N≤100,0≤M≤N(N-1),1≤time≤1000,마을번호1~N.자기간선/같은방향중복없음.역방향별도존재가능.출력#번호단독줄후N행N열최소시간행렬. 행은출발,열은도착. Java class Solution/main.

```text
입력
2
3 4
1 2 4
2 3 2
1 3 10
3 1 7
2 0

출력
#1
0 4 6
9 0 2
7 11 0
#2
0 -1
-1 0
```

첫째1→3은1→2→3으로6,2→1은2→3→1으로9,3→2는3→1→2로11.둘째자기마을만0,다른마을불가. 코드/거리배열의미/풀이설명/시간공간복잡도/실제풀이시간제출.정답및핵심풀이요청전미공개.
