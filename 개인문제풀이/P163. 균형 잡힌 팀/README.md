# P163. 균형 잡힌 팀

SSAFY 실전 모의 8회차 2번 · 독립 창작 · SWEA D3 비공식 추정 · Java · 로컬 통과

2026-11-20. [17기 공식 안내](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_menu_cd=&p_pageno=&p_process=select-board-view&p_seq=194&p_tabseq=226504)와 [15기 후기](https://5-ms.tistory.com/32) 참고. 최초 1번 풀이 35분 및 추가 수정 시간을 제외한 전체 80분 타이머 잔여 시간으로 진행한다. 상세 결과는 모의 종료 후 공개.

N명의 능력치가 주어진다. 서로 다른 사람 K명을 선택해 한 팀을 만든다. 팀 내 최대 능력치와 최소 능력치의 차이를 최소화하라. 입력 순서에 상관없이 선택할 수 있고 능력치가 같아도 다른 사람이다. K=1일 때 차이는 0이다.

입력 첫 줄 T(1~10). 각 케이스는 N K(1≤K≤N≤100,000), 능력치 N개(각 0~10^9). Solution.main에서 #케이스번호 최소차이를 출력한다.

예시 N=6, K=3, 능력치 10 3 20 12 11 4에서 10,11,12를 선택해 차이 2를 얻는다.

## 모의 종료 평가

Java 21 로컬 30/30. 96점. 10분. 시간 O(N log N), 공간 O(N).
