# P118. 숫자를 정렬하자

- D2 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 10분
- 확인일 2026-11-13 · [SWEA 1966](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV5PrmyKAWEDFAUq)

정수 N개를 작은 수부터 큰 수 순서로 출력한다. 같은 수가 여러 번 주어지면 나온 횟수만큼 출력한다.

Java `Solution.main`으로 구현한다. 첫 줄에는 테스트 케이스 수 T가 주어진다. 각 케이스의 첫 줄에는 N(5 ≤ N ≤ 50), 다음 줄에는 정수 N개가 주어진다. 각 답은 `#케이스번호` 뒤에 결과를 공백으로 구분해 한 줄에 출력한다.

## 자체 예시

```text
2
5
8 3 5 3 1
6
9 7 5 3 2 1
```

```text
#1 1 3 3 5 8
#2 1 2 3 5 7 9
```

첫 케이스에는 3이 두 번 있으므로 결과에도 두 번 나온다.
