# P116. 쇠막대기 자르기

- D4 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 25분
- 확인일 2026-11-12 · [SWEA 5432](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AWVl47b6DGMDFAXm)

괄호 문자열로 쇠막대기와 레이저의 배치를 나타낸다. 인접한 여는 괄호와 닫는 괄호 `()`는 레이저다. 나머지 여는 괄호와 그에 대응하는 닫는 괄호는 막대기의 양 끝이다. 레이저는 해당 위치를 가로지르는 모든 막대기를 자른다. 잘린 뒤 남는 조각의 총개수를 구한다.

Java `Solution.main`으로 구현한다. 첫 줄에 테스트 케이스 수 T가 주어지고, 다음 T줄에 괄호 문자열이 하나씩 주어진다. 문자열 길이는 최대 100,000이다. 각 결과를 `#케이스번호 조각수` 형식으로 출력한다.

## 자체 예시

```text
2
(()())
((())())
```

```text
#1 3
#2 5
```

첫 케이스는 막대기 하나를 두 번 잘라 3조각을 만든다. 둘째 케이스의 바깥 막대기는 두 번 잘려 3조각, 안쪽 막대기는 한 번 잘려 2조각이 된다.
