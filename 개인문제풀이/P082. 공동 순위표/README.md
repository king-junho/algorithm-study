# P082. 공동 순위표

- D2 수준 추정. 유형은 배열과 집계. 권장 20분.
- 공개 대회 연습 문제의 조건과 입출력을 변형했다. [AtCoder ABC399 B](https://atcoder.jp/contests/abc399/tasks/abc399_b?lang=en)는 2025-03-29에 공개되었으며 2026-11-09에 확인했다. 공동 순위 규칙을 유지하고 입력 제한, 예시, SWEA 형식을 별도로 구성했다.

N명의 점수가 학생 번호 순서대로 주어진다. 학생의 순위는 자신보다 높은 점수를 받은 학생 수에 1을 더한 값이다. 모든 학생의 순위를 학생 번호 순으로 출력한다.

첫 줄에 T가 주어진다. 각 테스트 케이스는 첫 줄의 N과 다음 줄의 점수 N개로 구성된다. 1 ≤ T ≤ 10, 1 ≤ N ≤ 100,000, 0 ≤ 점수 ≤ 100. 출력은 `#번호 순위1 순위2 ... 순위N` 형식이다.

입력 예시

```text
3
6
70 100 70 90 100 60
4
0 0 0 0
1
55
```

출력 예시

```text
#1 4 1 4 3 1 6
#2 1 1 1 1
#3 1
```

첫째에서 70점보다 높은 학생이 세 명이므로 두 70점 학생은 공동 4위다. 둘째에서는 모두 같은 점수라 전원이 1위다. 셋째는 학생 한 명이 1위다.

Java `Solution` 클래스의 `main`으로 작성한다. 풀이 설명, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.


## 2026-11-09 — P082 최초 제출 통과

- 20분(15:40~16:00), 96점. 정확성 40, 효율성 19, 코드 품질 13, 테스트·경계 조건 15, 설명 9.
- Java 21에서 3,584개 표준입출력 사례를 검증했다. 길이 1~7과 점수 0·1·100의 전수 3,279개, 무작위 300개, 예시 3개, N=100,000 경계 2개가 모두 일치했다. 각 학생보다 높은 학생을 직접 세는 정답을 사용했고, 최대 입력은 두 점수 및 동일 점수로 구성해 기대 순위를 계산했다. 줄 끝 공백은 비교에서 제외했다. 공개 채점기는 미실행했다.
- 정렬 배열을 뒤에서 읽을 때 같은 점수의 첫 위치 i에는 더 높은 점수가 n-1-i개 있으므로 순위는 n-i다. 점수별 순위를 원래 입력 순서로 조회하는 방식이 정확하다. 주석의 idx+1은 n-i로 정정한다.
- 제출 시간 O(N log N), 공간 O(N). 점수 범위가 0~100으로 고정되어 빈도 배열로 O(N+101) 처리할 수 있다. 원시 타입 new HashMap()은 javac의 비검사 변환 경고를 내므로 new HashMap<>()로 고치고, 호출 전 즉시 덮어쓰는 grades 배열 생성을 없앤다.
