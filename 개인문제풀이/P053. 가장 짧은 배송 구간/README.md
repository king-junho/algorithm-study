# P053. 가장 짧은 배송 구간

- 독립 창작(2026), 학습용 D3 상당(비공식 추정), 유형 비공개.
- 난이도 참고: SWEA 공식 D3 목록 https://swexpertacademy.com/main/code/problem/problemList.do?orderBy=RECOMMEND_COUNT&pageIndex=1&pageSize=10&problemLevel=3&select-1=3&selectCodeLang=CCPP / 확인2026-10-28. 공식 등록 문제나 채용 기출 아님.
- 권장30분 / 제출 대기

일렬로 배치된 N개 창고의 물품 수가 주어진다. 순서를 바꾸지 않고 연속한 창고를 하나 이상 선택하여 물품 합계가 K 이상이 되게 한다. 가능한 구간 중 창고 개수의 최솟값을 출력한다. 없으면0. 정확히 K일 필요 없음. 원형 연결 아님.

입력 T(1~10), 각 케이스 N K, 다음줄 N개 물품수. 1≤N≤100000,1≤K≤10^12,1≤물품수≤10^9. 각 케이스 독립. 출력 #번호 최소창고수. Java class Solution/main.

```text
입력
3
6 7
2 3 1 2 4 3
4 10
1 1 1 1
3 8
8 1 2

출력
#1 2
#2 0
#3 1
```

첫째 마지막 두 창고4+3=7, 하나만으로는7이상 불가. 둘째 전체 합4로불가. 셋째 첫 창고만 선택. 코드·기법 선택 이유·시간공간복잡도·실제풀이시간 제출. 유형 및 풀이 힌트 요청전 공개 안함.


## 2026-10-28 — P053 첫 제출 수정 필요

- 20분, 잠정48점(정확성20/효율성3/품질12/경계5/설명8).
- Java21 실제 실행: 예시3케이스 통과. N3,K2000000000,배열900000000 900000000 900000000은 기대3 실제0(int 합 오버플로). N3,K3000000000,배열1000000000 세 개는 기대3이나 nextInt에서 InputMismatchException 발생.
- K≤10^12, 전체 합≤10^14이므로 K와 누적합 모두 long 필요. 주석 long과 실제 int 불일치. 최악 N100000에서 안쪽 반복 합은 4999950000회, O(N²). 전체 시간초과 실행은 하지 않았으며 연산 횟수로 부적합 판단.
- 정답 로직은 작은 값에서는 올바르나 큰 값과 효율성 불충족. 유형 비공개 원칙을 지키고 우선 이전 구간 합 재사용/양수 조건을 단계별 힌트로 안내. 완료 풀이 파일·커밋·푸시 없음.

## 수정 제출 통과 — 2026-10-28

풀이 시간1시간(사용자 최종 보고),93점(40/20/11/15/7). Java21에서4384개 표준입출력 케이스를 실행해 독립 완전탐색/동일값 최대배열 수학 정답과 일치. 값1~3의 길이1~6 배열과 여러 목표 총4079개, 무작위300, 큰합 반례2, N100000 경계3을 포함. 외부 채점기 미실행. 시간 O(N), 전체 공간 O(N), 입력배열 제외 추가 공간 O(1).

K와 합 long 수정, 투포인터 전환으로 정확성·효율성 해결. while안 두 분기 중 하나의 포인터만 앞으로 이동. 우측 끝에 도달하고 합이 부족하면 양수 조건상 더 줄여도 불가능하므로 종료 적절. 오래된 이중for/O(N²) 주석 및 미사용 import 삭제 필요. 개선 예시는 오른쪽 for 확장/왼쪽 while 축소 구조이며 동일4384케이스 실행 검증.
