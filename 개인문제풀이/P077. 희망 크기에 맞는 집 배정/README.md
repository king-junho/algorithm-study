# P077. 희망 크기에 맞는 집 배정

- 공개 연습: CSES Apartments https://cses.fi/problemset/task/1084 . 확인2026-10-30, 원문연도 미확인. 기출 아님. 원문 수치 조건 유지, T/#출력·예시 변형, 한국어 요약.
- D3 수준 비공식 추정(공식 SWEA 등급 아님). 투 포인터 응용. 권장30분, 제출 대기.

신청자 N명의 희망 집 크기와 빈집 M개의 실제 크기가 주어진다. 희망크기 a인 신청자는 a-K 이상 a+K 이하 크기의 집을 수락한다. 한 집에는 한 명, 한 명에게는 한 집만 배정할 수 있다. 배정받는 사람 수의 최대값을 구하라. 모두 배정하지 않아도 됨, 중복 크기 가능/각자 별개, 입력 정렬 미보장.

입력 T(1~10), 각케이스 N M K, 다음줄 N개 희망크기, 다음줄 M개 실제크기. 1≤N,M≤200000, 0≤K≤1000000000, 1≤각크기≤1000000000.
출력 #번호 최대배정인원. Java Solution/main.

입력
```
3
3 4 2
10 20 30
21 8 33 19
3 3 0
5 5 7
5 7 7
1 1 3
10
13
```
출력
```
#1 2
#2 2
#3 1
```
첫째10희망→8,20희망→19또는21,30희망은없음. 둘째크기5집한개이므로5희망중한명만,7희망한명배정. 셋째차이K와같아가능.
