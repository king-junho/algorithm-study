## 문제 요약

N개 자연수에서 하나 이상 원소를 골라 합이K인 선택의 수를 출력한다. 연속할 필요없고 각위치는최대1번선택한다. 같은값이어도다른위치면다른선택이다. 순서를바꿔중복계수하지않는다.

## 입력·출력과 제한

첫줄T,각테스트첫줄N K,다음줄N개자연수.
1≤N≤20,1≤K≤1000,1≤A[i]≤100.
각케이스출력 #번호 정답.
전체Java프로그램,class Solution,package없음. T상한은확인자료에미명시하여별도제한을만들지않음.

## 학습용 예시

```text
입력
3
4 5
1 2 3 4
3 2
1 1 2
3 10
1 2 3

출력
#1 2
#2 2
#3 0
```

첫예시1+4/2+3두선택,둘째두개의1선택/2하나선택,셋째불가능.

- 93/100: 정확성40, 효율성20, 코드품질12, 테스트·경계15, 설명6. 학습통과,풀이25분.
- Java21 실제20,141입력,제출·개선재귀를독립적인0/1부분집합DP기준과모두일치.길이1~6값1~3전체배열과목표1~3N+1,무작위1,000,길이20경계4. sum=0및visited복원확인. 별도main실행으로학습예시3케이스표준입출력·헤더일치확인. 외부SWEA채점기미실행,검증파일제외.
- startIdx이후만선택하여중복순서제거,같은값다른위치별선택구분,양수조건에서sum>=k가지치기,테스트별sum/count초기화정확.
- 시간최악O(2^N): 가능한부분집합2^N,순서증가로각선택한번씩탐색. 내부for전체반복은재귀트리간선수에대응. N20이면최대약1,048,576상태. k가커가지치기없을때실제로전체부분집합방문.
- 공간O(N): numbers배열,visited배열,최대깊이N재귀스택. 총호출수2^N과동시에쌓이는호출N을구분.
- visited불필요: 다음호출시i+1부터만탐색하므로이전위치재선택불가능. sum은매개변수로주면가감복원불필요,count도재귀반환값누적으로필드제거가능. 개선예시는동일입력으로검증.
- 코드주석의for0부터가아니라startIdx부터탐색,시간NlogN은정렬도없고부분집합탐색이므로맞지않음. 최종제출로직보존,공간O(1)등원래오류주석은문서에서정정.
