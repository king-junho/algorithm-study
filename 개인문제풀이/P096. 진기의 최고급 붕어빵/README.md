## 문제

0초에는 붕어빵이 없다. M초, 2M초, 3M초처럼 M초가 지날 때마다 붕어빵 K개가 완성된다. 손님마다 도착 즉시 붕어빵 한 개를 받아야 한다. 생산이 끝나는 시각과 도착 시각이 같으면 그때 만든 붕어빵도 줄 수 있다. 모든 손님에게 즉시 줄 수 있는지 판단한다.

## 입출력과 제한

첫 줄에 테스트 케이스 수 T가 주어진다. 각 케이스는 첫 줄에 N M K, 다음 줄에 손님 N명의 도착 시각을 입력받는다. 1 ≤ N, M, K ≤ 100이며 도착 시각은 0 이상 11,111 이하다. 케이스마다 `#번호 Possible` 또는 `#번호 Impossible`을 한 줄에 출력한다. 번호는 1부터 시작한다.

## 자체 예시

입력

```text
3
3 3 2
6 3 4
3 3 2
5 3 4
1 2 3
0
```

출력

```text
#1 Possible
#2 Impossible
#3 Impossible
```

첫 번째와 두 번째 케이스에서는 3초에 완성된 두 개가 3초와 4초에 모두 나간다. 다음 생산은 6초이므로 세 번째 손님이 6초에 오면 받을 수 있고 5초에 오면 받을 수 없다.

Java `Solution.main`으로 작성한다. 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
