# P108. 최빈수 구하기

- 권장 시간 10분
- 확인일 2026-11-12 · [SWEA 1204](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV13zo1KAAACFAYh)

## 문제

학생 1,000명의 점수에서 가장 자주 등장하는 점수를 구한다. 최빈수가 여러 개이면 그중 가장 큰 점수를 출력한다. 점수는 0 이상 100 이하의 정수다.

## 입출력

Java `Solution.main`으로 구현한다. 첫 줄에 테스트 케이스 수 T가 주어진다. 각 케이스의 첫 줄에는 케이스 번호가 주어지고, 다음 줄에는 공백으로 구분된 점수 1,000개가 주어진다. 각 답을 `#케이스번호 최빈수` 형식으로 출력한다.

## 자체 예시

1번 케이스에 40점 400개, 70점 400개, 100점 200개가 주어지면 40과 70의 빈도가 같다. 출력은 `#1 70`이다.
