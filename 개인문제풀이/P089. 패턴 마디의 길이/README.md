## 문제

어떤 짧은 문자열을 계속 이어 붙인 결과에서 앞 30글자가 주어진다. 이 30글자를 만들 수 있는 가장 짧은 반복 단위의 길이를 구한다. 마지막 반복 단위는 중간에서 잘릴 수 있다.

## 입출력과 제한

첫 줄에 테스트 케이스 수 T가 주어진다. 다음 T줄에는 길이가 30인 문자열이 한 줄에 하나씩 주어진다. 반복 단위의 길이는 최대 10이다. 각 케이스마다 `#번호 길이`를 한 줄에 출력한다. 번호는 1부터 시작한다.

## 자체 예시

입력

```text
2
ABCABCABCABCABCABCABCABCABCABC
ABCDEFGABCDEFGABCDEFGABCDEFGAB
```

출력

```text
#1 3
#2 7
```

두 번째 문자열은 ABCDEFG를 네 번 이어 붙이고 다음 반복의 앞 두 글자 AB까지 읽은 결과다.

Java `Solution.main`으로 작성한다. 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
