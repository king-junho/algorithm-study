## 요약

1~N번사람M개서로아는관계가주어진다。관계는양방향이며여러관계를거쳐이어진사람들은하나의무리。다른누구와도관계없는사람은혼자한무리。전체무리수를구한다。

## 입출력·제한

첫줄T,각케이스N M,이후M줄a b。1≤N≤100,0≤M≤N(N-1)/2,사람번호1~N,서로다른사람관계,같은관계반복없음。출력 #번호 무리수。T상한확인자료미명시하여추가하지않음。Java전체프로그램,class Solution,package없음。

## 제출

코드·풀이설명·시간공간복잡도(사람수N/관계수M구분)·실제풀이시간。직접테스트제출요구없음。BFS/DFS중선택,새알고리즘필요없음。정답·핵심처리순서요청전미공개。P034/P036보류유지。
