## 요약

N×N체스판에N개퀸을서로공격하지않도록배치하는방법수를구한다. 퀸은같은행·열·두대각선방향어느거리든공격한다. 한칸에최대하나. 회전/대칭이어도놓인칸집합이다르면다른방법이다. 퀸개체에번호를붙이거나놓는순서만바꾼것은다른방법이아니다. 불가능하면0.

## 입출력·제한

첫줄T,이후테스트마다N하나. 1≤N≤10. 각케이스 #번호 방법수 출력. T상한은확인자료에미명시하여추가하지않음. Java전체프로그램,class Solution,package없음.

## 학습용 예시

```text
입력
4
1
2
3
4

출력
#1 1
#2 0
#3 0
#4 2
```

N4배치예(행순서열번호1기반):[2,4,1,3]및[3,1,4,2].
