# P144. 배송량 조회

SSAFY 17기 SW전공 적성진단 대비 · 독립 창작 · 비공식 SWEA D3 추정 · Java · 로컬 통과

2026-11-17 확인. [17기 공식 공지](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_process=select-board-view&p_seq=194&p_tabseq=226504)의 80분과 [2025년 15기 후기](https://5-ms.tistory.com/32)의 두 문항 형식을 참고했다. 모의 2번은 최초 풀이 22분 기준으로 58분. 재제출에 걸린 시간은 미확인이다.

N일 동안의 배송량과 Q개의 조회가 주어진다. 각 조회의 시작일과 종료일 양끝을 모두 포함해 배송량의 합을 구한다.

첫 줄에 T(1~10). 각 케이스는 N Q(각 1~100,000), 다음 줄에 N개의 배송량(각 0~10억), 이후 Q줄에 L R(1 ≤ L ≤ R ≤ N)이 주어진다. Solution.main에서 한 케이스를 한 줄에 `#케이스번호 결과1 결과2 …`로 출력한다.

배송량 4 0 7 2 5에서 조회 (1,3), (3,3), (2,5)의 답은 각각 11, 7, 14다.

## 제출 기록

14분(11:32~11:46). Java 21 로컬 60개 통과. 출력은 줄별 공백 토큰으로 비교했다. 시간·공간 O(N+Q).
