# P138. 조별과제

D3 · SWEA 공개 연습 · 권장 5분 · 로컬 통과

2026-11-16 확인. [SWEA 13218 원문](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AXzjvCCq-PwDFASs&categoryId=AXzjvCCq-PwDFASs&categoryType=CODE)

학생 N명 중 세 명씩 조를 만든다. 각 학생은 최대 한 조에 속하며 남는 학생은 조에 넣지 않아도 된다. 만들 수 있는 조의 최대 개수를 구한다.

첫 줄에 T, 이후 각 줄에 학생 수 N이 주어진다. 세부 입력 제한은 공식 원문을 참고한다. 각 케이스는 `#케이스번호 최대조개수`로 출력한다.

학생이 8명이면 2조를 만들 수 있고, 2명이면 0조다.

## 제출 기록

3분(12:40~12:43). Java 21 로컬 30개 통과. 공식 채점 미확인. 케이스당 시간과 추가 공간 O(1). 출력 버퍼 별도.
