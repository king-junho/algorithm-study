# P105. 중간 평균값 구하기

## 문제

정수 10개에서 최댓값과 최솟값을 각각 한 개씩 제외한다. 남은 8개의 평균을 구하고 소수점 첫째 자리에서 반올림한 정수를 출력한다. 각 정수의 범위는 0부터 10,000까지다.

## 입출력

Java `Solution.main`으로 구현한다. 첫 줄에 테스트 케이스 수 `T`가 주어지고, 이후 각 줄에는 공백으로 구분된 정수 10개가 주어진다. 각 케이스의 답은 `#케이스번호 결과` 형식으로 출력한다.

## 자체 예시

입력

```text
1
3 0 8 1 6 9 2 4 5 7
```

출력

```text
#1 5
```

0과 9를 제외한 8개의 평균은 4.5이며, 반올림하면 5다.
