# P132. 거듭 제곱

D3 · SWEA 1217 공개 연습 · 유형은 원문의 재귀 조건으로 공개 · 권장 15분
확인일 2026-11-14 · [SWEA 원문](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV14dUIaAAUCFAYD)

두 자연수 N과 M을 받아 N의 M제곱을 구한다. 이 문제에서는 거듭제곱 계산에 재귀 호출을 사용한다.

Java Solution.main으로 구현한다. 테스트 케이스는 10개 고정이다. 각 케이스는 번호가 적힌 줄과 N M이 적힌 줄로 이루어진다. N과 M은 양의 정수이며 결과는 int 범위에 들어간다. 출력은 #입력케이스번호 결과 형식이다.

자체 예시 한 케이스

```text
1
3 4
```

```text
#1 81
```

3을 4번 곱하면 81이다.

## 제출 기록

사용자 요청으로 정답 처리했다. 로컬 테스트 10개 중 2개에서 출력 케이스 번호가 달랐다. 복습 대상이다.
