# P100. 날짜 계산기

- SWEA 1948 공개 연습 문제다. 2026-11-11에 공식 목록에서 D2를 확인했다. 최초 공개 연도는 확인되지 않았다. [문제 페이지](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV5PnnU6AOsDFAUq) · [공식 D2 목록](https://swexpertacademy.com/main/code/problem/problemList.do?orderBy=PASS_RATE&pageIndex=2&pageSize=10&problemLevel=2&select-1=2&selectCodeLang=JAVA)
- 풀이 유형은 비공개다.
- 권장 시간은 15분이다.

같은 해의 두 날짜가 주어진다. 시작일과 종료일을 모두 포함한 일수를 구한다. 날짜는 유효하며 두 번째 날짜는 첫 번째 날짜보다 뒤다. 2월은 28일까지다.

첫 줄에 테스트 케이스 수 T가 주어진다. 다음 T줄에 `시작월 시작일 종료월 종료일`이 공백으로 구분되어 주어진다. 각 월은 1~12이고, 일은 해당 월의 범위에 들어간다. 각 케이스에서 `#번호 일수`를 한 줄에 출력한다. 번호는 1부터 시작한다.

자체 예시 입력

```text
3
2 27 3 2
4 10 4 15
1 1 12 31
```

예시 출력

```text
#1 4
#2 6
#3 365
```

첫 케이스는 2월 27일, 2월 28일, 3월 1일, 3월 2일을 포함해 총 4일이다.

Java `Solution.main`으로 작성한다. 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
