# P143. 창고 점검 로봇

SSAFY 17기 SW전공 적성진단 대비 · 독립 창작 · 비공식 SWEA D2~D3 추정 · Java · 수정 후 로컬 통과 · 복습 대상

2026-11-17 확인. [17기 공식 공지](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_process=select-board-view&p_seq=194&p_tabseq=226504)에서 11월 21일 응시 80분을 확인했다. [2025년 15기 응시 후기](https://5-ms.tistory.com/32)와 [난이도 후기](https://hehesu.tistory.com/91)를 참고해 80분에 2문항인 모의 회차로 구성한다. 1번만 먼저 공개한다. 1번 목표 25분, 회차 전체 제한 80분.

H×W 창고에서 S는 시작 칸, 점은 빈칸, #은 벽이다. 로봇은 S에서 북쪽을 향해 시작한다. L/R은 제자리에서 왼쪽/오른쪽 90도 회전, F는 한 칸 전진이다. 벽이나 격자 밖을 향한 F는 위치와 방향을 유지하고 실패 횟수에 더한다. 시작 칸을 포함해 방문한 서로 다른 칸 수와 실패 횟수를 구한다.

첫 줄은 T(1~10). 케이스마다 H W(각 1~100), 길이 W인 격자 H줄, 길이 1~10,000인 명령 문자열 한 줄을 읽는다. 시작 칸은 정확히 하나다. Solution.main에서 `#케이스번호 방문칸수 실패횟수`를 출력한다.

예시 격자 S../.#./...에서 FRFFRFFF는 서로 다른 5칸을 방문하고 전진이 2회 실패한다.

최초 풀이 22분. 수정 시간 미확인. Java 21 로컬 10개 통과. 시간 O(HW+L), 격자와 명령 문자열을 포함한 공간 O(HW+L).
