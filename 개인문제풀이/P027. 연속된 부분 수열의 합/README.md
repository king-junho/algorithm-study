# P027 — 연속된 부분 수열의 합

- 출처: 일반 공개 연습 / https://school.programmers.co.kr/learn/courses/30/lessons/178870
- 확인일: 2026-10-22 / 특정 시험 출제 연도 미확인, 카카오·SSAFY 기출로 분류하지 않음
- 난이도: 투 포인터 기초 응용 / 유형: 연속 구간 합·최단 구간·동률 처리
- 권장 시간: 35분 / 상태: 학습 통과97점 · 풀이25분

## 문제 요약

비내림차순 정렬된 양의 정수 배열 sequence에서 합이 k인 비어 있지 않은 연속 구간을 찾아 시작·끝 인덱스(모두 포함)를 반환한다. 여러 개면 가장 짧은 구간을 선택하고, 길이도 같으면 시작 인덱스가 가장 작은 것을 선택한다. 답은 항상 존재한다. 이번에는 투 포인터로 구현한다.

`public int[] solution(int[] sequence, int k)`

## 제한

- 5 ≤ sequence.length ≤ 1,000,000
- 1 ≤ sequence[i] ≤ 1,000, 비내림차순(중복 가능)
- 5 ≤ k ≤ 1,000,000,000
- 인덱스는 0부터 시작, 원래 배열 순서 유지

## 공식 예시

| sequence | k | 반환 |
| --- | --- | --- |
| [1,2,3,4,5] | 7 | [2,3] |
| [1,1,1,2,3,4,5] | 5 | [6,6] |
| [2,2,2,2,2] | 6 | [0,2] |

첫 예시는3+4,둘째는길이1인5선택,셋째는동일길이중가장앞구간선택.

## 제출

코드,풀이 설명,시간·공간 복잡도와 근거,실제 풀이 시간. 직접 테스트 제출 요구 없음. 정답·핵심 풀이는 요청 전 공개하지 않음.

## 제출 평가 — 2026-10-22

- 97/100: 정확성40/40, 효율성20/20, 코드품질14/15, 테스트·경계15/15, 설명8/10. 학습 통과, 풀이 시간25분.
- Java21 실제16,375입력, 동일·새 객체 실행 모두 통과. 공식3, 길이5~10·값1~4 비내림차순 배열과 가능한 목표합 전수, 무작위3,000, 길이100만 경계4개. 작은 입력은 독립 이중 반복문 기준과 비교, 최대 입력은 명시적 기대값으로 비교. 입력 불변. 외부 채점기는 실행하지 않음. 검증 소스 제외.
- 합이 같으면 더 짧을 때만 갱신하므로 동일길이는 먼저 찾은 작은 시작점 유지. right가 끝이고 sum<k면 남은 양수 제거로 합을 키울 수 없어 종료 안전. 왼쪽이 오른쪽을 앞서는 빈 구간의 sum=0에서도 다음 확장이 올바르게 동작한다.
- 시간O(N): 각 포인터 최대N회 전진. 추가공간O(1). 최대 전체합10억으로 int 범위 안전.
- 개선: length는 현재 끝-시작 차이로 저장되지만 비교 순서는 정확하다. right-left+1을 사용하면 실제 원소개수와 이름이 일치한다. 주석의 sum=0 초기화는 실제 sum=sequence[0]에 맞춰 수정할 것. 동일길이 우선순위 및 양수 조건에 따른 이동·종료 근거를 설명에 추가할 것.
