# P126. 사칙연산 유효성 검사

- D4 · SWEA 공개 연습 · 유형 비공개
- 권장 시간 20분
- 확인일 2026-11-13 · [SWEA 1233](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV141176AIwCFAYD)

양의 정수와 연산자 `+`, `-`, `*`, `/`가 들어 있는 완전 이진 트리가 주어진다. 이 트리가 올바른 사칙연산식을 표현하면 1, 그렇지 않으면 0을 출력한다. 계산 결과는 구할 필요가 없다.

Java `Solution.main`으로 구현한다. 테스트 케이스는 10개로 고정이며 맨 앞에 T는 없다. 각 케이스의 첫 줄에는 정점 수 N(1 ≤ N ≤ 200)이 주어진다. 다음 N줄에는 정점 번호, 값, 존재하는 자식의 정점 번호가 순서대로 주어진다. 정점 번호는 1부터 N까지이고 루트는 1이다. 각 결과를 `#케이스번호 결과` 형식으로 출력한다.

## 자체 예시

두 케이스만 발췌했다.

```text
3
1 + 2 3
2 7
3 4
3
1 8 2 3
2 2
3 -
```

```text
#1 1
#2 0
```

첫 케이스는 7 + 4를 표현한다. 둘째 케이스에서는 8이 두 자식을 가지며 -에는 피연산자가 없다.
