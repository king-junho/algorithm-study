# P051. 긴급 보급 상자

- 출처 구분: 독립 창작(2026). 공개 채용 기출이나 SWEA 등록 문제가 아님.
- 난이도: 학습용 D3 상당(공식 등급 아님). 유형은 사용자 요청으로 제출·피드백 전 비공개.
- 난이도 참고: SWEA 공식 D3 공개 문제 목록 https://swexpertacademy.com/main/code/problem/problemList.do?orderBy=RECOMMEND_COUNT&pageIndex=1&pageSize=10&problemLevel=3&select-1=3&selectCodeLang=CCPP (확인 2026-10-27). 문제 조건·예시는 독립 작성.
- 권장 시간 35분 / 제출 대기

N개의 보급품 중 일부를 골라 무게 제한 W인 상자에 담는다. 보급품 i는 무게 w_i와 중요도 v_i를 가진다. 각 보급품은 하나만 있으며 나누어 담을 수 없다. 무게 합이 W 이하일 때 중요도 합의 최댓값을 구한다. 같은 무게/중요도의 물품도 서로 다른 물품이다. 아무것도 담지 않아도 되며 그 중요도는0이다.

입력 첫줄 T(1~10), 각 케이스 첫줄 N W, 이후 N줄 무게 중요도. 1≤N≤20, 1≤W≤1000000000, 1≤w_i≤1000000000, 1≤v_i≤10000. 무게 합이 제한과 같아도 된다. 출력 #번호 최대중요도. Java class Solution/main.

```text
입력
3
4 7
3 8
4 9
5 12
2 5
3 4
5 10
6 20
7 30
3 6
2 5
2 5
2 5

출력
#1 17
#2 0
#3 15
```

첫째 1·2번(무게7/중요도17) 또는3·4번(무게7/중요도17). 둘째 어떤 물품도 못 담음. 셋째 세 물품 모두 담음. 코드, 기법 선택 이유와 설명, 시간·공간 복잡도, 실제 풀이 시간 제출. 유형·핵심 풀이·정답 미공개.
