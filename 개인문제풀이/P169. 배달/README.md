# P169. 배달

- 출처: 프로그래머스 공개 연습 https://school.programmers.co.kr/learn/courses/30/lessons/12978
- 확인일: 2026-11-24. 출제 연도 미확인.
- 유형: 제출 또는 요청 전 비공개(배운 알고리즘 응용 복습)
- 난이도: SWEA D3~D4 수준 비공식 추정
- 권장 시간: 30분
- 상태: 미제출

1~N 마을, 양방향 도로 road의 각 원소[a,b,c]는 연결된 두 마을과 이동 시간이다. 1번에서 총 이동 시간 K 이하로 도달할 수 있는 마을 수를 반환한다. 1번도 포함한다. 두 마을 사이 다른 시간의 도로가 여러 개 존재할 수 있으며, 모든 마을 사이 경로가 존재한다.

Java public int solution(int N,int[][] road,int K). N1~50, 도로수1~2000, a와b다름, 도로 시간1~10000, K1~500000. 동일한 도로 정보는 중복되지 않는다.

예시 N5, road=[[1,2,1],[2,3,3],[5,2,2],[1,4,2],[5,3,1],[5,4,2]], K3 →4. 1,2,4,5번 마을에 배달 가능.
