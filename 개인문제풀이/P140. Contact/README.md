# P140. Contact

D4 · SWEA 공개 연습 · 권장 25분 · 로컬 통과

2026-11-16 확인. [SWEA 1238 공식 문제](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV15B1cKAKwCFAYD&categoryId=AV15B1cKAKwCFAYD&categoryType=CODE)

시작점에서 비상 연락을 시작한다. 처음 연락을 받은 사람은 다음 차례에 자신에게 등록된 상대에게 동시에 연락한다. 마지막 차례에 처음 연락받은 사람 중 가장 큰 번호를 구한다.

사람 번호는 1~100이다. 연락 방향은 단방향이며 같은 쌍이 반복될 수 있다. 테스트 케이스는 10개 고정이다. 각 케이스는 정수 개수 L과 시작점 S, 이어서 (보낸 사람, 받는 사람)으로 묶이는 정수 L개가 주어진다. 각 케이스마다 `#케이스번호 사람번호`를 출력한다.

시작점 1과 연락 쌍 1→2, 1→9, 2→4, 2→6이 주어지면 마지막 차례에 4와 6이 연락을 받아 답은 6이다.

## 제출 기록

20분(12:57~13:17). Java 21 로컬 100개 통과. SWEA 공식 채점 미확인. 케이스당 시간·공간 O(N+M).
