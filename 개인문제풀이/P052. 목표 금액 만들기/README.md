# P052. 목표 금액 만들기

- 독립 창작(2026), 학습용 D3 상당(공식 등급 아님), 유형 비공개.
- 난이도 참고: SWEA 공식 D3 목록 https://swexpertacademy.com/main/code/problem/problemList.do?orderBy=RECOMMEND_COUNT&pageIndex=1&pageSize=10&problemLevel=3&select-1=3&selectCodeLang=CCPP / 확인일2026-10-27. 기출 기반 문제라고 주장하지 않음.
- 권장25분 / 제출 대기

번호1~N의 쿠폰 각1장이 있다. 일부 쿠폰 금액의 합을 정확히 K로 만드는 선택 방법의 수를 구하라. 각 쿠폰은 최대 한 번 사용하고 나눌 수 없다. 순서가 달라도 같은 쿠폰 집합이면 같은 방법, 금액이 같아도 번호가 다르면 다른 쿠폰이다.

입력 T(1~10), 각 케이스 N K, 다음줄 N개 금액. 1≤N≤20,1≤K≤1000000000,1≤금액≤1000000000. 출력 #번호 방법수. Java class Solution/main.

```text
입력
3
4 5
1 2 3 4
4 2
1 1 1 1
2 3
5 6

출력
#1 2
#2 6
#3 0
```

첫째 번호(1,4)/(2,3). 둘째 번호쌍(1,2),(1,3),(1,4),(2,3),(2,4),(3,4). 셋째 불가능. 코드·선택기법과 이유·함수 반환 의미(함수 사용시)·시간공간복잡도·풀이시간 제출. 해설은 요청 전 비공개.

## 제출 평가

2026-10-27, 15분, 96점(40/20/13/15/8), 통과. Java21 표준입출력812케이스를 독립적인 합별 개수 DP와 비교해 모두 일치. 작은 배열 전수504·무작위300·경계8 포함. N=20, 같은 금액 서로 다른 쿠폰, 불가능, 마지막 선택에서 완성, 큰 누적합, 다중 테스트 초기화 검증. 외부 채점기 미실행. 시간 O(2^N), 공간 O(N).

반환값은 현재 선택에서 남은 쿠폰으로 목표를 완성하는 방법 수. 정확히 도달하면1, 초과하거나 남은 쿠폰 없으면0, 자식 경우의 수는 합으로 누적. 모든 금액이 양수이므로 목표 도달 즉시 반환 가능. 주석의 사용처리 및 coupons[currentIdx]는 실제 구현과 불일치. 현재값은 coupons[i]이며 방문배열 없이 인덱스 증가로 중복 방지.
