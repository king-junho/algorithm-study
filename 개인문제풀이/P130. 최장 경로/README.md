# P130. 최장 경로

D3 · SWEA 2814 공개 연습 · 유형 비공개 · 권장 25분

2026-11-14 확인. [SWEA 문제 목록](https://swexpertacademy.com/main/code/problem/problemList.do?orderBy=INQUERY_COUNT&pageIndex=6&pageSize=20)

정점 1번부터 N번까지와 M개의 양방향 간선이 주어진다. 아무 정점에서 시작해 간선을 따라 이동한다. 같은 정점은 한 경로에서 한 번만 방문할 수 있다. 가장 긴 경로에 포함되는 정점 수를 구한다. 시작 정점도 센다.

Java Solution.main으로 구현한다. 첫 줄에 T, 각 케이스 첫 줄에 N M, 다음 M줄에 간선의 양 끝 정점 번호가 주어진다. 1 ≤ N ≤ 10, 0 ≤ M ≤ 20. 각 결과는 #케이스번호 정점수로 출력한다.

```text
2
5 4
1 2
2 3
2 4
4 5
1 0
```

```text
#1 4
#2 1
```

첫 케이스에서는 1 → 2 → 4 → 5로 정점 4개를 방문할 수 있다. 둘째 케이스에서는 시작 정점 하나를 센다.
