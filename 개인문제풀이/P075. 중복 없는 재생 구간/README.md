# P075. 중복 없는 재생 구간

- 공개 연습: CSES Playlist https://cses.fi/problemset/task/1141 . 확인2026-10-30, 출제연도 미확인. 기출 아님. 원문 조건 유지, T/#출력 및 예시 변형.
- 난이도: D3 수준 비공식 추정, 공식 SWEA 등급 아님. 유형: 투 포인터 응용. 권장35분, 제출 대기.

재생 순서대로 N개의 노래 번호가 주어진다. 같은 노래 번호가 한 번도 중복되지 않는 연속 구간 중 최대 길이를 구하라. 순서 변경/중간 원소 삭제 불가, 번호 동일하면 같은 노래, 노래 하나 구간 허용. 출력은 길이만.

입력 T(1~10), 각케이스 N, 다음줄 N개 노래번호. 1≤N≤200000, 1≤번호≤1000000000.
출력 #번호 최대길이. Java Solution/main.

입력
```
4
7
1 2 1 3 4 2 5
4
7 7 7 7
5
10 20 30 40 50
6
1 2 3 2 4 5
```
출력
```
#1 5
#2 1
#3 5
#4 4
```
첫째 위치3~7 [1,3,4,2,5] 길이5. 둘째 같은번호 반복으로 길이1. 셋째 전체5. 넷째 위치3~6 [3,2,4,5] 길이4. 자료구조/이동 규칙 요청 전 비공개.


## 2026-10-30 — P075 첫 제출: 수정 대기

- 풀이20분(13:05~13:25). 잠정60점(정확성20/효율성18/품질10/테스트·경계5/설명7). Java21 실제4사례: [1,2,3,4,4] 기대4/실제1, [1,2,2,1] 기대2/실제3, [5] 기대1/실제1, 첫 예시 기대5/실제5.
- 마지막 등장 위치 해시 접근 적절. 두 오류: 최장 구간 대신 마지막 구간만 반환, 현재 구간 밖의 과거 등장 때문에 left가 뒤로 이동. 매 right에서 최대 길이 누적 및 left 단조 증가 필요. map은 전체 과거 마지막 위치이고 현재 구간 포함 여부와 같지 않음.
- 평균 시간O(N), 공간O(N), 해시 연산 최악O(1)보장은 아님. Hashtable보다 단일 스레드 학습 코드에는 HashMap 권장. 주석 반환 +1과 실제 루프 종료 right==n의 차이 유의(루프 안 길이는 right-left+1). 전체 정답 미제공, 수정 유도. 완료 Java 저장·커밋·푸시 없음.
