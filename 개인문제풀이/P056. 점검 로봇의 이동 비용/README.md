# P056. 점검 로봇의 이동 비용

- 독립 창작(2026),학습용 D3 상당(공식등급아님),유형비공개.
- 참고: SWEA 공식 D3 목록 https://swexpertacademy.com/main/code/problem/problemList.do?orderBy=RECOMMEND_COUNT&pageIndex=1&pageSize=10&problemLevel=3&select-1=3&selectCodeLang=CCPP /확인2026-10-28. 조건및예시는독립작성.
- 권장30분/제출대기

0~N번 지점이 일렬로 있다. 로봇은0번에서출발하고 한번에앞으로1칸 또는2칸이동한다. 1~N번각지점에는도착할때지불하는비용이있다. 건너뛴지점비용은내지않는다. 시작0번비용0. 반드시N번에도착,뒤로이동불가,N번을넘어갈수없다. 최소총비용출력.

입력T(1~10),각케이스N,다음줄1~N번비용N개.1≤N≤100000,0≤비용≤10^9.출력 #번호 최소총비용. Java class Solution/main.

```text
입력
3
5
10 15 20 1 5
2
8 3
1
7

출력
#1 21
#2 3
#3 7
```

첫째0→2→4→5비용15+1+5=21.둘째0→2비용3.셋째0→1비용7. 코드·기법선택이유·풀이설명·시간공간복잡도·실제시간제출. 핵심풀이및유형은요청전미공개.
