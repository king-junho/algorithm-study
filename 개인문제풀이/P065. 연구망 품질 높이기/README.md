# P065. 연구망 품질 높이기

- 독립창작(2026),기초응용(학습용D3상당·공식등급아님),유형비공개.
- 참고 https://cp-algorithms.com/graph/mst_kruskal.html 및 https://cp-algorithms.com/graph/dijkstra.html /확인2026-10-29.기출아님.
- 권장35분/제출대기

N개기지,M개양방향통신선후보와각품질점수. 정확히N-1개선택해모든기지가직접/경유로서로통신하도록하며선택점수합최댓값구하기.각선점수를한번씩합산,경로별점수합이나최솟값목표아님.연결불가-1,N1은선택0개점수0.

입력T(1~10),각케이스N M,이후M줄a b score.1≤N≤1000,0≤M≤min(10000,N(N-1)/2),1≤score≤10^9,기지번호1~N.자기간선/중복없음.출력 #번호 최대점수합. Java class Solution/main.

```text
입력
3
3 3
1 2 8
2 3 6
1 3 4
4 2
1 2 10
3 4 20
1 0

출력
#1 14
#2 -1
#3 0
```

첫째1-2와2-3선택8+6=14.모든3개선택은N-1개조건위반.둘째전체연결불가.셋째0개선택0점. 코드/기법선택근거/복잡도/풀이시간제출.유형및핵심풀이요청전비공개.

## 수정 통과 — 2026-10-29

97점(정확성40/효율성20/품질14/경계15/설명8). 초기12분(이전주석47~59),추가수정시간미보고. 초기int합계의10^9세간선반례는기대3000000000/실제-1294967296,최신long수정으로해결. Java21표준입출력1064케이스를독립내림차순Kruskal과비교해통과. 작은그래프전수760·무작위300·최대경계4. 단절,N1,M0,동률,최대합999000000000포함. 공개채점기미실행.

최대신장트리이며내림차순Prim맞음. 시작더미간선0은실제선택선이아니라시작정점등록이므로문제없음. 새정점하나확정마다실제간선하나추가,시작제외N-1개조건만족. 시간O(N+Mlog(M+1)),공간O(N+M). 명칭mst보다maximumSpanningTree가의미명확.
