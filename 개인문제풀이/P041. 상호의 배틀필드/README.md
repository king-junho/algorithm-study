## 요약

H×W지도에전차하나。 .평지,*벽돌,#강철,-물,^v<>방향전차(아래평지)。UDLR은방향먼저바꾸고그방향한칸이판안평지이면이동,아니면제자리방향만변경。이동전칸은평지。S는현재방향포탄,전차이동없음。포탄은평지/물통과,*첫벽돌은평지로바꾸고소멸,#강철은그대로두고소멸,범위밖소멸。

## 입출력·제한

첫줄T,각케이스H W,이후H줄공백없는길이W문자열,명령수N,길이N명령문자열。2≤H,W≤20,1≤N≤100。전차정확히하나。출력은 #번호 공백 첫행,나머지행은다음줄에공백없이。Java전체프로그램,class Solution,package없음。T상한확인자료미명시。

## 학습용 예시

```text
입력
1
3 5
.....
>.*#.
.....
4
SSRR

출력
#1 .....
..>#.
.....
```

첫S로벽돌제거,둘째S는강철에막힘,RR로평지2칸이동。

## 제출

전체코드,풀이설명,시간공간복잡도와근거(H/W/N구분),실제풀이시간。직접테스트제출요구없음。정답·핵심구현요청전미공개。
