# P154. 예산 범위의 연속 구매

투 포인터 · 독립 창작 · SWEA D3 상단~D4 초입 비공식 추정 · Java · 권장 30분 · 미제출

2026-11-19 출제. 이전 고정 길이와 가변 길이 학습을 확장한 연속 구간 개수 세기 연습이다.

상품 N개의 가격이 순서대로 주어진다. 하나 이상의 연속된 상품을 골랐을 때 가격 합이 L 이상 R 이하인 선택 방법의 개수를 구한다. 시작 또는 끝 위치가 다르면 다른 방법이다. 각 선택은 독립적으로 세며 구간이 겹쳐도 된다.

첫 줄 T(1~10). 각 케이스는 N L R(1≤N≤100,000, 0≤L≤R≤10^14), 다음 줄에 N개의 가격(각 0~10^9)이 주어진다. Solution.main에서 #케이스번호 방법수를 출력한다.

예시 N=5, L=3, R=5, 가격 1 2 1 3 2의 답은 6이다.
