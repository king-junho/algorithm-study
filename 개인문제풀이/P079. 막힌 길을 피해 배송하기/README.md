# P079. 막힌 길을 피해 배송하기

- 공개 연습: CSES Grid Paths I https://cses.fi/problemset/task/1638 /확인2026-10-30, 원문연도 미확인. 기출 아님. 원문조건 유지, 제목/예시/T/#출력 변형.
- D2~D3 수준 비공식 추정. 유형은 사용자 요청으로 제출 전 비공개. 권장35분, 제출 대기.

N×N 지도 왼쪽 위(1,1)에서 오른쪽 아래(N,N)까지 이동하는 서로 다른 경로 수를 구하라. 한 번에 오른쪽 또는 아래 한 칸만 이동. .은이동가능,*는막힌칸. 시작/도착도막혀있을수있음. 경로는거쳐가는칸의순서가다르면다름. 시작=도착이고이동가능하면경로1,불가능0. 답을1000000007로나눈나머지출력.

입력T(1~10),각케이스N(1~1000),다음N줄길이N문자열(.또는*,공백없음). 출력 #번호 경로수의나머지. Java Solution/main.

입력
```
4
3
...
.*.
...
2
.*
*.
1
.
1
*
```
출력
```
#1 2
#2 0
#3 1
#4 0
```
첫째가장위행→오른쪽열또는왼쪽열→가장아래행두경로. 둘째출발점에서이동불가. 셋째이동없이도착,넷째시작막힘. 코드/선택한기법과이유/시간공간복잡도/풀이시간제출. 자료구조및풀이힌트요청전비공개.
