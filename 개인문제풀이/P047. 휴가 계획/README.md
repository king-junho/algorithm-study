## 요약

N일간하루에A/B/C활동중정확히하나를선택한다。날짜별활동보상a/b/c가주어진다。이틀연속같은활동금지,하루이상사이에다른활동이있으면재선택가능。보상총합최댓값구한다。

## 입출력·제한

원문은한케이스입력이지만학습에서는첫줄T(1~10)추가。각케이스N,이후N줄a_i b_i c_i。원문제약1≤N≤100000,1≤보상≤10000유지。출력 #번호 최대합으로변형。Java전체코드,class Solution,package없음。

## 2026-10-27 — 복습 보류

점화식 설명을 받은 뒤 사용자 구현 제출. 코드를 수동 확인했으며 활동별 이전 두 상태의 최댓값을 이용하는 전이와 첫날 초기화가 문제 조건에 맞는다. 시간 O(N), 공간 O(N). 실제 실행 및 공개 채점기 검증은 하지 않았으며 통과·점수 확정 및 완료 풀이 커밋은 하지 않는다. 풀이 시간 미보고.

복습 포인트: dp[i][j]는 i일에 j 활동으로 끝나는 누적 최대 행복도다. 현재 주석에는 이전 상자 문제의 점화식과 rewards/int[] 이름이 남아 있어 수정이 필요하다. 도움 없이 상태·초기값·전이를 다시 설명하고 구현하는 것을 재도전 목표로 둔다.

### 제출 구현 메모 (완료 풀이 아님)

```java
private static int maxHappy(int[][] happy) {
    int n = happy.length;
    int[][] dp = new int[n][3];
    dp[0][0] = happy[0][0];
    dp[0][1] = happy[0][1];
    dp[0][2] = happy[0][2];
    for (int row = 1; row < n; row++) {
        dp[row][0] = Math.max(dp[row - 1][1], dp[row - 1][2]) + happy[row][0];
        dp[row][1] = Math.max(dp[row - 1][0], dp[row - 1][2]) + happy[row][1];
        dp[row][2] = Math.max(dp[row - 1][1], dp[row - 1][0]) + happy[row][2];
    }
    return Math.max(Math.max(dp[n - 1][0], dp[n - 1][1]), dp[n - 1][2]);
}
```
