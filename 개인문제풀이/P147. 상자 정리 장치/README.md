# P147. 상자 정리 장치

2026-11-18 확인. [17기 공식 공지](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_menu_cd=&p_pageno=&p_process=select-board-view&p_seq=194&p_tabseq=226504)의 80분과 [2025년 15기 응시 후기](https://5-ms.tistory.com/32)의 순차 공개 형식을 참고했다. 1번 권장 30분. 모의 기준 충족 시 2번 공개, 회차 종료 후 채점 공개.

H×W 격자에서 0은 빈칸, 양수는 상자의 색이다. 초기 격자는 그대로 둔다. 각 명령에서 H r은 r행을 오른쪽으로 한 칸, V c는 c열을 아래로 한 칸 순환 이동한다. 빈칸도 함께 이동하고 끝에서 밀려난 값은 반대편으로 들어온다. 행과 열은 1부터 센다.

명령 직후 모든 칸이 같은 양수인 행을 한꺼번에 제거한다. 제거한 행이 있으면 각 열에서 상자가 아래로 떨어져 빈칸 없이 바닥부터 쌓이며 위아래 순서는 유지된다. 같은 규칙으로 새로 생긴 행도 제거할 수 없을 때까지 반복한다. 제거할 행이 없으면 낙하 없이 다음 명령으로 넘어간다.

첫 줄 T(1~10). 케이스마다 H W Q(H, W는 2~30, Q는 1~200), 0~9 정수 W개가 적힌 H줄, 이어서 유효한 명령 Q줄. Solution.main에서 `#케이스번호 제거한상자수 남은상자수` 출력.

예시에서 H 1 명령 후 222 행을 제거하고, 낙하로 생긴 111 행도 제거한다. 총 6개를 제거하고 2개가 남는다.

```text
1
3 3 1
1 2 1
1 0 1
2 2 2
H 1
```

```text
#1 6 2
```

## 재풀이 평가

Java 21 로컬 100개 통과, 94점. 재풀이 시간 미확인. 시간 O((Q+H)HW), 공간 O(HW+Q), 출력 버퍼 별도.
