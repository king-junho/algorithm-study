## 문제

정수 N을 2, 3, 5, 7, 11의 거듭제곱을 곱해 나타낼 수 있다. N = 2^a × 3^b × 5^c × 7^d × 11^e일 때 다섯 지수 a, b, c, d, e를 순서대로 구한다.

## 입출력과 제한

첫 줄에 테스트 케이스 수 T가 주어진다. 이후 각 줄에 2 이상 10,000,000 이하의 정수 N이 주어진다. 케이스마다 `#번호 a b c d e`를 한 줄에 출력한다. 번호는 1부터 시작한다.

## 자체 예시

입력

```text
2
84
275
```

출력

```text
#1 2 1 0 1 0
#2 0 0 2 0 1
```

84는 2² × 3 × 7이고, 275는 5² × 11이다.

Java `Solution.main`으로 작성한다. 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
