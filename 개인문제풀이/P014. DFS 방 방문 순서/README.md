# P014 — DFS 방 방문 순서

- 출처구분: 창작 문제(기출 아님), P013 후속·P009의 DFS버전
- 참고: https://school.programmers.co.kr/learn/courses/30/lessons/43162 (연결개념, 원문과목표다름)
- 확인·창작일: 2026-10-19 / 난이도: DFS 기초 / 유형: 재귀DFS·방문순서
- 권장시간:20분 / 상태: 로컬 검증 통과 · 96/100 · 10분

## 설명

rooms[i]는 i번방과 직접 연결된 방 목록이다. start에서 재귀DFS로 탐색하며 각 방에 처음 들어간 순서대로 번호배열을 반환한다. 현재방의 이웃을 목록순으로 확인하며, 미방문이웃을 발견하면 그 방의 탐색을 먼저 끝낸 뒤 다음이웃을 확인한다. 시작방포함, 각방한번만, 도달불가방제외.

## 함수·제한

`public int[] solution(int[][] rooms, int start)`

- 방수1~10, 번호0..rooms.length-1, 유효한start
- 문양방향·양쪽목록에표시, 자기연결·목록내중복없음, 빈목록가능
- 각 연결목록은 번호오름차순으로 제공, 그순서대로확인
- 재귀DFS로구현, BFS큐미사용
- 결과는 방문순서이며 정렬된방번호나거리배열아님

## 예시

1. rooms=[[1,2],[0,3],[0],[1]],start0 → [0,1,3,2]. 1로들어가3까지탐색한뒤돌아와2방문.
2. rooms=[[1],[0],[]],start2 → [2]. 출발방만도달.
3. rooms=[[1,2],[0,2],[0,1]],start1 → [1,0,2]. 순환이어도한번씩방문.

## 제출

Java코드, 재귀호출·복귀흐름을포함한설명, 시간·공간복잡도와근거, 실제풀이시간. 테스트제출요구없음.

## 최종 평가

- 정확성40/40, 효율성20/20, 품질12/15, 경계15/15, 설명9/10 =96/100,10분.
- [P014.java](P014.java): 제출DFS 로직·필드·공개범위 유지. import·클래스·공백 정리, 디버그 printArr 호출과 전용 출력함수만 제외해 최종 저장. 반환용 스트림은1회 유지.
- Java21 실제검증: 원본(출력함수 포함)과 저장버전 각각6,406개 입력을 재사용·새인스턴스에서 실행, 각각12,812호출 통과. n≤5 모든 단순무방향그래프/모든시작점5,405, 무작위1,000, n10완전연결1. 독립적인 스택DFS와 방문순서 일치, 입력불변. 외부채점기 없음. 검증파일 제외.
- 시간O(V+E): 각방1회방문, 양방향목록총2E확인, 반환변환O(V). 출력용중복변환도 차수는같으나 불필요.
- 공간O(V): visited·결과리스트·반환배열·최대V깊이재귀스택. 결과제외도 O(V).
- 개선확인: answer를 solution마다 새로생성해 이전호출상태초기화. 순환·공유이웃·고립·임의시작 정상.
- 품질보완: 필드와 dfs는 private 권장. index→current, 향상된for문 사용가능. 디버그출력과중복배열변환 제거.
- 설명보완: 방문한 이웃은 건너뛰고 다음이웃을 계속 확인한다. 이미 방문한 이웃을 만났다고 현재dfs를 즉시return하면 뒤의 미방문이웃을 놓칠 수 있음. 실제코드는 정확.
