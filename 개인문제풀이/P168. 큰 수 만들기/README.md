# P168. 큰 수 만들기

- 출처: 프로그래머스 공개 연습 https://school.programmers.co.kr/learn/courses/30/lessons/42883
- 확인일: 2026-11-22. 출제 연도 미확인.
- 유형: 그리디 · 스택
- 난이도: 복습 중간~도전, SWEA D3~D4 수준 비공식 추정
- 권장 시간: 35분
- 상태: 해설 확인 · 복습 재도전 대상

숫자 문자열 number에서 정확히 k개의 자릿수를 삭제한다. 남은 숫자들의 상대적 순서는 유지한다. 만들 수 있는 가장 큰 수를 문자열로 반환한다.

Java: public String solution(String number, int k). number 길이2~1000000, 1≤k<number.length().

예시: 1924에서2개삭제→94, 1231234에서3개삭제→3234, 4177252841에서4개삭제→775841. 첫 예시는 1과2를 삭제한다.
