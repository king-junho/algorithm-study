# P008 — 연결된 방 찾기

- 출처 구분: 공개 연습 문제 기반 창작. 기출 아님.
- 참고: https://school.programmers.co.kr/learn/courses/30/lessons/43162
- 확인일: 2026-10-19 / 창작일: 2026-10-19
- 변경점: 전체 그룹 개수 대신 0번 방에서 갈 수 있는 방 개수만 센다. 연결 정보는 각 방의 이웃 목록으로 제공한다.
- 난이도: BFS 첫 연습 / 유형: 큐·방문 여부·기본 탐색
- 권장 시간: 20분 / 상태: 학습 통과 · 89/100 · 풀이 시간 20분

## 설명

방 번호는 0부터 rooms.length-1까지다. rooms[i]는 i번 방과 문으로 직접 연결된 방 번호 목록이다. 문은 양방향이며 연결 정보는 양쪽 목록에 모두 들어 있다. 0번 방에서 출발해 문을 여러 번 지나갈 수 있을 때 도달 가능한 서로 다른 방의 개수를 반환한다. 출발 방도 포함하며 같은 방은 한 번만 센다.

## 함수와 제한

`public int solution(int[][] rooms)`

- 방 개수는 1 이상 10 이하
- 각 방의 연결 목록은 비어 있을 수 있음
- 방 번호는 유효하며, 자기 연결과 목록 내 중복은 없음
- BFS 연습이므로 Queue와 반복문으로 구현(재귀 미사용)

## 예시

- [[1],[0,2],[1],[]] → 3. 0-1-2, 방3은 고립.
- [[],[]] → 1. 출발 방0만 도달.
- [[1,2],[0,2],[0,1]] → 3. 순환 연결이어도 각 방을 한 번만 센다.

## 최종 평가

- 정확성40/40, 효율성20/20, 코드품질12/15, 테스트8/15, 설명9/10 = 89/100. 20분.
- [P008.java](P008.java)에 제출 로직 보존, 클래스명·import만 보완.
- 실제 검증: Java 21에서 이전 2,100개(방1~5 모든 무방향 단순그래프 1,099 / 무작위1,000 / 방10 완전연결1)와 사용자 추가2개를 실행해 모두 통과. 입력 불변 확인. 외부 채점기 없음.
- 사용자 테스트: [[1,2,3],[0],[0],[0]] 예상4/실제4, [[3],[3],[3],[0,1,2]] 예상4/실제4. 직접 실행 여부는 미보고. 두 테스트 모두 별 모양 연결이므로 다음에는 고립·순환·여러 경로를 섞을 것.
- V=방 수, E=문 수. 각 방을 최대1회 큐 처리하고 연결 목록을 총2E번 확인하므로 O(V+E), 추가 공간 O(V).
- 오답 수정: 현재 방과 다음 방 혼동을 고쳐 검사·추가·방문표시 대상을 일치시킴. 시작 방 특별처리와 모호한 n 이름은 개선 여지.
