## 문제 요약

1..n번 사람이 번호순으로 단어를 말하고 n번 다음은1번으로 돌아간다. words에는 발언 순서대로 단어가 주어진다. 첫 단어 이후 각 단어는 직전 단어의 마지막 문자로 시작해야 하며 이미 나온 단어는 다시 사용할 수 없다. 가장 먼저 규칙을 어긴 사람의 번호와 그 사람의 몇번째 발언인지 [번호,차례]로 반환한다. 탈락자가 없으면[0,0]. 단어의 실제 의미는 판단하지 않는다. 원문 조건을 보존한 요약.

## 함수·제한

`public int[] solution(int n, String[] words)`

- 2≤n≤10
- n≤words.length≤100
- 각 단어 길이2~50,영어 소문자만
- 길이1단어는 입력에없음
- 반환배열길이2. 차례는 해당사람의 발언횟수이며전체단어번호아님

## 예시

1. 공식: n3,words=[tank,kick,know,wheel,land,dream,mother,robot,tank] →[3,3]. 9번째tank가중복이며3번사람의세번째발언.
2. 추가학습: n2,words=[ab,bc,cd,da] →[0,0]. 중복없고연결조건모두충족. 실제단어의미는판단하지않음.
3. 공식: n2,words=[hello,one,even,never,now,world,draw] →[1,3]. never의마지막r과now의시작n불일치,1번사람의세번째발언에서처음탈락.

## 최종 평가

- 정확성40/40,효율성20/20,품질13/15,경계15/15,설명5/10=93/100. 풀이시간미보고.
- [P023.java](P023.java): 제출로직보존,import·클래스·서식정리. List.getLast는현재Java21에서지원.
- Java21 실제26,494입력×동일/새객체각각52,988호출통과. 공식3,두문자단어4종의길이2~6모든배열·유효참가자수25,488,무작위1,000,최대100단어·길이50의정상/중복/연결오류3. 독립중복검사와순차플레이어·차례시뮬레이션기준,입력불변. 외부채점기미실행. 검증소스제외.
- 정확성: 첫단어이전문자검사생략,중복·끝말불일치중최초시점반환,사람번호idx%n+1·개인차례idx/n+1정확. 두오류가동시에있어도동일시점반환이므로검사순서문제없음.
- W=단어수,L=최대길이,n=참가자수. contains는이전단어를순차비교해최악O(WL),전체O(W²L). startsWith·마지막한글자substring은추가O(1),지배항변화없음.
- 입력제외추가공간O(W): 리스트는입력String참조만저장하고단어내용을복제하지않음. 한문자substring은일시상수공간.
- 효율성: W≤100,L≤50제한에적합해만점. 개선시HashSet중복검사평균상수회탐색,문자열해시비용포함평균O(WL)로가능. 현재코드교체없음.
- 품질: 이전단어는words[idx-1]에서얻고charAt으로끝·첫문자비교하면반복getLast·substring을줄일수있음. 주석은끝말연결검사누락·사람번호+1빠짐,시간복잡도오류수정필요.

## 2026-10-21 HashSet 개선·시간 보고

- 재제출95/100(정확성40/효율성20/품질15/경계15/설명5),풀이15분. 기존List버전93점은이력유지.

- Java21 동일26,494입력을동일·새객체에서재검증해52,988호출모두통과. 외부채점기미실행. 제출로직보존하여P023.java갱신,검증파일제외.
- 새버전시간평균O(WL): W=단어수,L=최대단어길이. 해시탐색평균상수회·문자열해시/비교O(L). L≤50고정이면평균O(W). 해시최악을상수시간으로단정하지않음.
- 추가공간O(W): 집합에입력문자열참조와관리노드저장,단어내용복제없음. 이전List시간O(W²L)는이력이며현재코드와구분.
- 남은설명과제: 주석의List/ArrayList를Set/HashSet으로변경,끝말연결검사·사람번호+1반영. n은참가자수이므로복잡도입력기호구분.
