# P167. 땅따먹기

- 출처: 프로그래머스 공개 연습 https://school.programmers.co.kr/learn/courses/30/lessons/12913
- 확인일: 2026-11-22. 출제 연도 미확인.
- 유형: DP · 행별 최댓값
- 난이도: 복습 중간, SWEA D3 수준 비공식 추정
- 권장 시간: 30분
- 상태: 통과 · 96점

N행 4열 점수판의 각 행에서 한 칸씩 고른다. 인접한 두 행에서는 같은 열을 고를 수 없다. 모든 행에서 선택한 점수 합의 최댓값을 반환한다. 처음과 끝 행은 인접하지 않는다.

Java 함수 public int solution(int[][] land). N은 1~100000, 각 행 길이는4, 각 점수는1~100. 표준입출력 없이 int 결과 반환.

예: [[1,2,3,5],[5,6,7,8],[4,3,2,1]] → 16. 4열의5, 3열의7, 1열의4를 고른다.

## 2026-11-22 · P167 평가 정정 및 통과

- 최초 계산 테스트 100개는 모두 통과. 추가 1개 실패는 public 접근 지정자 검사였으며 알고리즘 오답으로 취급하지 않는다. 사용자 요청으로 통과 처리. 저장본은 public만 추가.
- 제출 계산 로직 및 이전/현재 행 개선 코드 각각 Java 21 로컬 검증 101개 통과. 공개 채점기 미사용. 15분, 96점(정확성40/효율성20/품질13/경계15/설명8). 제출 O(N) 시간·O(N) 추가 공간, 개선 O(N) 시간·O(1) 추가 공간.
- 배열 인자는 배열 전체를 복사하지 않는다. DP 상태는 현재 열로 끝나는 최대 누적 점수이며 이전 행을 모두 참조한 후 다음 행으로 전환한다. 설명의 최소 누적합은 최대 누적 점수로 수정해야 한다.
