# P156. 전 품목 점검 기간

SSAFY 모의 6회차 2번 · 독립 창작 · SWEA D3 추정 · Java · 로컬 통과

2026-11-19. [17기 공식 공지](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_menu_cd=&p_pageno=&p_process=select-board-view&p_seq=194&p_tabseq=226504)와 [15기 후기](https://5-ms.tistory.com/32) 참고. 전체 80분에서 1번 31분 기준 최대 49분. 실제 타이머 잔여 시간 적용. 세부 채점은 종료 후 공개.

N일 동안 매일 품목 하나를 점검했다. 품목 번호는 1~K이다. 모든 품목이 한 번 이상 등장하는 비어 있지 않은 연속 기간 중 길이가 가장 짧은 것을 구한다. 동률이면 시작일이 빠른 구간을 선택한다. 날짜는 1부터 센다. 불가능하면 -1이다.

첫 줄 T(1~10). 케이스마다 N K(1≤N≤100,000, 1≤K≤1,000), 다음 줄에 품목 번호 N개가 주어진다. Solution.main에서 #케이스번호 시작일 기간길이 또는 #케이스번호 -1을 출력한다.

N=8, K=4, 기록 2 1 2 3 1 4 2 4에서 답은 #1 3 4다.

## 채점

Java 21 로컬 30/30. 풀이 시간 미확인. 평균 시간 O(N), 공간 O(N+K), 함수 추가 공간 O(K).
