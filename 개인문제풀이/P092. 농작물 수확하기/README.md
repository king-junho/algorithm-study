## 문제

N×N 농장의 각 칸에 농작물 가치가 적혀 있다. 농장의 정중앙을 중심으로, 네 꼭짓점이 농장의 네 변 가운데 칸에 닿는 마름모 영역에서만 수확한다. 테두리 칸도 포함해 수확한 농작물의 가치 합을 구한다.

## 입출력과 제한

첫 줄에 테스트 케이스 수 T가 주어진다. 각 케이스의 첫 줄에 홀수 N이 주어진다. 1 ≤ N ≤ 49. 다음 N줄에는 0~5 사이의 숫자 N개가 공백 없이 주어진다. 각 케이스마다 `#번호 가치합`을 한 줄에 출력한다. 번호는 1부터 시작한다.

## 자체 예시

입력

```text
2
3
123
450
234
1
5
```

출력

```text
#1 14
#2 5
```

첫 케이스에서는 첫 행 가운데 2, 둘째 행 전체 4·5·0, 마지막 행 가운데 3을 수확한다. 둘째 케이스에서는 한 칸만 수확한다.

Java `Solution.main`으로 작성한다. 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
