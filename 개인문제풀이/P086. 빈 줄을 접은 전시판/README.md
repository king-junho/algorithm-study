# P086. 빈 줄을 접은 전시판

- 난이도는 D3 수준 추정이다.
- 유형은 풀이 전 비공개다.
- 권장 시간은 25분이다.
- 공개 연습 문제의 입출력을 SWEA 형식으로 변형했다. 2021-08-08에 공개된 원문을 2026-11-09에 확인했다. [AtCoder ABC213 C](https://atcoder.jp/contests/abc213/tasks/abc213_c)

## 문제

H행 W열의 전시판에 표식 N개가 놓여 있다. 표식 번호는 입력 순서대로 1번부터 N번까지다. 표식이 하나도 없는 행은 제거해 위로 붙이고, 표식이 하나도 없는 열은 제거해 왼쪽으로 붙인다. 남은 행끼리, 남은 열끼리의 상대적인 순서는 유지한다.

모든 빈 행과 빈 열을 제거한 뒤, 각 표식의 새 위치를 입력 순서대로 출력하라. 행과 열 번호는 제거 전후 모두 1부터 시작한다.

## 입력

- 첫 줄에 테스트 케이스 수 T가 주어진다. 1 ≤ T ≤ 10.
- 각 테스트 케이스의 첫 줄에 H W N이 주어진다. 1 ≤ H, W ≤ 1,000,000,000이며 1 ≤ N ≤ min(100,000, H × W)이다.
- 다음 N줄에 각 표식의 행과 열 r c가 주어진다. 1 ≤ r ≤ H, 1 ≤ c ≤ W이며 같은 칸에 표식이 두 개 이상 놓이지 않는다.

## 출력

테스트 케이스마다 첫 줄에 `#테스트케이스번호`를 출력한다. 그다음 N줄에 각 표식의 새 행과 새 열을 공백으로 구분해 입력 순서대로 한 줄씩 출력한다. 테스트 케이스 번호는 1부터 시작한다.

## 예시 입력

```text
2
8 7 5
5 7
2 7
5 1
8 3
2 3
1000000000 1000000000 1
1000000000 1000000000
```

## 예시 출력

```text
#1
2 3
1 3
2 1
3 2
1 2
#2
1 1
```

첫 번째 전시판에서 (5, 7)은 빈 줄을 제거한 뒤 (2, 3)으로 이동한다. 두 번째 전시판에는 표식이 하나뿐이므로 한 행과 한 열만 남는다.

Java `Solution.main`으로 작성한다. 제출할 때 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 적는다.

- 20분(18:20~18:40), 79점. 정확성 40/40, 효율성 3/20, 코드 품질 13/15, 테스트·경계 조건 15/15, 설명 8/10. 효율성 미통과로 수정 대기.
- Java 21에서 예시와 한 행·한 열, 10억 좌표, 무작위 소형 격자를 포함해 200개 케이스의 표식 2,635개를 실행했다. 각 좌표보다 작은 서로 다른 좌표를 직접 세어 출력 전체를 비교했고 모두 일치했다. 최대 입력의 시간은 측정하지 않았다.
- 모든 행과 열이 서로 다르면 각 리스트의 contains와 indexOf가 선형 탐색을 반복한다. 두 축의 비교를 합하면 2N²이며 N=100,000에서 200억 번이다. 시간 O(N²), 케이스당 공간 O(N), 전체 출력 버퍼는 별도다.
- 정렬된 고유 좌표의 1부터 시작하는 순위라는 아이디어를 유지한다. 중복 확인과 순위 조회를 선형 탐색 없이 처리하도록 수정한다.
