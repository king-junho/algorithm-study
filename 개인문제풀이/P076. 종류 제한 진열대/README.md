# P076. 종류 제한 진열대

- 독립 창작(2026), 기출 아님. D3 수준 비공식 추정, 투 포인터 응용. 권장35분, 제출 대기.
- 개념 참고: CSES Distinct Values Subarrays II https://cses.fi/problemset/task/2428 , 확인2026-10-30. 원문 연도 미확인. 원문은 종류 수 제한을 만족하는 구간 개수, 이번 문제는 최대 길이이며 예시·입출력 별도 구성.

N개 상품의 종류 번호가 순서대로 주어진다. 서로 다른 종류가 K개 이하인 연속 구간 중 최대 상품 개수를 구하라. 같은 종류는 여러 번 있어도 된다. 순서 변경/중간 상품 제외 불가. K는 상품 수가 아닌 종류 수 제한. 출력 길이만.

입력 T(1~10), 각 케이스 N K, 다음 줄 N개 종류번호. 1≤K≤N≤200000, 1≤번호≤1000000000. 출력 #번호 최대상품개수. Java Solution/main.

입력
```
4
7 2
1 2 1 3 3 2 2
6 1
5 5 7 7 7 5
5 3
1 2 3 4 5
4 2
8 8 8 8
```
출력
```
#1 4
#2 3
#3 3
#4 4
```
첫째 위치4~7 [3,3,2,2] 종류2/길이4. 둘째 [7,7,7] 길이3. 셋째 연속3개가최대. 넷째 전부같은종류로전체4. 자료구조·이동규칙 요청 전 비공개.


## 2026-10-30 — P076 첫 제출: 수정 대기

- 주석 기준20분(13:05~13:25). 잠정62점(정확성20/효율성18/품질11/테스트·경계5/설명8). Java21 실제3사례: [1,2,1,2,3,3],K=2 기대4/실제5; 문제 첫예시 기대4/실제4; 둘째예시 기대3/실제3.
- LinkedHashSet에서 한 종류를 삭제해도 현재 구간 안의 그 종류가 모두 사라지는 것은 아님. 반례 right=4에서 종류1 삭제 후 left=1이지만 실제 [2,1,2,3]은3종류, set은{2,3}으로 상태 불일치. right=5에서 잘못된 길이5 갱신.
- 현재 구간 안 종류별 등장 횟수를 관리하고 왼쪽 원소 제거 시 감소, 횟수0이 될 때만 종류 삭제하는 방식으로 수정 유도. LinkedHashSet도 마지막 인덱스를 별도로 추적하면 가능하므로 사용 자체가 불가능하다고 단정하지 않음. 평균시간O(N), 입력포함공간O(N), 현재 set 자체는O(K). 전체 정답 요청 전 비공개, 완료 저장·커밋·푸시 없음.
