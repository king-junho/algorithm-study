# P063. 비상 연락 완료 시각

- 독립창작(2026),기초응용,유형비공개.
- 참고 https://cp-algorithms.com/graph/dijkstra.html 및 https://cp-algorithms.com/graph/mst_prim.html /확인2026-10-29. 실제기출·SWEA등록문제아님.
- 권장30분/제출대기

1~N번센터,M개단방향연락경로. 시각0에S번센터가비상소식을알고,소식을받은센터는즉시모든출발경로로동시에전달한다.각경로는고정전달시간.여러경로전달은병렬,센터는가장먼저받은시각부터전달가능.모든센터가소식을받기까지시간최소를출력.하나라도도달불가면-1.출발지는시각0에이미소식수신.

입력T(1~10),각케이스N M S,이어M줄a b time.1≤N≤1000,0≤M≤min(10000,N(N-1)),1≤S,a,b≤N,1≤time≤10^9.자기간선/같은방향중복없음,역방향존재가능.출력 #번호 완료시각. Java class Solution/main.

```text
입력
3
4 4 1
1 2 4
1 3 1
3 2 1
2 4 3
3 1 1
1 2 2
1 0 1

출력
#1 5
#2 -1
#3 0
```

첫째3번1,2번2,4번5에수신하므로전체완료5.둘째3번불가.셋째이미유일센터수신0. 코드/기법선택근거/복잡도/실제시간제출.유형및핵심풀이요청전비공개.
