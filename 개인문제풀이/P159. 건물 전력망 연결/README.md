# P159. 건물 전력망 연결

MST 기본 · 독립 창작 · 입문 · Java · 권장 20분 · 로컬 통과

2026-11-20 출제. 이전 MST·다익스트라·플로이드 학습 후 기초 유형 재점검 요청에 따라 MST부터 진행한다.

1~N 건물 사이 양방향 전선 후보 M개와 설치 비용이 주어진다. 전선을 선택해 모든 건물이 직접 또는 다른 건물을 거쳐 연결되도록 할 때 최소 총비용을 구한다. 불가능하면 -1이다. 시작 건물을 지정하지 않는다.

입력 첫 줄 T(1~10). 각 케이스 첫 줄 N M(1≤N≤100, 0≤M≤1,000), 다음 M줄 a b c(1≤a,b≤N, a≠b, 1≤c≤10^9). 같은 두 건물 사이 후보가 여러 개일 수 있다. Solution.main에서 #케이스번호 최소비용을 출력한다. N=1이면 비용 0.

예시 N=4, 간선 (1,2,3), (1,3,5), (2,3,1), (2,4,4), (3,4,2)의 최소 비용은 6이다.

## 제출 평가

7분(15:20~15:27). Java 21 로컬 100/100. 96점. 시간 O(N+M log(M+1)), 공간 O(N+M), 출력 버퍼 별도.
