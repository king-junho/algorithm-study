# P137. 장애물 경주 난이도

- 난이도 D3 · SWEA 공개 연습
- 확인일 2026-11-16
- 권장 시간 15분
- 상태 로컬 통과
- [SWEA 6730 공식 문제](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AWefy5x65PoDFAUh)

첫 블록부터 마지막 블록까지 순서대로 이동하며, 한 번의 이동에서 가장 크게 올라간 높이와 가장 크게 내려간 높이를 각각 구한다. 해당 방향의 높이 변화가 없으면 0이다.

입력은 테스트 케이스 수 T와 각 케이스의 블록 수 N, 높이 N개로 구성된다. 세부 제한은 공식 문제를 참고한다. 각 케이스마다 `#케이스번호 최대상승 최대하강`을 출력한다.

- `3 8 6 6 1` → `5 5`
- `4 4 4` → `0 0`

## 제출 기록

7분(12:30~12:37). 배열 순회. Java 21 로컬 107개 중 실패 0개. SWEA 공식 채점 미확인. 케이스당 시간 O(N), 입력 배열 포함 공간 O(N).
