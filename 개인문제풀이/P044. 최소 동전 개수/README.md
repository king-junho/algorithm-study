# P044 — 최소 동전 개수

- 출처구분:독립창작학습문제。실제평가기출/SWEA공식문제아님。
- 개념자료 https://cp-algorithms.com/dynamic_programming/intro-to-dp.html 。확인일2026-10-26,학습문제작성연도2026。
- 난이도:DP기초 / 유형:최솟값DP·동전조합
- 권장시간30분 / 상태:계산식 검증 완료·DP 해설 후 복습 대기

## 문제

1원·3원·4원동전을무제한사용할수있다。정확히N원을만들때필요한동전최소개수를구한다。동전순서는상관없고사용개수최소만출력。0원은동전0개。

## 입출력·제한

첫줄T(1~10),이후각케이스N(0~10000)。출력 #번호 최소개수。항상1원으로만들수있음。Java전체코드,class Solution,package없음。DP배열에작은금액의답을저장하여구현。

## 예시

```text
입력
4
0
2
6
10

출력
#1 0
#2 2
#3 2
#4 3
```

2원은1+1。6원은3+3두개,4+1+1세개보다적다。10원은4+3+3세개。

## 제출

전체코드,dp[i]의의미,초깃값·이전상태선택근거,시간공간복잡도,실제풀이시간。직접테스트제출요구없음。정답·점화식요청전미공개。

## 2026-11-04 — P044 계산식 개선안 및 정당화
