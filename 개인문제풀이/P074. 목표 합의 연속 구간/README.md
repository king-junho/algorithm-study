# P074. 목표 합의 연속 구간

- 유형: 투 포인터. D2 수준 비공식 추정(원문 공식 등급 아님).
- 출처: 공개 연습 CSES Subarray Sums I, https://cses.fi/problemset/task/1660 , 확인2026-10-30. 원문 출제 연도 미확인. 기출 분류 아님. 원문 조건은 유지하고 T/#번호 출력 및 별도 예시로 변형.
- 권장25분, 제출 대기.

양의 정수 N개가 입력 순서대로 주어진다. 합이 정확히 K인 비어 있지 않은 연속 구간의 개수를 구하라. 구간의 시작 또는 끝 위치가 다르면 다른 구간이다. 구간끼리 겹쳐도 된다. 배열 순서 변경 불가, 길이1 허용.

입력 T(1~10), 각 케이스 N K, 다음 줄 N개 정수. 1≤N≤200000, 1≤K,각 원소≤1000000000. 출력 #번호 구간개수. Java Solution/main.

입력
```
3
5 3
1 2 1 2 1
4 2
1 1 1 1
1 5
5
```
출력
```
#1 4
#2 3
#3 1
```
첫째 1-based [1,2],[2,3],[3,4],[4,5]. 둘째 [1,2],[2,3],[3,4]. 셋째 [1,1]. 정답 코드 및 이동 규칙 요청 전 비공개.
