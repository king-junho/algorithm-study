# P149. 합포장 주문 쌍

SSAFY 모의 4회차 2번 · 독립 창작 · SWEA D3 추정 · Java · 오답 · 복습 대상

2026-11-18. [17기 공식 공지](https://www.ssafy.com/ksp/servlet/swp.board.controller.SwpBoardServlet?p_menu_cd=&p_pageno=&p_process=select-board-view&p_seq=194&p_tabseq=226504)의 전체 80분 기준과 [15기 응시 후기](https://5-ms.tistory.com/32)를 참고했다. 1번에 쓴 시간을 포함해 처음 설정한 타이머의 남은 시간으로 진행한다.

N건의 주문 무게가 주어진다. 다른 두 주문의 무게 합이 L 이상 R 이하인 쌍의 수를 구한다. 순서는 구분하지 않으며 같은 무게라도 입력 위치가 다르면 별개의 주문이다. 각 쌍은 독립적으로 센다.

첫 줄 T(1~10). 케이스마다 N L R(2≤N≤100,000, 0≤L≤R≤2,000,000,000), 다음 줄에는 무게 N개(각 0~1,000,000,000). Solution.main에서 `#케이스번호 쌍의수`를 출력한다.

무게 1 1 3 4 7, L=4, R=5라면 두 무게 1 각각이 3, 4와 짝을 이뤄 답은 4다.

## 채점

로컬 28/30, 풀이 7분. 시간 O(N²), 공간 O(N). 최대 쌍 개수를 long으로 표현하고 쌍을 열거하는 비용을 줄여야 한다.
