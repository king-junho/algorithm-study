## 문제

두 수열의 원래 순서를 유지한 채, 짧은 수열 전체가 긴 수열의 연속된 구간에 놓이도록 맞춘다. 마주 보는 수끼리 곱해서 모두 더했을 때 가능한 합의 최댓값을 구한다.

## 입출력과 제한

첫 줄에 테스트 케이스 수 T가 주어진다. 각 케이스는 길이 N M, 첫 수열의 N개 정수, 둘째 수열의 M개 정수를 한 줄씩 입력받는다. 두 길이는 각각 3 이상 20 이하다. 각 케이스에서 `#번호 최댓값`을 한 줄에 출력한다. 번호는 1부터 시작한다.

## 자체 예시

입력

```text
1
3 4
1 2 3
4 1 2 3
```

출력

```text
#1 14
```

첫 번째 위치에 맞추면 합이 12이고, 두 번째 위치에 맞추면 합이 14다.

Java `Solution.main`으로 작성한다. 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
