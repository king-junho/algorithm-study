# P011 — 모든 방까지의 거리

- 출처 구분: 창작 문제(기출 아님), P010 후속 연습
- 참고: https://school.programmers.co.kr/learn/courses/30/lessons/49189 (공개 연습의 시작점 기준 최단거리 개념 참고)
- 변경점: 간선 쌍 대신 방별 연결 목록, 임의 start, 가장 먼 방 개수 대신 전체 거리 배열 반환. 방 번호0부터.
- 확인·창작일: 2026-10-19 / 난이도: BFS 기초 / 유형: BFS·거리 배열
- 권장 시간: 20분 / 상태: 로컬 검증 통과 · 98/100 · 20분

## 설명

rooms[i]는 i번 방과 직접 연결된 방 목록이다. start에서 모든 방까지 문을 지나는 최소 횟수를 구해 방 번호순 배열로 반환한다. start의 거리는0, 도달 불가 방은-1. 모든 문은 이동비용1이며 양방향.

## 함수·제한

`public int[] solution(int[][] rooms, int start)`

- 방 수1~20, 방 번호0..rooms.length-1
- start는 유효한 방 번호
- 연결은 양쪽 목록에 모두 제공. 빈 목록 가능, 자기 연결·중복 없음
- 연결 목록은 정렬되지 않을 수 있음
- 반환 배열 길이는 방 개수. 결과[i]는 방문순서가 아니라 i번 방까지 거리
- Queue와 반복문으로 BFS 구현

## 예시

1. rooms=[[1,2],[0,3],[0,4],[1,4],[2,3],[]], start=0 → [0,1,1,2,2,-1]. 방1·2는1회, 방3·4는2회, 방5 고립.
2. rooms=[[1],[0,2],[1]], start=2 → [2,1,0]. 방번호순 결과.
3. rooms=[[]], start=0 → [0].

- Java21 실제10,784개 시작점 사례 통과. 방1~5 모든 단순무방향그래프·모든 시작점, 방1~20 무작위500개·모든 시작점, 방20 완전연결·고립. 이웃목록 순서 무작위, 전체 거리배열을 독립 Floyd-Warshall과 비교. 입력 불변. 외부 채점기 미실행. Check.java 제외.
- 시간 O(V+E), 입력 제외 추가 공간 O(V). 거리 배열도 공간 계산에 포함.
- 품질: FIFO만 쓰므로 Queue 인터페이스로 의도를 좁히면 명확. next 지역변수와 향상된 for문으로 반복 인덱스 접근 정리 가능. Deque 선택·add/offer 혼용 자체는 오류 아님.
- 이해 확인: 모든 문 비용1이고 FIFO가 거리순으로 처리하므로 첫 발견이 최단. 같은거리·더긴 다른경로는 있을 수 있으나 더짧은 경로의 뒤늦은 발견은 없음. 비용이 다르면 일반 BFS로 보장 불가.
