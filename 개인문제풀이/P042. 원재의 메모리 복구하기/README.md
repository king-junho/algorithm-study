## 요약

0/1문자열target을복구한다。현재메모리는같은길이모두0이다。한번의조작으로위치하나와값0/1을골라그위치부터마지막까지모두선택한값으로덮어쓴다。target과같게만드는최소조작횟수를구한다。비트각각반전하는연산이아님。

## 입출력·제한

첫줄T,테스트마다목표문자열하나。길이1~50,0/1만포함。선행0보존해야하므로문자열입력。출력 #번호 최소횟수。Java전체프로그램,class Solution,package없음。T상한확인자료미명시。

## 학습용 예시

```text
입력
4
0011
1000
0000
10101

출력
#1 1
#2 2
#3 0
#4 5
```

0011은0000에서세번째위치부터1로설정한번。1000은0000→1111→1000。0000은이미일치。

## 2026-10-26 — 20분 보고 및 개선 검토
