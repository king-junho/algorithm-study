# P013 — DFS로 연결된 방 세기

- 출처 구분: 창작 문제(기출 아님), P008의 재귀 DFS 버전
- 참고: https://school.programmers.co.kr/learn/courses/30/lessons/43162 (공개 연습의 연결 개념 참고)
- 변경점: 연결 목록으로 제공, 지정된 start에서 갈 수 있는 방 개수만 반환. 재귀 DFS 학습 조건 추가.
- 확인·창작일: 2026-10-19 / 난이도: DFS 첫 연습 / 유형: 그래프·재귀 DFS·방문 표시
- 권장 시간: 20분 / 상태: 수정안 채택·로컬 검증 통과 · 97/100

## 설명

rooms[i]는 i번 방과 직접 연결된 방 목록이다. start에서 문을 여러 번 지나 도달할 수 있는 서로 다른 방의 개수를 반환한다. 출발 방도 포함하고 같은 방은 한 번만 센다. 문은 양방향, 거리나 방문 순서는 구하지 않는다.

## 함수·제한

`public int solution(int[][] rooms, int start)`

- 방 수1~10, 번호0..rooms.length-1
- start는 유효한 번호
- 양방향 연결은 양쪽 목록에 모두 제공
- 자기연결·목록내중복 없음, 순환·고립 가능, 빈 목록 가능
- 큐를 사용하는 BFS 대신 재귀 DFS로 구현. 보조 메서드 사용 가능

## 예시

1. rooms=[[1],[0,2],[1],[]], start=0 →3. 0,1,2 도달,3 고립.
2. 동일 rooms, start=3 →1. 출발방3만 포함.
3. rooms=[[1,2],[0,2],[0,1]], start=1 →3. 순환이어도 세 방을 한 번씩만 센다.

## 제출
