## 문제

N×N 숫자 배열을 시계 방향으로 90도, 180도, 270도 회전한 결과를 구한다.

## 입출력과 제한

첫 줄에 테스트 케이스 수 T가 주어진다. 각 케이스의 첫 줄에 N이 주어지고, 다음 N줄에는 한 자리 숫자가 N개씩 공백으로 구분되어 주어진다. 3 ≤ N ≤ 7이다.

각 케이스의 첫 줄에 `#번호`를 출력한다. 이어지는 N줄에는 90도, 180도, 270도 회전 결과의 해당 행을 순서대로 출력한다. 각 결과 내부의 숫자는 붙여 쓰고, 세 결과 사이는 공백 하나로 구분한다. 번호는 1부터 시작한다.

## 자체 예시

입력

```text
1
3
1 2 3
4 5 6
7 8 9
```

출력

```text
#1
741 987 369
852 654 258
963 321 147
```

90도 회전 결과의 첫 행은 7·4·1, 180도는 9·8·7, 270도는 3·6·9다.

Java `Solution.main`으로 작성한다. 풀이 아이디어, 시간·공간 복잡도, 실제 풀이 시간을 함께 확인한다.
