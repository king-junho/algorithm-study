상자N개의용량과독립적인주문Q개의물품크기가주어진다. 각주문마다물품크기이상의용량인상자의개수를구한다. 같은용량의상자도각각센다. 주문은실제상자를소모하지않는독립조회이다. 용량입력정렬보장없음. 동일크기주문반복가능.

입력T(1~10),각케이스N Q,다음줄N개상자용량,다음줄Q개주문크기.1≤N,Q≤100000,1≤용량/크기≤10^9. 출력 #번호 뒤에 주문순서대로Q개정수. Java class Solution/main.

```text
입력

#1 3 1 0
#2 1 1
```
