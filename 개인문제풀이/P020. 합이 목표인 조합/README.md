# P020 — 합이 목표인 조합

- 출처구분:창작문제(기출아님),P019후속
- 참고:https://school.programmers.co.kr/learn/courses/30/lessons/12977 (서로다른수선택·합검사개념)
- 원문과차이:숫자1..n·선택개수m·목표합target,소수판별대신목표합일치조합반환
- 확인·창작일:2026-10-20 / 난이도:백트래킹기초+ / 유형:조합·조건검사·가지치기
- 권장시간:30분 / 상태: 로컬 검증 통과 · 97/100 · 15분

## 설명

1..n중서로다른숫자m개를골라합이target인모든조합을반환한다. 같은숫자구성은순서와무관하게하나로취급하며각행은엄격오름차순,전체행은사전순이다. 가능한조합이없으면행이없는빈2차원배열을반환한다.

## 함수·제한

`public int[][] solution(int n, int m, int target)`

- 1≤m≤n≤9
- 1≤target≤45
- 각결과행길이m,원소1..n,중복없음
- 빈결과예시new int[0][] 또는new int[0][m], [[]]와다름
- 재귀백트래킹구현

## 예시

1. n5,m2,target6 → [[1,5],[2,4]]. [3,3]은중복이라불가.
2. n6,m3,target10 → [[1,3,6],[1,4,5],[2,3,5]].
3. n4,m3,target5 → []. 서로다른3개최소합1+2+3=6이므로불가.

## 제출

Java코드,풀이설명(가지치기사용시안전한이유),시간·공간복잡도및근거(결과저장포함여부),실제풀이시간. 직접테스트제출요구없음.

## 최종 평가

- 정확성40/40,효율성20/20,품질13/15,경계15/15,설명9/10=97/100,15분.
- [P020.java](P020.java): 제출로직보존,붙여넣기서식·클래스·import·공백정리
- 후보변수lastCandicate오탈자유지.
- Java21 전입력2,025개(n1..9,m1..n,target1..45)를2회반복4,050사례,동일·새객체각각검증(8,100호출). 결과행2,026개·빈결과3,300사례. 독립비트마스크기준,사전순·행참조독립·이전결과불변확인. 외부채점기없음,검증파일제외.
- K=C(n,m): 합조건과무관하게탐색하는전체조합수. R:목표합일치하는반환조합수(0≤R≤K).
- 시간O(mK): 전체K조합마다sum O(m),정답R개clone O(mR),탐색노드수O(mK). 복사만K번하는것이아니라모든조합의합검사가시간근거.
- 결과제외공간O(m): path와재귀깊이. 결과포함O(m+mR),최악R≤K를사용하면상한O(m+mK). List참조O(R)·바깥배열O(R)는mR에포함(m≥1).
- 후보상한n-remaining+1은남은자리수를채울수없는후보를제외하는안전한가지치기. 양의수합을활용한추가가지치기는없어도제한충분.
- 품질보완: lastCandicate→lastCandidate,backtrack private권장. result.toArray는빈리스트에서도빈배열을반환하므로isEmpty삼항불필요. 재귀매개변수에sum을전달하면완성시stream합계재계산제거가능(출력비용과탐색범위는별도평가).

## 2026-10-20 누적 합 개선

- 재제출에서 sum을매개변수로전달하고선택전+=number·탐색후-=number로복원. 정확하며완성시합검사O(1).
- Java21 전범위2,025입력2회반복4,050사례를동일·새객체각각검증,모두통과. 사전순·행독립·이전결과유지도동일. 기존97점·15분이력유지,추가수정시간미보고.
- sum은int값으로전달되므로 sum+number를인자로바로전달하면현재호출의sum변경·복원없이같은동작가능.
- K=C(n,m),R=정답수. 현재누적합버전은시간O(C(n+1,m)+mR),간단한상한O(mK). 전체유효접두사수Σ[d=0..m]C(n-m+d,d)=C(n+1,m). 합검사O(1),정답배열복사O(mR).
- 결과제외공간O(m),포함O(m+mR),스택깊이m. 이전스트림합버전시간설명은이력으로보존.
