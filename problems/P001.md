## 문제 설명

두 정수의 일치 여부에 따라 정해진 값을 반환한다. 두 값이 같을 때 반환값은 `1`, 서로 다를 때 반환값은 `-1`이다. 원문 조건을 보존한 요약이다.

## 함수 형식

Java의 `Solution` 클래스 안에 다음 메서드를 구현한다. 표준 입력과 출력은 사용하지 않는다.

```java
public int solution(int num1, int num2)
```

## 제한사항

- 두 매개변수는 각각 0 이상 10,000 이하의 정수다.
- 반환형은 `int`다.

## 예시

| num1 | num2 | 반환값 |
| --- | --- | --- |
| 2 | 3 | -1 |
| 11 | 11 | 1 |
| 7 | 99 | -1 |

첫 번째와 세 번째는 서로 다른 수이므로 -1, 두 번째는 같은 수이므로 1을 반환한다.
